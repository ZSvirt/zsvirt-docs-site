# Security policy

Please report suspected security vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/ZSvirt/zsvirt-docs-site/security/advisories/new). Include the affected revision, reproduction steps, impact and any suggested fix. Do not include real credentials or personal data in a reproduction.

Do not disclose exploit details through public issues or pull requests before maintainers have coordinated a fix. Ordinary content errors and non-security bugs can be reported through GitHub issues.

Security fixes target the current `main` branch. This repository does not publish a response-time guarantee.
