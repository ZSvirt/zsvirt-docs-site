# 文档站样式职责

`layout.tsx` 按以下顺序加载样式。页面组件和 MDX 内容共用这套样式，不再在 `global.css` 叠加另一套主题或布局。

| 文件 | 负责内容 |
| --- | --- |
| `global.css` | Tailwind、Fumadocs 框架入口与 Tailwind theme 声明 |
| `zsphere-foundation.css` | 明暗主题变量、页面基础排版、全局焦点与减少动态效果 |
| `zsphere-shell.css` | 顶栏、语言与主题控件、侧栏、目录及页面容器布局 |
| `zsphere-content.css` | 正文、卡片、提示、步骤、表格、代码块、标签页与折叠内容 |
| `zsphere-api.css` | API 方法标签、端点、请求/响应面板、代码控制台与 playground |

新增规则先找到所属模块，并直接修改现有定义。不要在 `global.css` 或文件末尾叠加整套覆盖。媒体查询与交互状态属于各自模块；相同选择器在不同媒体条件下不等于重复规则。

整理声明时需核对选择器优先级、简写与展开属性、`!important` 和媒体条件。只有确认旧声明已完全失效，才能删除；不要仅按选择器文本去重。

样式变更验证普通文档、文档索引与 API 页，覆盖中英文、浅色/深色、1440/1024/768/390px，以及移动导航和 API 弹窗。结构整理以修改前的截图与计算样式为基准；不为通过对比而更新基准。

应用检查：在仓库根目录运行 `pnpm test`、`pnpm types:check`、`pnpm build`。构建与开发服务不要同时操作同一 `.next` 目录。
