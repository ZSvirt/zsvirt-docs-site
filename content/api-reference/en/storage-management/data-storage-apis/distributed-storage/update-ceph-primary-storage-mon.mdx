---
title: "Update Distributed Storage Monitoring Node"
---

<APIPage method="PUT" path="/v1/primary-storage/ceph/mons/{monUuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "updateCephPrimaryStorageMon": {
    "hostname": "10.0.1.4"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the example above, **systemTags** and **userTags** fields can be omitted. They are listed to indicate that the body can contain these two fields.
</Callout>

Curl Examples

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"updateCephPrimaryStorageMon":{"hostname":"10.0.1.4"}}' \
http://localhost:8080/zstack/v1/primary-storage/ceph/mons/cda8b731b2e23b8eb1081dec0f7a0a60/actions
```
