---
title: "Refresh Data Storage Capacity"
---

<APIPage method="PUT" path="/v1/primary-storage/{primaryStorageUuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "syncPrimaryStorageCapacity": {},
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the example above, **systemTags** and **userTags** fields can be omitted. They are listed to indicate that the body can contain these two fields.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"syncPrimaryStorageCapacity":{}}' \
http://localhost:8080/zstack/v1/primary-storage/36ad940fe805304b85ca8af209b044b5/actions
```
