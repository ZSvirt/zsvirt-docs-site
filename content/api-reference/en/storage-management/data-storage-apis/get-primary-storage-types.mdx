---
title: "Get Data Storage Type List"
---

## **API Request**
URLs

```
GET zstack/v1/primary-storage/types
```

Headers

```
Authorization: OAuth the-session-uuid
```

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/primary-storage/types
```

Parameter List

|Name|Type|Location|Description|Allowed Values|Starting Version|
|----|----|--------|-----------|--------------|----------------|
|systemTags \(Optional\)|List|query|System Tags| |0.6|
|userTags \(Optional\)|List|query|User Tags| |0.6|
