---
title: "Add Reserved IP Range"
---

<APIPage method="POST" path="/v1/l3-networks/{l3NetworkUuid}/reserved-ip-ranges">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "startIp": "192.168.100.10",
    "endIp": "192.168.100.250"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the preceding sample, `systemTags` and `userTags` are optional. These two fields can be included in the body structure.
</Callout>

Curl Sample

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"startIp":"192.168.100.10","endIp":"192.168.100.250"}}' \
http://localhost:8080/zstack/v1/l3-networks/dc9fb647bbd73a768da652b6cd100495/reserved-ip-ranges
```
