<APIPage method="PUT" path="/v1/security-groups/{securityGroupUuid}/rules/state/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "changeSecurityGroupRuleState": {
    "ruleUuids": [
      "c895848e49763a85a74d0a8cee5a0720"
    ],
    "state": "Enabled"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the preceding sample, both **systemTags** and **userTags** are optional. They are listed here to indicate that these two fields can be included in the body.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8"
-H "Authorization: OAuth YOUR_SESSION_UUID"
-X PUT -d '{"changeSecurityGroupRuleState":{"ruleUuids":["c895848e49763a85a74d0a8cee5a0720"],"state":"Enabled"}}'
http://localhost:8080/zstack/v1/security-groups/fbd126afdf6b32caab55327d2901170f/rules/state/actions
```
