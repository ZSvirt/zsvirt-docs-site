<APIPage method="POST" path="/v1/security-groups">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "name": "sp",
    "description": "test create security group"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the preceding sample, both **systemTags** and **userTags** are optional. These two fields can be included in the body structure.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"name":"sp","description":"test create security group"}}' \
http://localhost:8080/zstack/v1/security-groups
```
