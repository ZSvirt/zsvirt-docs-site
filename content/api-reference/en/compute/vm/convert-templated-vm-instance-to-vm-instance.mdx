---
title: "Convert VM Template to Virtual Machine"
---

<APIPage method="POST" path="/v1/vm-instances/{templatedVmInstanceUuid}/convert-to-vmInstance?TemplatedVmInstanceUuid={TemplatedVmInstanceUuid}">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "name": "test-vm"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the example above, **systemTags** and **userTags** fields can be omitted. They are listed to indicate that these two fields can be included in the body.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"name":"test-vm"}}' \
http://localhost:8080/zstack/v1/vm-instances/60ac0f41f16031b19ab7666ab610466a/convert-to-vmInstance
```

Parameter List

|Name|Type|Location|Description|Allowed Values|Starting Version|
|----|----|--------|-----------|--------------|----------------|
|TemplatedVmInstanceUuid|String|url|VM Template UUID| |4.2.6|
|name|String|body\(included in the `params` structure\)|Virtual Machine Name| |4.2.6|
|systemTags \(Optional\)|List|body|System Tag| |4.2.6|
|userTags \(Optional\)|List|body|User Tag| |4.2.6|
|resetTpm \(Optional\)|Boolean|body\(included in the `params` structure\)|Whether to reset the TPM state after converting to a VM| |5.0.0|
