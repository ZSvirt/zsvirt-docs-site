---
title: "Create VM Instance"
---

<APIPage method="POST" path="/v1/vm-instances">

Create a new VM instance.

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "name": "vm1",
    "instanceOfferingUuid": "ae97ced44efc3314b8f7798972b4ba1a",
    "imageUuid": "da119f7906513eccabf271991c35a65e",
    "l3NetworkUuids": [
      "cc0e4c5e77df3af68e59668e7f9e06c5"
    ],
    "dataDiskOfferingUuids": [
      "19d22d051b063d379a2816daaf431838",
      "905d94a6abb5398fa1995f6398e3f6fc"
    ],
    "clusterUuid": "a0468dc645223f67bd0f2ab95276bbae",
    "description": "this is a vm",
    "strategy": "InstantStart",
    "rootVolumeSystemTags": [
      "volumeProvisioningStrategy::ThickProvisioning"
    ]
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the above example, **systemTags** and **userTags** fields can be omitted. They are listed to indicate that the body can contain these two fields.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8"
-H "Authorization: OAuth YOUR_SESSION_UUID"
-X POST -d '{"params":{"name":"vm1","instanceOfferingUuid":"ae97ced44efc3314b8f7798972b4ba1a","imageUuid":"da119f7906513eccabf271991c35a65e","l3NetworkUuids":["cc0e4c5e77df3af68e59668e7f9e06c5"],"dataDiskOfferingUuids":["19d22d051b063d379a2816daaf431838","905d94a6abb5398fa1995f6398e3f6fc"],"clusterUuid":"a0468dc645223f67bd0f2ab95276bbae","description":"this is a vm","strategy":"InstantStart","rootVolumeSystemTags":["volumeProvisioningStrategy::ThickProvisioning"]}}'
http://localhost:8080/zstack/v1/vm-instances
```
