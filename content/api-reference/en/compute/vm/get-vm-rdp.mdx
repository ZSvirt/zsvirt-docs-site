---
title: "Get VM RDP Status"
---

<APIPage method="GET" path="/v1/vm-instances/{uuid}/rdp">

Get VM RDP switch status. Return value is true or false

Headers

```
Authorization: OAuth the-session-uuid
```

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/vm-instances/78494eb669424e97b6f18920a920adbf/rdp
```

Parameter List

|Name|Type|Location|Description|Allowed Values|Starting Version|
|----|----|--------|-----------|--------------|----------------|
|uuid|String|url|Resource UUID, uniquely identifies the resource| |2.1|
|systemTags \(Optional\)|List|query| | |2.1|
|userTags \(Optional\)|List|query| | |2.1|

{
