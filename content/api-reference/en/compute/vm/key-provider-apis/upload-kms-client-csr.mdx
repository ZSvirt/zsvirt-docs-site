---
title: "Upload a KMS Client CSR and Private Key"
---

<APIPage method="PUT" path="/v1/key-providers/kms/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "uploadKmsClientCsr": {
    "csrPem": "-----BEGIN CERTIFICATE REQUEST-----\n...\n-----END CERTIFICATE REQUEST-----",
    "csrKeyPem": "YOUR_PRIVATE_KEY_PEM"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the preceding example, the `systemTags` and `userTags` fields can be omitted. They are listed to indicate that the body can include these two fields.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"uploadKmsClientCsr":{"csrPem":"-----BEGIN CERTIFICATE REQUEST-----\n...\n-----END CERTIFICATE REQUEST-----","csrKeyPem":"YOUR_PRIVATE_KEY_PEM"}}' \
http://localhost:8080/zstack/v1/key-providers/kms/ff0a9250e11b3fe5a553d61be176d300/actions
```

Parameter List

|Name|Type|Location|Description|Optional Value|Since|
|----|----|--------|-----------|--------------|-----|
|csrPem|String|body \(contained in `uploadKmsClientCsr` structure\)|CSR| |5.0.0|

|uuid|String|url|Resource UUID, which uniquely identifies the resource| |5.0.0|
|systemTags \(optional\)|List|body|System tags| |5.0.0|
