---
title: "Change NIC Default Traffic Policy"
---

<APIPage method="PUT" path="/v1/security-groups/nics/{vmNicUuid}/security-policy/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "changeVmNicSecurityPolicy": {
    "ingressPolicy": "ALLOW",
    "egressPolicy": "DENY"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the example above, **systemTags** and **userTags** fields can be omitted. They are listed to indicate that the body can contain these two fields.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" -H "Authorization: OAuth YOUR_SESSION_UUID" -X PUT -d '{"changeVmNicSecurityPolicy":{"ingressPolicy":"ALLOW","egressPolicy":"DENY"}}' http://localhost:8080/zstack/v1/security-groups/nics/5551303bee7037c8848cdb5741be7ff7/security-policy/actions
```
