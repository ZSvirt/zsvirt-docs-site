---
title: "Create Stop Virtual Machine Scheduler"
---

<APIPage method="POST" path="/v1/vm-instances/{vmUuid}/schedulers/stopping">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "schedulerName": "vm-scheduler",
    "schedulerDescription": "for test stop vm scheduler",
    "type": "simple",
    "interval": 5.0,
    "repeatCount": 10.0,
    "startTime": 0.0
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the example above, **systemTags** and **userTags** fields can be omitted. They are listed to indicate that the body can contain these two fields.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST http://localhost:8080/zstack/v1/vm-instances/09b1ee5bddea44a5bb56c471deae95d5/schedulers/stopping?
```
