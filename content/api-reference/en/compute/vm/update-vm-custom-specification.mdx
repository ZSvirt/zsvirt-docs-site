---
title: "Update Virtual Machine Custom Operating System Specification"
---

<APIPage method="PUT" path="/v1/vm-custom-specifications/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "updateVmCustomSpecification": {
    "description": "description"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the example above, `systemTags` and `userTags` fields can be omitted. They are listed to indicate that these two fields can be included in the body.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"updateVmCustomSpecification":{"description":"description"}}' \
http://localhost:8080/zstack/v1/vm-custom-specifications/ff0a9e874342368bb28daaf2c9b3cc00/actions
```
