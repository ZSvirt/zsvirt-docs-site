---
title: "Update VM CD-ROM"
---

<APIPage method="PUT" path="/v1/vm-instances/cdroms/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "updateVmCdRom": {
    "name": "cd-2"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the example above, **systemTags** and **userTags** fields can be omitted. They are listed to indicate that the body can contain these two fields.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"updateVmCdRom":{"name":"cd-2"}}' http://localhost:8080/zstack/v1/vm-instances/cdroms/407c8e5cee4b3430bbb9f0f4d4c8a422/actions
```
