---
title: "Reimage Virtual Machine"
---

<APIPage method="PUT" path="/v1/vm-instances/{vmInstanceUuid}/actions">

Reimage a Virtual Machine root volume to its initial state. This API is only valid for Virtual Machines created from non-ISO images.

**Warning:** After executing this API, the Virtual Machine root volume will be reset to its initial state created, meaning all data written afterward will be lost. This operation cannot be reversed!

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "reimageVmInstance": {},
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
The **systemTags** and **userTags** fields in the example above are optional. Listed to indicate these fields can be included in the body.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"reimageVmInstance":{}}' \
http://localhost:8080/zstack/v1/vm-instances/f38615d717a438c39eca3b8b560a00ef/actions
```
