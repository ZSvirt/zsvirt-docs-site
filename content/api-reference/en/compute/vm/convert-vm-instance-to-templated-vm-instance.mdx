title: "Convert Virtual Machine To Templated Virtual Machine"
---

<APIPage method="POST" path="/v1/vm-instances/{vmInstanceUuid}/convert-to-templatedVmInstance">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {},
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the example above, **systemTags** and **userTags** fields can be omitted. They are listed to indicate that the body can contain these two fields.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{}}' http://localhost:8080/zstack/v1/vm-instances/ad7a18919c8331f3a3b2fa482414afee/convert-to-templatedVmInstance
```

|Name|Type|Location|Description|Allowed Values|Starting Version|
