---
title: "Update Group Directory"
---

<APIPage method="PUT" path="/v1/update/directory">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "updateDirectory": {
    "uuid": "66a79f93fd5d3d269302297dc1459f6e",
    "name": "test"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the example above, **systemTags** and **userTags** fields can be omitted. They are listed to indicate that the body can contain these two fields.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"updateDirectory":{"uuid":"66a79f93fd5d3d269302297dc1459f6e","name":"test"}}' http://localhost:8080/zstack/v1/update/directory
```

Parameter List

|Name|Type|Location|Description|Allowed Values|Starting Version|
|----|----|--------|-----------|--------------|----------------|
|uuid|String|body\(contained in **updateDirectory** structure\)|Resource UUID, a unique identifier for the resource| |4.6.0|
|name|String|body\(contained in **updateDirectory** structure\)|Resource Name| |4.6.0|
|systemTags \(optional\)|List|body|System Tags| |4.6.0|
|userTags \(optional\)|List|body|User Tags| |4.6.0|
