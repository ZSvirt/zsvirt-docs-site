---
title: "Attach ISO to VM"
---

<APIPage method="POST" path="/v1/vm-instances/{vmInstanceUuid}/iso/{isoUuid}">

Attach an ISO image to a Running or Stopped Virtual Machine.

Headers

```
Authorization: OAuth the-session-uuid
```

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST http://localhost:8080/zstack/v1/vm-instances/b1105c5dd00f323d99aa182dee237628/iso/8f36a77ab76e3425a571a7f75fca2d69
```

Parameter List

|Name|Type|Location|Description|Allowed Values|Starting Version|
|----|----|--------|-----------|--------------|----------------|
|vmInstanceUuid|String|url|Virtual Machine UUID| |0.6|
|isoUuid|String|url|ISO UUID| |0.6|
|systemTags \(optional\)|List|body|System Tags| |0.6|
|userTags \(optional\)|List|body|User Tags| |0.6|
