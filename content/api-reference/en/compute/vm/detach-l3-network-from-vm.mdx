---
title: "Detach L3 Network from VM"
---

<APIPage method="DELETE" path="/v1/vm-instances/nics/{vmNicUuid}">

Detach a network from a Running or Stopped Virtual Machine.

Headers

```
Authorization: OAuth the-session-uuid
```

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X DELETE http://localhost:8080/zstack/v1/vm-instances/nics/e8c694f7dcaa3a48860312d86d77fcde
```

|Name|Type|Location|Description|Allowed Values|Starting Version|
|----|----|--------|-----------|--------------|----------------|
|vmNicUuid|String|url|VM NIC UUID. The network to which this NIC belongs will be detached from the Virtual Machine.| |0.6|
|systemTags \(optional\)|List|body|System Tags| |0.6|
|userTags \(optional\)|List|body|User Tags| |0.6|
