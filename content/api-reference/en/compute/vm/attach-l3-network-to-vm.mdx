---
title: "Attach L3 Network to VM"
---

<APIPage method="POST" path="/v1/vm-instances/{vmInstanceUuid}/l3-networks/{l3NetworkUuid}">

Dynamically add a network to a Running or Stopped Virtual Machine.

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "driverType": "e1000"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
Note: **systemTags** and **userTags** fields can be omitted in the above example. They are listed to indicate that the body can contain these two fields.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"driverType":"e1000"}}' \
http://localhost:8080/zstack/v1/vm-instances/f526e22f739838f4bcdfdd20f0ba8a73/l3-networks/00fab8159d1d3534802c588c2bd9a28b
```
