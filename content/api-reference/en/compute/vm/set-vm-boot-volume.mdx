---
title: "Set VM Boot Volume"
---

<APIPage method="PUT" path="/v1/vm-instances/{vmInstanceUuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "setVmBootVolume": {
    "volumeUuid": "5f9b86be026636008999dd6b971a6f18"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the example above, **systemTags** and **userTags** fields can be omitted. They are listed to indicate that the body can contain these two fields.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"setVmBootVolume":{"volumeUuid":"5f9b86be026636008999dd6b971a6f18"}}' http://localhost:8080/zstack/v1/vm-instances/0352b51de6353d2ea89f2b4ca1c2178c/actions
```
