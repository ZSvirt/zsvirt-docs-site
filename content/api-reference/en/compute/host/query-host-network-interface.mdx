title: "Query Host NIC Information"

<APIPage method="GET" path="/v1/hosts/nics">

```
GET zstack/v1/hosts/nics/{uuid}
```

Headers

```
Authorization: OAuth the-session-uuid
```

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/hosts/nics
```

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/hosts/nics/df5b59fdb3c9388297fd89c5fa6dea65
```

Queryable Fields

Run the CLI command tool, enter `QueryHostNetworkInterface` and press Tab to view all queryable fields and resources that can be queried across tables.
