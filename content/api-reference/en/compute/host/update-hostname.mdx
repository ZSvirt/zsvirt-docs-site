---
title: "Update Hostname"
---

<APIPage method="PUT" path="/v1/hosts/hostname/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "updateHostname": {
    "hostname": "user"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the example above, `systemTags` and `userTags` fields can be omitted. They are listed to show that the body can contain these two fields.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"updateHostname":{"hostname":"user"}}' \
http://localhost:8080/zstack/v1/hosts/hostname/edd915d52a0c3d108616187f388bf4e7/actions
```

Parameter List

|Name|Type|Location|Description|Allowed Values|Starting Version|
|----|----|--------|-----------|--------------|----------------|
|uuid|String|url|Host UUID| |4.10.20|
|hostname|String|body \(contained in the `updateHostname` structure\)|Host hostname| |4.10.20|
|systemTags \(Optional\)|List|body|System Tags| |4.10.20|
|userTags \(Optional\)|List|body|User Tags| |4.10.20|
