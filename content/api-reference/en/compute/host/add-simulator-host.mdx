title: "Add Simulator Host"

<APIPage method="POST" path="/v1/hosts/simulators">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "memoryCapacity": 1000000000,
    "cpuCapacity": 1000000000,
    "name": "simulator",
    "managementIp": "127.0.0.1",
    "clusterUuid": "d8d3b37f047f3d04b089e5b9e7e878a9"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the example above, `systemTags` and `userTags` fields can be omitted. They are listed to show that the body can contain these two fields.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \-X POST -d '{"params":{"memoryCapacity":1000000000,"cpuCapacity":1000000000,"name":"simulator","managementIp":"127.0.0.1","clusterUuid":"d8d3b37f047f3d04b089e5b9e7e878a9"}}' \
http://localhost:8080/zstack/v1/hosts/simulators
```
