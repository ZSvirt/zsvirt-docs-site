<APIPage method="GET" path="/v1/pci-device/candidate-pci-devices-for-new-create-vm">

Get loadable PCI devices for a newly created Virtual Machine.

Headers

```

Authorization: OAuth the-session-uuid
```

Curl Example

```

curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/pci-device/candidate-pci-devices-for-new-create-vm?hostUuid=3376aee6af913e278a1a6aafc28c2e94
```
