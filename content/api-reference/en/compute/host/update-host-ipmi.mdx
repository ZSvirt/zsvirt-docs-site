---
title: "Update Host IPMI Information"
---

<APIPage method="PUT" path="/v1/hosts/ipmi/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "updateHostIpmi": {
    "ipmiAddress": "127.0.0.10",
    "ipmiUsername": "admin",
    "ipmiPassword": "password",
    "ipmiPort": 623
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the above example, **systemTags** and **userTags** fields can be omitted. They are listed to indicate that these two fields can be included in the body.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \-X PUT -d '{"updateHostIpmi":{"ipmiAddress":"127.0.0.10","ipmiUsername":"admin","ipmiPassword":"password","ipmiPort":623}}' \
http://localhost:8080/zstack/v1/hosts/ipmi/6cbd75f1a7cb3805b47a8dca8871c1c6/actions
```
