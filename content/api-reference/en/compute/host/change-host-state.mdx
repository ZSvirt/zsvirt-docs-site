---
title: "Change Host State"
---

<APIPage method="PUT" path="/v1/hosts/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "changeHostState": {
    "stateEvent": "enable"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the above example, **systemTags** and **userTags** fields can be omitted. They are listed to indicate that these two fields can be included in the body.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth b86c9016b4f24953a9edefb53ca0678c" \
-X PUT -d '{"changeHostState":{"stateEvent":"enable"}}' \
http://localhost:8080/zstack/v1/hosts/70e37940fe263e858a151850a312143f/actions
```
