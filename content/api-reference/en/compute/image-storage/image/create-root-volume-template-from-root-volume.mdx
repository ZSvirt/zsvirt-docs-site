title: "Create Root Volume Template from Root Volume"
---

<APIPage method="POST" path="/v1/images/root-volume-templates/from/volumes/{rootVolumeUuid}">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "name": "My Root Volume Template",
    "backupStorageUuids": [
      "a3cb55d45fb63d1da4911b9d16273a55"
    ],
    "platform": "Linux",
    "system": false
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the above example, **systemTags** and **userTags** fields can be omitted. They are listed to indicate that the body can contain these two fields.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"name":"My Root Volume Template","backupStorageUuids":["a3cb55d45fb63d1da4911b9d16273a55"],"platform":"Linux","system":false}}' http://localhost:8080/zstack/v1/images/root-volume-templates/from/volumes/3bfc6f9eaf243299b8515382310be47b
```

<Callout type="info">
-   ZSvirt supports copying GuestTools label values from the VM to the Image when creating a Root Volume Image from a Root Volume. When using this Image to create a VM, the GuestTools label values are copied from the Image to the new VM. Add **GuestTools** option to **SystemTags**.
    -   Option format: `GuestTools::TOOLS_VERSION`, where TOOLS\_VERSION initial value is 1.0.0. This value will change as the tool version advances.
    -   Example: `GuestTools::1.0.0`
    -   Additional note: When creating an Image from a VM's Root Volume, copy the GuestTools label values from the VM to the Image.
</Callout>
