---
title: "Update Standalone Image Storage"
---

<APIPage method="PUT" path="/v1/backup-storage/image-store/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "updateImageStoreBackupStorage": {
    "hostname": "192.168.1.18"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the example above, `systemTags` and `userTags` fields can be omitted. They are listed to indicate that the body can contain these two fields.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"updateImageStoreBackupStorage":{"hostname":"192.168.1.18"}}' \
http://localhost:8080/zstack/v1/backup-storage/image-store/fa603f20ce2c370a8ba9d1928c3d6173/actions
```
