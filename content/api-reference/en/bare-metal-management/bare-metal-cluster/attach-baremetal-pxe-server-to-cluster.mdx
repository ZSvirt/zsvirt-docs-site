---
title: "Attach PXE Server to Bare Metal Cluster"
---

<APIPage method="POST" path="/v1/clusters/{clusterUuid}/pxeservers/{pxeServerUuid}">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {},
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the example above, `systemTags` and `userTags` fields can be omitted. They are listed to indicate that these fields can be included in the body.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{}}' \
http://localhost:8080/zstack/v1/clusters/47b43452a77a309e9c9e1b3b23a9e978/pxeservers/b069eaeb0e2c355aaabca9738fb8332b
```

Parameter List

|Name|Type|Location|Description|Allowed Values|Starting Version|
|----|----|--------|-----------|--------------|----------------|
|pxeServerUuid|String|url|Deployment server UUID| |3.1.1|
|clusterUuid|String|url|Bare metal cluster UUID| |3.1.1|
|systemTags \(Optional\)|List|body|System Tag| |3.1.1|
|userTags \(Optional\)|List|body|User Tag| |3.1.1|
