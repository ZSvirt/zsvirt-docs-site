---
title: "Recover Bare Metal Instance"
---

<APIPage method="PUT" path="/v1/baremetal/instances/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "recoverBaremetalInstance": {},
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the example above, `systemTags` and `userTags` fields can be omitted. They are listed to indicate that these fields can be included in the body.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"recoverBaremetalInstance":{}}' \
http://localhost:8080/zstack/v1/baremetal/instances/0a71736890e437928f90415a276ca245/actions
```
