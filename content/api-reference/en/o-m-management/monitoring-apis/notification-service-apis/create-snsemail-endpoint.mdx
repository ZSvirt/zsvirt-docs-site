title: "Create Email Endpoint"
---

<APIPage method="POST" path="/v1/sns/application-endpoints/emails">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "email": "example@cloud.io",
    "emails": [
      "example@cloud.io"
    ],
    "name": "email",
    "platformUuid": "5efc525948a537e39a91290c57d6d37b"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the above example, the **systemTags** and **userTags** fields are optional. They are listed to indicate that the body can contain these two fields.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"email":"example@cloud.io","emails":["example@cloud.io"],"name":"email","platformUuid":"5efc525948a537e39a91290c57d6d37b"}}' http://localhost:8080/zstack/v1/sns/application-endpoints/emails
```
