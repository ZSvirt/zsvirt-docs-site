title: "Create a WeCom Endpoint"
---

<APIPage method="POST" path="/v1/sns/application-endpoints/we-com">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "url": "https://example.invalid/webhook",
    "atAll": false,
    "atPersonUserIds": [
      "18900002222",
      "13377778888"
    ],
    "atPersonList": {
      "13377778888": "jack"
    },
    "name": "wecom"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the example above, the **systemTags** and **userTags** fields are optional. They are listed to indicate that these two fields can be included in the body.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"url":"https://example.invalid/webhook","atAll":false,"atPersonUserIds":["18900002222","13377778888"],"atPersonList":{"13377778888":"jack"},"name":"wecom"}}' \
http://localhost:8080/zstack/v1/sns/application-endpoints/we-com
```
