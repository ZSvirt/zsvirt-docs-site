title: "Update Feishu Endpoint"
---

<APIPage method="PUT" path="/v1/sns/application-endpoints/feishu/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "updateSNSFeiShuEndpoint": {
    "url": "https://example.invalid/webhook",
    "atAll": false,
    "secret": "YOUR_WEBHOOK_SECRET",
    "name": "new name",
    "description": "desc"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the preceding example, the **systemTags** and **userTags** fields are optional. They are listed to indicate that the body can contain these two fields.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"updateSNSFeiShuEndpoint":{"url":"https://example.invalid/webhook","atAll":false,"secret":"YOUR_WEBHOOK_SECRET","name":"new name","description":"desc"}}' \
http://localhost:8080/zstack/v1/sns/application-endpoints/feishu/74a9c83578883992b21555b2f46ce38d/actions
```
