Headers

```
Authorization: OAuth the-session-uuid
```

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/sns/sms-endpoints?q=name=SmsEndpoint
```

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/sns/sms-endpoints/5efca3a7d67031fbba5bc512e52a4798
```

Queryable Fields

Run the CLI tool, enter `QuerySNSSmsEndpoint` and press Tab to view all queryable fields and cross-table queryable resource names.

## API Response
On success, this API returns an empty JSON structure `{}`. On error, the returned JSON structure contains an error field, for example:

```
{
  "error": {
    "code": "SYS.1001",
    "description": "A message or a operation timeout",
    "details": "Create VM on KVM timeout after 300s"
  }
}
```
