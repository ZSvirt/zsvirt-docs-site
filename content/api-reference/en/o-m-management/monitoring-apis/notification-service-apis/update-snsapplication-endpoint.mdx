---
title: "Update SNS Application Endpoint"
---

<APIPage method="PUT" path="/v1/sns/application-endpoints/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "updateSNSApplicationEndpoint": {
    "name": "new name"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the preceding example, the **systemTags** and **userTags** fields are optional. They are listed to indicate that the body can contain these two fields.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"updateSNSApplicationEndpoint":{"name":"new name"}}' \
http://localhost:8080/zstack/v1/sns/application-endpoints/7d6155384f4e3cdaa6e877ecec59318c/actions
```

Parameter List

|Name|Type|Location|Description|Allowed Values|Starting Version|
