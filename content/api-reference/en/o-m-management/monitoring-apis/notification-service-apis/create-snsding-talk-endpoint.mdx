title: "Create DingTalk Endpoint"

<APIPage method="POST" path="/v1/sns/application-endpoints/ding-talk">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "url": "https://example.invalid/webhook",
    "atAll": false,
    "secret": "YOUR_WEBHOOK_SECRET",
    "atPersonPhoneNumbers": [
      "18900002222",
      "13377778888"
    ],
    "atPersonList": {
      "13377778888": "jack"
    },
    "name": "dinding"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the preceding example, the **systemTags** and **userTags** fields are optional. They are listed to indicate that the body can contain these two fields.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"url":"https://example.invalid/webhook","atAll":false,"secret":"YOUR_WEBHOOK_SECRET","atPersonPhoneNumbers":["18900002222","13377778888"],"atPersonList":{"13377778888":"jack"},"name":"dinding"}}' \
http://localhost:8080/zstack/v1/sns/application-endpoints/ding-talk
```
