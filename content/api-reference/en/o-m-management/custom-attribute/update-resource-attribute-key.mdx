---
title: "Update Custom Attribute Key"
---

<APIPage method="PUT" path="/v1/resource-attributes/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "updateResourceAttributeKey": {
    "description": "test"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the above example, the `systemTags` and `userTags` fields can be omitted. They are listed to show that these two fields can be included in the body.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"updateResourceAttributeKey":{"description":"test"}}' \
http://localhost:8080/zstack/v1/resource-attributes/ff03a2b491023030bf58b1b35ea9cd00/actions
```
