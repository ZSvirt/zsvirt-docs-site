title: "Get Management Node Status"
---

<APIPage method="GET" path="/v1/management-nodes/status">

Headers

```
Authorization: OAuth the-session-uuid
```

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/management-nodes/status
```

Parameter List

|Name|Type|Location|Description|Allowed Values|Starting Version|
|----|----|--------|-----------|--------------|----------------|
|systemTags \(Optional\)|List|query|System tags| |4.10.20|
|userTags \(Optional\)|List|query|User tags| |4.10.20|
