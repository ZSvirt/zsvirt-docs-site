Queryable Fields

Run the CLI command-line tool, type `QueryClusterDRS` and press the Tab key to view all queryable fields and cross-table queryable resource names.

## API Response
On success, this API returns an empty JSON structure `{}`. On failure, the returned JSON structure contains an error field, for example:

```
{
  "error": {
    "code": "SYS.1001",
    "description": "A message or a operation timeout",
    "details": "Create VM on KVM timeout after 300s"
  }
}
```
