---
title: "Create Snapshot Group"
---

<APIPage method="POST" path="/v1/volume-snapshots/group">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "rootVolumeUuid": "901cae4fd9f43a1ca20da4146ddaec50",
    "name": "test"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
The **systemTags** and **userTags** fields in the above example are optional. They are listed to indicate that the body can contain these two fields.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"rootVolumeUuid":"901cae4fd9f43a1ca20da4146ddaec50","name":"test"}}' http://localhost:8080/zstack/v1/volume-snapshots/group
```
