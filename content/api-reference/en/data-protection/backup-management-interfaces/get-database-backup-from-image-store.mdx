title: "Get Database Backup"
---

<APIPage method="GET" path="/v1/database-backups/image-store">

Get exported database backup from backup storage.

Headers

```
Authorization: OAuth the-session-uuid
```

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/database-backups/image-store?url=ssh://root:password@localhost:22/Cloud_bs&registryPort=8000.0
```

Parameter List

|Name|Type|Location|Description|Allowed Values|Starting Version|
|----|----|--------|-----------|--------------|----------------|
|url|String|query|Image Storage URL| |3.0.0|
|registryPort \(Optional\)|int|query|Image repository access port| |3.0.0|
|systemTags \(Optional\)|List|query| | |3.0.0|
|userTags \(Optional\)|List|query| | |3.0.0|
