title: "Sync Database Backup"
---

<APIPage method="PUT" path="/v1/database-backups/imageStore/{imageStoreUuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "syncDatabaseBackup": {},
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
The **systemTags** and **userTags** fields in the above example are optional. They are listed to indicate that the body can contain these two fields.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"syncDatabaseBackup":{}}' http://localhost:8080/zstack/v1/database-backups/imageStore/77e7125f5ecf4cbe9129b0e8483a00ae/actions
```
