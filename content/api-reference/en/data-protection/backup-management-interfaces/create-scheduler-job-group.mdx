---
title: "Create a Scheduler Job Group"
---

<APIPage method="POST" path="/v1/scheduler/jobgroups">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "name": "job",
    "description": "description",
    "type": "startVm"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
The **systemTags** and **userTags** fields in the above example are optional. They are listed to indicate that the body can contain these two fields.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"name":"job","description":"description","type":"startVm"}}' http://localhost:8080/zstack/v1/scheduler/jobgroups
```
