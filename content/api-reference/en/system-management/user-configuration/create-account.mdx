---
title: "Create Account"
---

<APIPage method="POST" path="/v1/accounts">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "name": "test",
    "password": "password",
    "state": "Enabled"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
In the above example, the **systemTags** and **userTags** fields can be omitted. They are listed to show that these two fields can be included in the body.
</Callout>

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"name":"test","password":"password","state":"Enabled"}}' \
http://localhost:8080/zstack/v1/accounts
```
