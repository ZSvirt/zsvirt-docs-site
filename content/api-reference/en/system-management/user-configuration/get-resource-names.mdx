title: "Get Resource Names"

<APIPage method="GET" path="/v1/resources/names">

Headers

```
Authorization: OAuth the-session-uuid
```

Curl Example

```
curl  -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/resources/names?uuids=393ce06589043e33b397bc21043e8cd4&uuids=b62bdb31280a30a69c2f110bac8cb682
```

Parameter List

|Name|Type|Location|Description|Allowed Values|Starting Version|
|----|----|--------|-----------|--------------|----------------|
|uuids|List|query|Resource UUID list| |0.6|
|systemTags \(Optional\)|List|query| | |0.6|
|userTags \(Optional\)|List|query| | |0.6|
