---
title: "Create SNS SNMP Platform"
---

<APIPage method="POST" path="/v1/sns/application-platforms/snmp">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "snmpAddress": "127.0.0.1",
    "snmpPort": 161,
    "name": "snmp platform"
  },
  "systemTags": [],
  "userTags": []
}
```

The `systemTags` and `userTags` fields in the above example are optional. They are listed to indicate that the body can contain these two fields.

Curl Example

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"snmpAddress":"127.0.0.1","snmpPort":161,"name":"snmp platform"}}' http://localhost:8080/zstack/v1/sns/application-platforms/snmp
```
