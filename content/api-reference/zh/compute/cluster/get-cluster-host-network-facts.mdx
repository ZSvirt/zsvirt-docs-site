<APIPage method="GET" path="/v1/cluster/hosts-network-facts/{clusterUuid}?hostUuid={hostUuid}">

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/cluster/hosts-network-facts/811d04aa12e3390cb29cb7664862e1f2?limit=1000&start=0
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|hostUuid|String|url|集群UUID| |4.3.6|
|limit \(可选\)|Integer|query| | |4.3.6|
|start \(可选\)|Integer|query| | |4.3.6|
|systemTags \(可选\)|List|query| | |4.3.6|
|userTags \(可选\)|List|query| | |4.3.6|
