---
title: "从虚拟机卸载网络"
---

<APIPage method="DELETE" path="/v1/vm-instances/nics/{vmNicUuid}">

从Running或Stopped的虚拟机上卸载一个网络。

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X DELETE http://localhost:8080/zstack/v1/vm-instances/nics/e8c694f7dcaa3a48860312d86d77fcde
```

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|vmNicUuid|String|url|虚拟机网卡UUID，该网卡所在网络会从虚拟机卸载掉| |0.6|
|systemTags \(可选\)|List|body|系统标签| |0.6|
|userTags \(可选\)|List|body|用户标签| |0.6|
