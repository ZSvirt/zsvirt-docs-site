title: "获取可选择的数据存储"

<APIPage method="GET" path="/v1/vm-instances/candidate-storages">

获取创建虚拟机可选择的数据存储。用户可通过指定虚拟机参数，来获取当前参数下可选择的数据存储。

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/vm-instances/candidate-storages?imageUuid=5f977e1354aa300bb27e0584d52bb09a&l3NetworkUuids=0276c5ffc04731d6b671c972272bd10a&dataDiskOfferingUuids=0b2b7ff196113ed79dad6bf815a6033e&dataDiskOfferingUuids=cfad76f5d345387d9215773fcd5389c5&clusterUuid=90fac86c000b335396f995bef052fb41
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|imageUuid|String|query|镜像UUID| |2.1|
|l3NetworkUuids|List|query|分布式端口组UUID| |2.1|
|rootDiskOfferingUuid \(可选\)|String|query|根硬盘使用的硬盘规格UUID，镜像类型为ISO时可选且必选| |2.1|
|rootDiskSize \(可选\)|Long|query|自定义根硬盘大小。仅在`imageUuid`指定的镜像是ISO时且`rootDiskOfferingUuid`为空需要指定| |4.3.12|
|dataDiskOfferingUuids \(可选\)|List|query|数据硬盘使用的硬盘规格UUID| |2.1|
|dataDiskSizes \(可选\)|List|query|自定义数据硬盘大小| |4.3.12|
|zoneUuid \(可选\)|String|query|数据中心UUID| |2.1|
|clusterUuid \(可选\)|String|query|集群UUID| |2.1|
|defaultL3NetworkUuid \(可选\)|String|query|默认分布式端口组UUID| |2.1|
|systemTags \(可选\)|List|query|系统标签| |2.1|
|userTags \(可选\)|List|query|用户标签| |2.1|
