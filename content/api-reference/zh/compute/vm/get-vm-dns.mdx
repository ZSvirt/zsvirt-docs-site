## API返回
返回示例

```
{
  "dnsList": [
    "8.8.8.8"
  ]
}
```

|名字|类型|描述|起始版本|
|---|---|---|----|
|dnsList|List|DNS列表|4.10.10|
|success|boolean| |4.10.10|
|vmDnsList|List|详情参考[vmDnsList](#p_tlh_1xv_dfc)|4.10.10|
|error|ErrorCode|错误码，若不为null，则表示操作失败, 操作成功时该字段为null。 详情参考[error](#p_ir4_1xv_dfc)|4.10.10|

### vmDnsList
|名字|类型|描述|起始版本|
|---|---|---|----|
|vmInstanceUuid|String|虚拟机UUID|4.10.10|
|vmNicUuid|String|虚拟机网卡UUID|4.10.10|
|dns|String|DNS地址|4.10.10|
|ipVersion|Integer|IP协议号|4.10.10|
|createDate|Timestamp|创建时间|4.10.10|
|lastOpDate|Timestamp|最后一次修改时间|4.10.10|

### error
|名字|类型|描述|起始版本|
|---|---|---|----|
|code|String|错误码号，错误的全局唯一标识，例如SYS.1000, HOST.1001|0.6|
|description|String|错误的概要描述|0.6|
|details|String|错误的详细信息|0.6|
|elaboration|String|保留字段，默认为null|0.6|
|opaque|LinkedHashMap|保留字段，默认为null|0.6|
|cause|ErrorCode|根错误，引发当前错误的源错误，若无原错误，该字段为null|0.6|
