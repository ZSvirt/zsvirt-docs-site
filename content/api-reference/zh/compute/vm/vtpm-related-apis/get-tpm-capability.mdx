---
title: "获取TPM详情数据"
---

<APIPage method="GET" path="/v1/tpms/capability">

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/tpms/capability?vmInstanceUuid=ff01ec80fd11327cba7519b66119d900
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|tpmUuid \(可选\)|String|query|TPM UUID| |5.0.0|
|vmInstanceUuid \(可选\)|String|query|虚拟机 UUID| |5.0.0|
|systemTags \(可选\)|List|query|系统标签| |5.0.0|
|userTags \(可选\)|List|query|用户标签| |5.0.0|

|名字|类型|描述|起始版本|
|---|---|---|----|
|success|boolean|获取是否成功|5.0.0|
|inventory|TpmCapabilityView|详情参考[inventory](#p_ldg_4pf_2jc)|5.0.0|
|error|ErrorCode|详情参考[error](#p_p35_npf_2jc)|5.0.0|

### inventory
|名字|类型|描述|起始版本|
|---|---|---|----|
|uuid|String|TPM UUID|5.0.0|
|name|String|TPM 资源名称|5.0.0|
|vmInstanceUuid|String|虚拟机 UUID|5.0.0|
|createDate|Timestamp|创建时间|5.0.0|
|lastOpDate|Timestamp|最后一次修改时间|5.0.0|
|edkVersion|String|EDK 套件版本|5.0.0|
|swtpmVersion|String|SWTPM 版本|5.0.0|
|resetTpmAfterVmCloneConfig|boolean|是否在虚拟机克隆后重置 TPM 状态的配置|5.0.0|
|fileRefs|List|详情参考[fileRefs](#p_ix1_4pf_2jc)|5.0.0|

### fileRefs
|名字|类型|描述|起始版本|
|---|---|---|----|
|uuid|String|相关文件 UUID|5.0.0|
|vmInstanceUuid|String|虚拟机 UUID|5.0.0|
|hostUuid|String|主机 UUID|5.0.0|
|type|String|文件类型, 按用途分类, 可能是 NvRam 或者 TpmState|5.0.0|
|path|String|主机侧相关文件或目录的路径|5.0.0|
|createDate|Timestamp|创建时间|5.0.0|
|lastOpDate|Timestamp|最后一次修改时间|5.0.0|

### error
|名字|类型|描述|起始版本|
|---|---|---|----|
|code|String|错误码号，错误的全局唯一标识，例如SYS.1000, HOST.1001|0.6|
|description|String|错误的概要描述|0.6|
|details|String|错误的详细信息|0.6|
|elaboration|String|保留字段，默认为null|0.6|
|opaque|LinkedHashMap|保留字段，默认为null|0.6|
|cause|ErrorCode|根错误，引发当前错误的源错误，若无原错误，该字段为null|0.6|
