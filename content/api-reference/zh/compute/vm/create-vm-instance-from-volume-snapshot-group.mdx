```
Authorization: OAuth the-session-uuid
```

  "params": {
    "name": "vm1",
    "description": "this is a vm",
    "instanceOfferingUuid": "5dda0d1013a433e9959967199f819c60",

      "5fc19e24bedc32f58116ce6d63247f1a"

上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>
