title: "从元数据注册虚拟机"
---

<APIPage method="POST" path="/v1/vm-instances/metadata/register">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "metadataPath": "/mnt/ps/vm-metadata/ff01ec80fd11327cba7519b66119d900.vmmeta",
    "primaryStorageUuid": "ff0359abb8443d2f8077cc368afa7c00",
    "zoneUuid": "ff0c268342c535aabf273d41a2be1d00",
    "clusterUuid": "ff0bcb94de7a3567b641d3fde2329d00",
    "hostUuid": "ff0192fa70113da886101145c084bd00",
    "name": "my-restored-vm"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中`systemTags`、`userTags`字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"metadataPath":"/mnt/ps/vm-metadata/ff01ec80fd11327cba7519b66119d900.vmmeta","primaryStorageUuid":"ff0359abb8443d2f8077cc368afa7c00","zoneUuid":"ff0c268342c535aabf273d41a2be1d00","clusterUuid":"ff0bcb94de7a3567b641d3fde2329d00","hostUuid":"ff0192fa70113da886101145c084bd00","name":"my-restored-vm"}}' \
http://localhost:8080/zstack/v1/vm-instances/metadata/register
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|metadataPath|String|body\(包含在`params`结构中\)|元数据文件在数据存储上的路径| |5.0.0|
|primaryStorageUuid|String|body\(包含在`params`结构中\)|目标数据存储UUID| |5.0.0|
|zoneUuid|String|body\(包含在`params`结构中\)|数据中心UUID| |5.0.0|
|clusterUuid|String|body\(包含在`params`结构中\)|集群UUID| |5.0.0|
|hostUuid \(可选\)|String|body\(包含在`params`结构中\)|物理机UUID| |5.0.0|
|name \(可选\)|String|body\(包含在`params`结构中\)|虚拟机名称| |5.0.0|
|tagUuids \(可选\)|List|body\(包含在`params`结构中\)|标签UUID列表| |5.0.0|
|systemTags \(可选\)|List|body|系统标签| |5.0.0|
|userTags \(可选\)|List|body|用户标签| |5.0.0|
