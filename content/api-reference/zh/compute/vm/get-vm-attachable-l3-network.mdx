<APIPage method="GET" path="/v1/vm-instances/{vmInstanceUuid}/l3-networks-candidates">

获取一个虚拟机可加载分布式端口组列表。

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth: YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/vm-instances/16bf0d8cb1e346568e4cfba52c70a9c2/l3-networks-candidates
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|vmInstanceUuid|String|url|虚拟机UUID| |0.6|
|systemTags \(可选\)|List|query|系统标签| |0.6|
|userTags \(可选\)|List|query|用户标签| |0.6|
