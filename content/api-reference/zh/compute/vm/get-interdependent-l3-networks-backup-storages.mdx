---
title: "获取内部依赖的分布式端口组或者镜像存储信息"
---

<APIPage method="GET" path="/v1/backupStorage-l3networks/dependencies">

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/backupStorage-l3networks/dependencies?zoneUuid=05861219da2d3b79ae38c89be62edb97&backupStorageUuid=1ab2d87b28683da09130464e62f13bb6
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|zoneUuid|String|query|数据中心UUID| |0.6|
|backupStorageUuid \(可选\)|String|query|镜像存储UUID| |0.6|
|l3NetworkUuids \(可选\)|List|query|分布式端口组UUID| |0.6|
|systemTags \(可选\)|List|query|系统标签| |0.6|
|userTags \(可选\)|List|query|用户标签| |0.6|
