---
title: "删除虚拟机Hostname"
---

<APIPage method="DELETE" path="/v1/vm-instances/{uuid}/hostnames">

删除虚拟机的Hostname。

<Callout type="info">
该删除操作仅仅是删除配置在数据库中以及DHCP服务器上的虚拟机hostname，无法改变虚拟机内部手动配置的hostname。
</Callout>

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X DELETE http://localhost:8080/zstack/v1/vm-instances/6932e80b9bfe39d191e96a237ad35814/hostnames
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|虚拟机UUID| |0.6|
|deleteMode\(可选\)|String|body| | |0.6|
|systemTags \(可选\)|List|body|系统标签| |0.6|
|userTags \(可选\)|List|body|用户标签| |0.6|

## API返回
该API成功时返回一个空的JSON结构**`{}`**，出错时返回的JSON结构包含一个error字段，例如：

```
{
  "error": {
    "code": "SYS.1001",
    "description": "A message or a operation timeout",
    "details": "Create VM on KVM timeout after 300s"
  }
}
```
