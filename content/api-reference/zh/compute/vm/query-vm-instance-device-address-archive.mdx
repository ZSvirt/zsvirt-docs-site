```
-H "Authorization: OAuth YOUR_SESSION_UUID" \

```

可查询字段

运行CLI命令行工具，输入`QueryVmInstanceDeviceAddressArchive`并按Tab键查看所有可查询字段以及可跨表查询的资源名。

|名字|类型|描述|起始版本|

|名字|类型|描述|起始版本|
