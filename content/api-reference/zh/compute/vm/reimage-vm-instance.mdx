---
title: "重置虚拟机"
---

<APIPage method="PUT" path="/v1/vm-instances/{vmInstanceUuid}/actions">

将一个虚拟机的根硬盘重置为最初状态。该API只对从非ISO创建出的虚拟机有效。

**Warning:** 执行该API后，虚拟机根硬盘重置成最初创建的状态，意味着所有后续写入的数据都会被丢失，该操作不可逆！

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "reimageVmInstance": {},
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"reimageVmInstance":{}}' \
http://localhost:8080/zstack/v1/vm-instances/f38615d717a438c39eca3b8b560a00ef/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|vmInstanceUuid|String|url|虚拟机UUID| |0.6|
|systemTags \(可选\)|List|body|系统标签| |0.6|
|userTags \(可选\)|List|body|用户标签| |0.6|
