<Callout type="info">
-   ZSvirt克隆虚拟机时支持支持亲和组功能，**SystemTags**增加**affinityGroup**选项。
    -   选项格式为：`affinityGroupUuid::UUID`
    -   例如：`affinityGroupUuid::5fd71606d5af451d981413f35367a8d6`
-   ZSvirt克隆虚拟机时支持指定硬盘置备方式，**SystemTags**增加**volumeProvisioningStrategy**选项，使用 **rootVolumeSystemTags**参数来传递 SystemTag。
    -   选项格式为：`volumeProvisioningStrategy::ThinProvisioning, volumeProvisioningStrategy::ThickProvisioning`
    -   例如：`volumeProvisioningStrategy::ThinProvisioning, volumeProvisioningStrategy::ThickProvisioning`
</Callout>

## API返回
<Callout type="info">
该API调用成功后，返回success为**true**。成功克隆的虚拟机数量由`numberOfClonedVm`返回。实际过程中，由于资源限制，可能存在部分成功、部分失败的情况。每台虚拟机的克隆失败原因存放在`inventories`里面的**error**字段。
</Callout>
