title: "重启虚拟机"

<APIPage method="PUT" path="/v1/vm-instances/{uuid}/actions">

重启一个虚拟机。

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "rebootVmInstance": {},
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"rebootVmInstance":{}}' \
http://localhost:8080/zstack/v1/vm-instances/5bae2edd13e73805a552df9a2aa8d4c9/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|虚拟机UUID| |0.6|
|systemTags \(可选\)|List|body|系统标签| |0.6|
|userTags \(可选\)|List|body|用户标签| |0.6|
