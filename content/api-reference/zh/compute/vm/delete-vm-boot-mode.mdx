---
title: "删除虚拟机启动模式"
---

<APIPage method="DELETE" path="/v1/vm-instances/{uuid}/bootmode">

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X DELETE http://localhost:8080/zstack/v1/vm-instances/fd62d4c5cdc6365889ac4cf477339c10/bootmode
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|资源的UUID，唯一标示该资源| |4.2.0|
|deleteMode \(可选\)|String|body| | |4.2.0|
|systemTags \(可选\)|List|body| | |4.2.0|
|userTags \(可选\)|List|body| | |4.2.0|

## API返回
该API成功时返回一个空的JSON结构`{}`，出错时返回的JSON结构包含一个error字段，例如：

```
{
  "error": {
    "code": "SYS.1001",
    "description": "A message or a operation timeout",
    "details": "Create VM on KVM timeout after 300s"
  }
}
```
