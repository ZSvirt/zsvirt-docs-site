title: "获取ISO可加载虚拟机列表"

<APIPage method="GET" path="/v1/images/iso/{isoUuid}/vm-candidates">

获取一个ISO可以加载到的虚拟机列表。

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/images/iso/282f9e4e21a43ebd82296f5f9a31e6a0/vm-candidates
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|isoUuid|String|url|ISO UUID| |0.6|
|systemTags \(可选\)|List|query|系统标签| |0.6|
|userTags \(可选\)|List|query|用户标签| |0.6|
