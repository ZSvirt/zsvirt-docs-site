title: "获取目的地列表"
---

<APIPage method="GET" path="/v1/vm-instances/candidate-destinations">

获取可以创建指定虚拟机参数的目的数据中心、集群、主机。用户可以使用该API，通过指定虚拟机参数获得可以创建满足参数虚拟机的目的地。

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/vm-instances/candidate-destinations?\
instanceOfferingUuid=0a3d761b0e3031a9b3c62f418fdade09&imageUuid=f6885d39912b347880517a58a9f5ad5b\
&l3NetworkUuids=51f30f4fcd3b3a0da2998b37f1a8d8a3\
&dataDiskOfferingUuids=cf8aa933d58230ee80a4181a66772d0b\
&dataDiskOfferingUuids=6a5ea214bc88372285ff3c301d64428c&clusterUuid=1f6b12b24aa03d4bb57f84a2df4a03f4
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|instanceOfferingUuid\(可选\)|String|query|计算规格UUID| |0.6|
|imageUuid|String|query|镜像UUID| |0.6|
|l3NetworkUuids|List|query|分布式端口组列表| |0.6|
|rootDiskOfferingUuid \(可选\)|String|query|根硬盘规格。仅在**imageUuid**指定的镜像是ISO时需要指定| |0.6|
|dataDiskOfferingUuids \(可选\)|List|query|硬盘规格列表| |0.6|
|zoneUuid \(可选\)|String|query|数据中心UUID| |0.6|
|clusterUuid \(可选\)|String|query|集群UUID| |0.6|
|defaultL3NetworkUuid \(可选\)|String|query|默认分布式端口组UUID| |0.6|
|cpuNum \(可选\)|int|query|CPU数目| |3.10.0|
|memorySize \(可选\)|long|query|内存大小, 单位Byte| |3.10.0|
|systemTags \(可选\)|List|query|系统标签| |0.6|
|userTags \(可选\)|List|query|用户标签| |0.6|
|rootDiskSize \(可选\)|Long|query|根硬盘规格大小。仅在**imageUuid**指定的镜像是ISO时且**rootDiskOfferingUuid**为空：需要指定| |4.1.2|
