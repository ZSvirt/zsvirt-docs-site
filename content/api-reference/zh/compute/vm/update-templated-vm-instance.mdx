<APIPage method="PUT" path="/v1/vm-instances/templatedVmInstance/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "updateTemplatedVmInstance": {
    "name": "templated-vm",
    "description": "description",
    "cpuNum": 1,
    "memorySize": 1073741824
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中`systemTags`、`userTags`字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"updateTemplatedVmInstance":{"name":"templated-vm","description":"description","cpuNum":1,"memorySize":1073741824}}' \
http://localhost:8080/zstack/v1/vm-instances/templatedVmInstance/d6d9c2ac923b34cd9c060b6dbb68757c/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|资源的UUID，唯一标示该资源| |4.2.6|
|name \(可选\)|String|body\(包含在`updateTemplatedVmInstance`结构中\)|资源名称| |4.2.6|
|description \(可选\)|String|body\(包含在`updateTemplatedVmInstance`结构中\)|资源的详细描述| |4.2.6|
|cpuNum \(可选\)|Integer|body\(包含在`updateTemplatedVmInstance`结构中\)|CPU数目| |4.2.6|
|memorySize \(可选\)|Long|body\(包含在`updateTemplatedVmInstance`结构中\)|内存大小| |4.2.6|
|systemTags \(可选\)|List|body|系统标签| |4.2.6|
|userTags \(可选\)|List|body|用户标签| |4.2.6|

```

  "inventory": {
    "uuid": "27fc31bc109231a799d943c0cf320f24",

    "lastOpDate": "Nov 14, 2017 10:20:57 PM"
  }
}
```

|名字|类型|描述|起始版本|
|---|---|---|----|
|success|boolean| |4.2.6|
|inventory|TemplatedVmInstanceInventory|详情参考[inventory](#p_umf_lvg_fcc)|4.2.6|
|error|ErrorCode|错误码，若不为null，则表示操作失败, 操作成功时该字段为null。 详情参考[error](#p_vl3_lvg_fcc)|4.2.6|

### inventory
|名字|类型|描述|起始版本|
|---|---|---|----|
|uuid|String|资源的UUID，唯一标示该资源|4.2.6|
|name|String|资源名称|4.2.6|
|zoneUuid|String|数据中心UUID|4.2.6|
|createDate|Timestamp|创建时间|4.2.6|
|lastOpDate|Timestamp|最后一次修改时间|4.2.6|

### error
|名字|类型|描述|起始版本|
|---|---|---|----|
|code|String|错误码号，错误的全局唯一标识，例如SYS.1000, HOST.1001|0.6|
|description|String|错误的概要描述|0.6|
|details|String|错误的详细信息|0.6|
|elaboration|String|保留字段，默认为null|0.6|
|opaque|LinkedHashMap|保留字段，默认为null|0.6|
|cause|ErrorCode|根错误，引发当前错误的源错误，若无原错误，该字段为null|0.6|
