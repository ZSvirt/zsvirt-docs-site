---
title: "设置虚拟机启动盘"
---

<APIPage method="PUT" path="/v1/vm-instances/{vmInstanceUuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "setVmBootVolume": {
    "volumeUuid": "5f9b86be026636008999dd6b971a6f18"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"setVmBootVolume":{"volumeUuid":"5f9b86be026636008999dd6b971a6f18"}}' http://localhost:8080/zstack/v1/vm-instances/0352b51de6353d2ea89f2b4ca1c2178c/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|vmInstanceUuid|String|url|虚拟机UUID| |4.2.0|
|volumeUuid|String|body\(包含在**setVmBootVolume**结构中\)|硬盘UUID| |4.2.0|
|systemTags \(可选\)|List|body|系统标签| |4.2.0|
|userTags \(可选\)|List|body|用户标签| |4.2.0|
