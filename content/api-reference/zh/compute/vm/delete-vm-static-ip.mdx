---
title: "删除虚拟机指定IP"
---

<APIPage method="DELETE" path="/v1/vm-instances/{vmInstanceUuid}/static-ips">

删除虚拟机分布式端口组上指定的IP。

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X DELETE http://localhost:8080/zstack/v1/vm-instances/fa0f86bf44593287af480c9151d41d1b/static-ips
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|vmInstanceUuid|String|url|虚拟机UUID| |0.6|
|l3NetworkUuid|String|body|分布式端口组UUID| |0.6|
|deleteMode\(可选\)|String|body| | |0.6|
|staticIp \(可选\)|String|body| | |3.10.0|
|systemTags \(可选\)|List|body|系统标签| |0.6|
|userTags \(可选\)|List|body|用户标签| |0.6|
