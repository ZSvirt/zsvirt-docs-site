title: "设置虚拟机时钟同步"
---

<APIPage method="PUT" path="/v1/vm-instances/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "setVmClockTrack": {
    "track": "guest",
    "syncAfterVMResume": true,
    "intervalInSeconds": 60
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT '{"setVmClockTrack":{"track":"guest","syncAfterVMResume":true,"intervalInSeconds":60.0}}' http://localhost:8080/zstack/v1/vm-instances/cc0a313462243900b6c843ff427b7f0e/actions
```
