---
title: "设置虚拟机启动模式"
---

<APIPage method="PUT" path="/v1/vm-instances/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "setVmBootMode": {
    "bootMode": "Legacy"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"setVmBootMode":{"bootMode":"Legacy"}}' http://localhost:8080/zstack/v1/vm-instances/aeba3a383f02352bb855f15f73e3840d/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|资源的UUID，唯一标示该资源| |4.2.0|
|bootMode|String|body\(包含在**setVmBootMode**结构中\)| | |4.2.0|
|systemTags \(可选\)|List|body| | |4.2.0|
|userTags \(可选\)|List|body| | |4.2.0|

## API返回
该API成功时返回一个空的JSON结构**`{}`**，出错时返回的JSON结构包含一个error字段，例如：

```
{
  "error": {
    "code": "SYS.1001",
    "description": "A message or a operation timeout",
    "details": "Create VM on KVM timeout after 300s"
  }
}
```
