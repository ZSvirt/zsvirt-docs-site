---
title: "热迁移虚拟机"
---

<APIPage method="PUT" path="/v1/vm-instances/{vmInstanceUuid}/actions">

将虚拟机热迁移至另一个主机。

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "migrateVm": {
    "hostUuid": "7571fb72e52b3fcab1a6992e7eef4cce",
    "migrateFromDestination": false,
    "allowUnknown": false,
    "downTime": 300
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \-X PUT -d '{"migrateVm":{"hostUuid":"7571fb72e52b3fcab1a6992e7eef4cce","migrateFromDestination":false,"allowUnknown":false,"downTime":300}}' \
http://localhost:8080/zstack/v1/vm-instances/c53c9b6235703b8ab96c1cc35859242d/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|vmInstanceUuid|String|url|虚拟机UUID| |0.6|
|hostUuid \(可选\)|String|body\(包含在**migrateVm**结构中\)|主机UUID| |0.6|
|migrateFromDestination \(可选\)|Boolean|body\(包含在**migrateVm**结构中\)|从迁移目的主机器发起迁移命令| |2.3|
|allowUnknown \(可选\)|boolean|body\(包含在**migrateVm**结构中\)|允许未知状态的虚拟机| |4.6.21|
|strategy \(可选\)|String|body\(包含在**migrateVm**结构中\)| |auto-converge|4.6.21|
|systemTags \(可选\)|List|body| | |0.6|
|userTags \(可选\)|List|body|用户标签| |0.6|
|downTime \(可选\)|Integer|body\(包含在**migrateVm**结构中\)|热迁移主机停机时间| |4.6.21|
