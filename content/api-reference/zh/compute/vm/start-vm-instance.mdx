title: "虚拟机开机"
---

<APIPage method="PUT" path="/v1/vm-instances/{uuid}/actions">

将一个虚拟机开机。

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "startVmInstance": {},
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"startVmInstance":{}}' \
http://localhost:8080/zstack/v1/vm-instances/647db3dbf974372ead60d4ba1c9efac3/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|虚拟机UUID| |0.6|
|clusterUuid \(可选\)|String|body\(包含在**startVmInstance**结构中\)|集群UUID。若指定，虚拟机将在该集群内开机| |0.6|
|hostUuid \(可选\)|String|body\(包含在**startVmInstance**结构中\)|主机UUID。若指定，虚拟机将在该主机上开机。该字段覆盖**clusterUuid**字段| |0.6|
|systemTags \(可选\)|List|body|系统标签| |0.6|
|userTags \(可选\)|List|body|用户标签| |0.6|
