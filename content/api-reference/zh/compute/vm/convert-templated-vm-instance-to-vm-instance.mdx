---
title: "虚拟机模板转换为虚拟机"
---

<APIPage method="POST" path="/v1/vm-instances/{templatedVmInstanceUuid}/convert-to-vmInstance?TemplatedVmInstanceUuid={TemplatedVmInstanceUuid}">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "name": "test-vm"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"name":"test-vm"}}' \
http://localhost:8080/zstack/v1/vm-instances/60ac0f41f16031b19ab7666ab610466a/convert-to-vmInstance
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|TemplatedVmInstanceUuid|String|url|虚拟机模板UUID| |4.2.6|
|name|String|body\(包含在`params`结构中\)|虚拟机名称| |4.2.6|
|systemTags \(可选\)|List|body|系统标签| |4.2.6|
|userTags \(可选\)|List|body|用户标签| |4.2.6|
|resetTpm \(可选\)|Boolean|body\(包含在`params`结构中\)|转换成虚拟机后是否重置 TPM 状态| |5.0.0|
