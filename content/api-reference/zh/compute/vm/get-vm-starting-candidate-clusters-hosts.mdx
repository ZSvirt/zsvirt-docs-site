---
title: "获取虚拟机可启动目的地列表"
---

<APIPage method="GET" path="/v1/vm-instances/{uuid}/starting-target-hosts">

获取一个停止的虚拟机可以启动的集群、主机列表。用户可以用该API判断一个停止的虚拟机可以在哪些集群、主机上启动。

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth: YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/vm-instances/d8cfc97f5099454bb3eed367a79d4e4c/starting-target-hosts
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|虚拟机UUID| |0.6|
|systemTags \(可选\)|List|query|系统标签| |0.6|
|userTags \(可选\)|List|query|用户标签| |0.6|
