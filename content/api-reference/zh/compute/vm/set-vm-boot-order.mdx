---
title: "指定虚拟机启动设备"
---

<APIPage method="PUT" path="/v1/vm-instances/{uuid}/actions">

指定一个虚拟机的启动设备。

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "setVmBootOrder": {
    "bootOrder": [
      "CdRom",
      "HardDisk"
    ]
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"setVmBootOrder":{"bootOrder":["CdRom","HardDisk"]}}' \
http://localhost:8080/zstack/v1/vm-instances/f757785b3980305095c89eb2b4e1b785/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|虚拟机UUID| |0.6|
|bootOrder \(可选\)|List|body\(包含在**setVmBootOrder**结构中\)|启动设备。**CdRom**：光驱，**HardDisk**：硬盘，**Network**：网络。若该字段不指定，则表示使用系统默认启动设备顺序\(HardDisk, CdRom, Network\)| |3.8.0|
|systemTags \(可选\)|List|body|系统标签| |0.6|
|userTags \(可选\)|List|body|用户标签| |0.6|
