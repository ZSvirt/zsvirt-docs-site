title: "加载网络到网卡"

<APIPage method="POST" path="/v1/nics/{vmNicUuid}/l3-networks/{l3NetworkUuid}">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {},
  "systemTags": [],
  "userTags": []
}
```

上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{}}' \
http://localhost:8080/zstack/v1/nics/573a061841c833f098482a47474a4514/l3-networks/8ad81f74fbf539d98c542fa94ecfa7d9
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|vmNicUuid|String|url|虚拟机网卡UUID| |3.1.0|
|l3NetworkUuid|String|url|分布式端口组UUID| |3.1.0|
|staticIp \(可选\)|String|body\(包含在**params**结构中\)|指定分配给虚拟机的IP地址| |3.1.0|
|systemTags \(可选\)|List|body| | |3.1.0|
|userTags \(可选\)|List|body| | |3.1.0|
