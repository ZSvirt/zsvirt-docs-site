---
title: "加载ISO到虚拟机"
---

<APIPage method="POST" path="/v1/vm-instances/{vmInstanceUuid}/iso/{isoUuid}">

加载一个ISO镜像到Running或Stopped的虚拟机。

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST http://localhost:8080/zstack/v1/vm-instances/b1105c5dd00f323d99aa182dee237628/iso/8f36a77ab76e3425a571a7f75fca2d69
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|vmInstanceUuid|String|url|虚拟机UUID| |0.6|
|isoUuid|String|url|ISO UUID| |0.6|
|systemTags \(可选\)|List|body|系统标签| |0.6|
|userTags \(可选\)|List|body|用户标签| |0.6|
