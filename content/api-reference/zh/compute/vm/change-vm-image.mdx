---
title: "修改虚拟机根硬盘"
---

<APIPage method="PUT" path="/v1/vm-instances/{vmInstanceUuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "changeVmImage": {
    "imageUuid": "dbfd52c2f87c39cda8c8945fca8d6a5a"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"changeVmImage":{"imageUuid":"dbfd52c2f87c39cda8c8945fca8d6a5a"}}' \
http://localhost:8080/zstack/v1/vm-instances/af9e42b52dc836dfac3ee89b08c47488/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|vmInstanceUuid|String|url|虚拟机UUID| |2.2|
|imageUuid|String|body\(包含在**changeVmImage**结构中\)|镜像UUID| |2.2|
|systemTags \(可选\)|List|body|系统标签| |2.2|
|userTags \(可选\)|List|body|用户标签| |2.2|
|resourceUuid \(可选\)|String|body\(包含在**changeVmImage**结构中\)| | |0.6|
|tagUuids \(可选\)|List|body\(包含在**changeVmImage**结构中\)|标签UUID列表| |0.6|

<Callout type="info">
-   ZSvirt修改虚拟机根硬盘时支持指定根硬盘所在的分布式存储池，**SystemTags**增加**rootPoolName**选项，使用 **rootPoolName**参数来传递 SystemTag。
</Callout>
    -   选项格式为：`ceph::rootPoolName::xxx, 其中xxx代表池名称`
    -   例如：`ceph::rootPoolName::pri-v-r-26e11ca6814d4e1ba504d845f7848db3`
