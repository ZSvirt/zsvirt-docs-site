title: "从根硬盘创建根硬盘镜像"
---

<APIPage method="POST" path="/v1/images/root-volume-templates/from/volumes/{rootVolumeUuid}">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "name": "My Root Volume Template",
    "backupStorageUuids": [
      "a3cb55d45fb63d1da4911b9d16273a55"
    ],
    "platform": "Linux",
    "system": false
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"name":"My Root Volume Template","backupStorageUuids":["a3cb55d45fb63d1da4911b9d16273a55"],"platform":"Linux","system":false}}' http://localhost:8080/zstack/v1/images/root-volume-templates/from/volumes/3bfc6f9eaf243299b8515382310be47b
```

<Callout type="info">
-   ZSvirt从根硬盘创建根硬盘镜像时支持从虚拟机拷贝GuestTools标签值到镜像， 使用该镜像创建虚拟机时，从镜像拷贝GuestTools标签值到新虚拟机。**SystemTags**增加**GuestTools**选项。
    -   选项格式为：`GuestTools::TOOLS_VERSION`，其中TOOLS\_VERSION初值为1.0.0，未来随着工具版本的提升，这个值会随之变化。
    -   例如：`GuestTools::1.0.0`
    -   补充说明：虚拟机根硬盘创建镜像时，从虚拟机拷贝GuestTools标签值到镜像。
</Callout>

    "format": "raw",

|名字|类型|描述|起始版本|
|---|---|---|----|
|error|ErrorCode|错误码，若不为null，则表示操作失败, 操作成功时该字段为null。 详情参考[error](#p_xkr_2n2_l1b)|0.6|
|inventory|ImageInventory|详情参考[inventory](#p_n5t_4n2_l1b)|0.6|

### error
|名字|类型|描述|起始版本|
|---|---|---|----|
|code|String|错误码号，错误的全局唯一标识，例如SYS.1000, HOST.1001|0.6|
|description|String|错误的概要描述|0.6|
|details|String|错误的详细信息|0.6|
|elaboration|String|保留字段，默认为null|0.6|
|opaque|LinkedHashMap|保留字段，默认为null|0.6|
|cause|ErrorCode|根错误，引发当前错误的源错误，若无原错误，该字段为null|0.6|

### inventory
|名字|类型|描述|起始版本|
|---|---|---|----|
|uuid|String|资源的UUID，唯一标示该资源|0.6|
|name|String|资源名称|0.6|
|description|String|资源的详细描述|0.6|
|state|String|镜像的启动状态|4.0.0|

|mediaType|String|镜像的类型|4.0.0|
