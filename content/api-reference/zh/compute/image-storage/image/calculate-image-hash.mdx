---
title: "计算镜像的MD5值"
---

<APIPage method="PUT" path="/v1/images/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "calculateImageHash": {
    "backupStorageUuid": "0eeaa5988c743c638485304f3d1f867e",
    "algorithm": "MD5"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"calculateImageHash":{"backupStorageUuid":"0eeaa5988c743c638485304f3d1f867e","algorithm":"MD5"}}' \
http://localhost:8080/zstack/v1/images/383bcf0b1515369a8169b66a91de1e00/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|资源的UUID，唯一标示该资源| |4.1.0|
|backupStorageUuid|String|body\(包含在**calculateImageHash**结构中\)|镜像存储UUID| |4.1.0|
|algorithm \(可选\)|String|body\(包含在**calculateImageHash**结构中\)| | |4.1.0|
|systemTags \(可选\)|List|body|系统标签| |4.1.0|
|userTags \(可选\)|List|body|用户标签| |4.1.0|
