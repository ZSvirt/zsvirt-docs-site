---
title: "从硬盘创建数据硬盘镜像"
---

<APIPage method="POST" path="/v1/images/data-volume-templates/from/volumes/{volumeUuid}">

Hearders

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "name": "My Data Volume Template",
    "backupStorageUuids": [
      "7fd08286addc4b388fac61935892acd7"
    ]
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"name":"My Data Volume Template","backupStorageUuids":["08e337886b873e8685991d1c7ba4d1ab"]}}' \
http://localhost:8080/zstack/v1/images/data-volume-templates/from/volumes/4c941eb9faeb3976803fce2f3609a475
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|name|String|body\(包含在**params**结构中\)|数据硬盘镜像名称| |0.6|
|description \(可选\)|String|body\(包含在**params**结构中\)|数据硬盘镜像的详细描述| |0.6|
|volumeUuid|String|body\(包含在**params**结构中\)|起始硬盘UUID| |0.6|
|backupStorageUuids \(可选\)|List|body\(包含在**params**结构中\)|镜像仓库UUID列表| |0.6|
|resourceUuid \(可选\)|String|body\(包含在**params**结构中\)|数据硬盘镜像UUID。若指定，数据硬盘镜像会使用该字段值作为UUID。| |0.6|
|systemTags \(可选\)|List|body|系统标签| |0.6|
|userTags \(可选\)|List|body|用户标签| |0.6|
