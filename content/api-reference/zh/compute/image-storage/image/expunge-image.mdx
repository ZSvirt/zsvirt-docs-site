---
title: "彻底删除镜像"
---

<APIPage method="PUT" path="/v1/images/{imageUuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "expungeImage": {
    "backupStorageUuids": [
      "ef3843bdde80427e9c8c0d4f05aa5cde"
    ]
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"expungeImage":{"backupStorageUuids":["3be136c8d8b8323bb94b8464aae4b0a7"]}}' \
http://localhost:8080/zstack/v1/images/4dcddfadcd113b5f89f181c4f4a080c7/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|Uuid|String|body\(包含在**params**结构中\)|资源的UUID，唯一标示该资源| |0.6|
|imageUuid|String|url|镜像UUID| |0.6|
|backupStorageUuids \(可选\)|List|body\(包含在**params**结构中\)|镜像仓库UUID列表| |0.6|
|systemTags \(可选\)|List|body|系统标签| |0.6|
|userTags \(可选\)|List|body|用户标签| |0.6|

## API返回
该API成功时返回一个空的JSON结构**`{}`**，出错时返回的JSON结构包含一个error字段，例如：

```
{
  "error": {
    "code": "SYS.1001",
    "description": "A message or a operation timeout",
    "details": "Create VM on KVM timeout after 300s"
  }
}
```
