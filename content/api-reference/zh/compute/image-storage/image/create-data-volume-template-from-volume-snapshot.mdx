---
title: "从硬盘快照创建数据硬盘镜像"
---

<APIPage method="POST" path="/v1/images/data-volume-templates/from/volume-snapshots/{snapshotUuid}">

从指定的硬盘快照创建出一个数据硬盘镜像。

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "name": "My Data Volume Template",
    "backupStorageUuids": [
      "dbf107f8efa531f786f243850499e010"
    ],
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"name":"My Data Volume Template","backupStorageUuids":["dbf107f8efa531f786f243850499e010"]}}' \
http://localhost:8080/zstack/v1/images/data-volume-templates/from/volume-snapshots/58976137bf95309692762077cd7077e3
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|snapshotUuid|String|url|快照UUID| |0.6|
|name|String|body\(包含在**params**结构中\)|数据硬盘镜像名称| |0.6|
|description \(可选\)|String|body\(包含在**params**结构中\)|数据硬盘镜像的详细描述| |0.6|
|backupStorageUuids|List|body\(包含在**params**结构中\)|镜像仓库UUID列表| |0.6|
|resourceUuid \(可选\)|String|body\(包含在**params**结构中\)|数据硬盘镜像UUID。若指定，数据硬盘镜像会使用该字段值作为UUID| |0.6|
|tagUuids \(可选\)|List|body\(包含在**params**结构中\)|标签UUID列表| | |
|systemTags \(可选\)|List|body|系统标签| |0.6|
|userTags \(可选\)|List|body|用户标签| |0.6|

|名字|类型|描述|起始版本|
|---|---|---|----|

|inventory|ImageInventory|详情参考[inventory](#p_ixz_nck_l1b)|0.6|
|failures|List|详情参考[failures](#p_epn_4ck_l1b)|0.6|

|elaboration|String|保留字段，默认为null|0.6|
