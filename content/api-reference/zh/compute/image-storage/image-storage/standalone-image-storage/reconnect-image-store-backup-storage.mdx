---
title: "重连本地镜像仓库"
---

<APIPage method="PUT" path="/v1/backup-storage/image-store/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "reconnectImageStoreBackupStorage": {},
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中`systemTags`、`userTags`字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"reconnectImageStoreBackupStorage":{}}' \
http://localhost:8080/zstack/v1/backup-storage/image-store/a6d3a3c8a24b3f669fcecbb7bc6798ca/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|本地镜像仓库的UUID| |1.6|
|systemTags \(可选\)|List|body\(包含在**params**结构中\)|系统标签| |1.6|
|userTags \(可选\)|List|body\(包含在**params**结构中\)|用户标签| |1.6|
