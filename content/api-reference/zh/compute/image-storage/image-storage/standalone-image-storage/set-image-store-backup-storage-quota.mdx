---
title: "设置镜像仓库配额"
---

<APIPage method="PUT" path="/v1/backup-storage/image-store/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "setImageStoreBackupStorageQuota": {
    "uuids": [
      "ff0e1223a4983a10b94369dc6b93ce00"
    ],
    "maxCapacity": 1099511627776
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中`systemTags`、`userTags`字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"setImageStoreBackupStorageQuota":{"uuids":["ff0e1223a4983a10b94369dc6b93ce00"],"maxCapacity":1099511627776}}' \
http://localhost:8080/zstack/v1/backup-storage/image-store/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuids \(可选\)|List|body\(包含在`setImageStoreBackupStorageQuota`结构中\)| | |0.6|
|maxCapacity|long|body\(包含在`setImageStoreBackupStorageQuota`结构中\)| | |0.6|
|systemTags \(可选\)|List|body|系统标签| |0.6|
|userTags \(可选\)|List|body|用户标签| |0.6|

## API返回
该API成功时返回一个空的JSON结构`{}`，出错时返回的JSON结构包含一个error字段，例如：

```
{
  "error": {
    "code": "SYS.1001",
    "description": "A message or a operation timeout",
    "details": "Create VM on KVM timeout after 300s"
  }
}
```
