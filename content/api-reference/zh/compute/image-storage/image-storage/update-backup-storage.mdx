---
title: "更新镜像存储信息"
---

<APIPage method="PUT" path="/v1/backup-storage/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "updateBackupStorage": {
    "name": "New Name"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中`systemTags`、`userTags`字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"updateBackupStorage":{"name":"New Name"}}' \
http://localhost:8080/zstack/v1/backup-storage/72f0f262f3323515b177d148ad1efb66/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|指定目标镜像仓库的UUID| |0.6|
|name \(可选\)|String|body\(包含在**updateBackupStorage**结构中\)|镜像仓库的新名称| |0.6|
|description \(可选\)|String|body\(包含在**updateBackupStorage**结构中\)|镜像仓库新的详细描述| |0.6|
|systemTags \(可选\)|List|body|系统标签| |0.6|
|userTags \(可选\)|List|body|用户标签| |0.6|

## API返回
返回示例

```
{
  "inventory": {
    "name": "New Name",
    "description": "Public Backup Storage",
    "totalCapacity": 1073741824.0,
    "availableCapacity": 968884224.0,
    "type": "Ceph",
    "state": "Enabled",
    "status": "Connected",
    "createDate": "Jun 7, 2017 9:20:36 PM",
    "lastOpDate": "Jun 7, 2017 9:20:36 PM",
    "attachedZoneUuids": [
      "90b2283f6c454453923dcf2f8e188330"
    ]
  }
}
```

|名字|类型|描述|起始版本|
|---|---|---|----|
|error|ErrorCode|错误码，若不为null，则表示操作失败, 操作成功时该字段为null。 详情参考[error](#p_gpr_h41_n1b)|0.6|
|inventory|BackupStorageInventory|详情参考[inventory](#p_af5_341_n1b)|0.6|

### error
|名字|类型|描述|起始版本|
|---|---|---|----|
|code|String|错误码号，错误的全局唯一标识，例如SYS.1000, HOST.1001|0.6|
|description|String|错误的概要描述|0.6|
|details|String|错误的详细信息|0.6|
|elaboration|String|保留字段，默认为null|0.6|
|opaque|LinkedHashMap|保留字段，默认为null|0.6|
|cause|ErrorCode|根错误，引发当前错误的源错误，若无原错误，该字段为null|0.6|

|url|String| |0.6|

|totalCapacity|Long| |0.6|

|type|String| |0.6|
|state|String| |0.6|
|status|String| |0.6|
|createDate|Timestamp|创建时间|0.6|
