---
title: "挂载镜像存储至数据中心"
---

<APIPage method="POST" path="/v1/zones/{zoneUuid}/backup-storage/{backupStorageUuid}">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {},
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{}}' http://localhost:8080/zstack/v1/zones/5776b543bc713f6d9abca9cd605c8199/backup-storage/53ef01cbf71d3bd68206908b87e51403
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|zoneUuid|String|url|数据中心UUID| |0.6|
|backupStorageUuid|String|url|镜像存储UUID| |0.6|
|systemTags \(可选\)|List|body|系统标签| |0.6|
|userTags \(可选\)|List|body|用户标签| |0.6|
