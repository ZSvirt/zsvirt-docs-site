---
title: "更新主机Hostname"
---

<APIPage method="PUT" path="/v1/hosts/hostname/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "updateHostname": {
    "hostname": "user"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中`systemTags`、`userTags`字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"updateHostname":{"hostname":"user"}}' \
http://localhost:8080/zstack/v1/hosts/hostname/edd915d52a0c3d108616187f388bf4e7/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|主机UUID| |4.10.20|
|hostname|String|body\(包含在`updateHostname`结构中\)|主机hostname| |4.10.20|
|systemTags \(可选\)|List|body|系统标签| |4.10.20|
|userTags \(可选\)|List|body|用户标签| |4.10.20|
