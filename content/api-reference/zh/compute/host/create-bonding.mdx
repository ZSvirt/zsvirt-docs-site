title: "创建Bond网口"
---

<APIPage method="POST" path="/v1/hosts/bondings">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "hostUuids": [
      "83e1a4a2ca0d3b0e836b032118196455"
    ],
    "type": "LinuxBonding",
    "mode": "802.3ad",
    "xmitHashPolicy": "layer2+3"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"hostUuids":["83e1a4a2ca0d3b0e836b032118196455"],"type":"LinuxBonding","mode":"802.3ad","xmitHashPolicy":"layer2+3"}}' http://localhost:8080/zstack/v1/hosts/bondings
```
