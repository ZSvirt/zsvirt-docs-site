---
title: "获取主机上的任务信息"
---

<APIPage method="GET" path="/v1/hosts/task-details">

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/hosts/task-details
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|hostUuids|List|query|主机UUIDs| |3.6.0|
|systemTags \(可选\)|List|query| | |3.6.0|
|userTags \(可选\)|List|query| | |3.6.0|
|syncSignatures \(可选\)|List|query| | |4.6.0|

## API返回
该API成功时返回一个空的JSON结构`{}`，出错时返回的JSON结构包含一个error字段，例如：

```
{
  "error": {
    "code": "SYS.1001",
    "description": "A message or a operation timeout",
    "details": "Create VM on KVM timeout after 300s"
  }
}
```
