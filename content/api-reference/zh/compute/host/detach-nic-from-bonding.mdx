---
title: "从Bond网口解绑slave"
---

<APIPage method="PUT" path="/v1/hosts/bondings/{uuid}/detach">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "detachNicFromBonding": {
    "slaveUuids": [
      "23ac510ff6a830ac8a52553e86e00b07"
    ],
    "type": "LinuxBonding"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"detachNicFromBonding":{"slaveUuids":["23ac510ff6a830ac8a52553e86e00b07"],"type":"LinuxBonding"}}' \
http://localhost:8080/zstack/v1/hosts/bondings/bee329acc0573a16bc30fafada5a96f6/detach
```

## API返回
该API成功时返回一个空的JSON结构**`{}`**，出错时返回的JSON结构包含一个error字段，例如：

```
{
  "error": {
    "code": "SYS.1001",
    "description": "A message or a operation timeout",
    "details": "Create VM on KVM timeout after 300s"
  }
}
```
