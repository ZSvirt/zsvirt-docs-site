---
title: "更新主机IOMMU启用状态"
---

<APIPage method="PUT" path="/v1/pci-device/hosts/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "updateHostIommuState": {
    "state": "Enabled"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"updateHostIommuState":{"state":"Enabled"}}' \
http://localhost:8080/zstack/v1/pci-device/hosts/7619742c9ff43b898487db33e1f096a4/actions
```
