---
title: "获取PCI设备列表"
---

<APIPage method="GET" path="/v1/vm-instances/{vmInstanceUuid}/candidate-pci-devices">

获取虚拟机可绑定PCI设备列表。

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/vm-instances/517c674367793e7db4f52bfc21839de7/candidate-pci-devices
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|vmInstanceUuid|String|url|虚拟机UUID| |2.1|
|systemTags \(可选\)|List|query| | |2.1|
|userTags \(可选\)|List|query| | |2.1|
|types \(可选\)|List|query| | |2.1|
