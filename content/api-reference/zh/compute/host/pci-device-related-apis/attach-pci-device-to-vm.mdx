---
title: "绑定PCI设备到虚拟机"
---

<APIPage method="POST" path="/v1/pci-device/pci-devices/{pciDeviceUuid}/attach">

绑定PCI设备到虚拟机，管理员可以直接将状态为System、Active的PCI设备绑定到状态为Active、Stop的虚拟机。

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "vmInstanceUuid": "d3f41f8b996b390992cc4607e7bb10dc"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"vmInstanceUuid":"d3f41f8b996b390992cc4607e7bb10dc"}}' \
http://localhost:8080/zstack/v1/pci-device/pci-devices/201b541edbed3dccbebfaa57b3beb9bb/attach
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|pciDeviceUuid|String|url|PCI设备UUID| |2.1|
|vmInstanceUuid|String|body\(包含在**params**结构中\)|虚拟机UUID| |2.1|
|systemTags \(可选\)|List|body| | |2.1|
|userTags \(可选\)|List|body| | |2.1|
