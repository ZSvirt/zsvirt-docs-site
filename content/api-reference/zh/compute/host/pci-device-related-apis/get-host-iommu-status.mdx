---
title: "获取主机lOMMU就绪状态"
---

<APIPage method="GET" path="/v1/pci-device/hosts/{uuid}/status">

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/pci-device/hosts/0ec53c2f753331f1a2c62b378821e9b7/status
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|资源的UUID，唯一标示该资源| |2.1|
|systemTags \(可选\)|List|query| | |2.1|
|userTags \(可选\)|List|query| | |2.1|

## API返回
返回示例

```
{
  "status": "Active"
}
```

|名字|类型|描述|起始版本|
|---|---|---|----|
|success|boolean| |2.1|
|error|ErrorCode|错误码，若不为null，则表示操作失败, 操作成功时该字段为null。 详情参考[error](#p_ahh_xcq_s1b)|2.1|
|status|HostIommuStatusType|详情参考[status](#p_grb_xcq_s1b)|2.1|

### error
|名字|类型|描述|起始版本|
|---|---|---|----|
|code|String|错误码号，错误的全局唯一标识，例如SYS.1000, HOST.1001|2.1|
|description|String|错误的概要描述|2.1|
|details|String|错误的详细信息|2.1|
|elaboration|String|保留字段，默认为null|2.1|
|opaque|LinkedHashMap|保留字段，默认为null|2.1|
|cause|ErrorCode|根错误，引发当前错误的源错误，若无原错误，该字段为null|2.1|

### status
|名字|类型|描述|起始版本|
|---|---|---|----|
|type|String|主机的IOMMU就绪状态，有Active和Inactive两种|2.1|
