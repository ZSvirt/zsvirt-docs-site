---
title: "更新主机启用状态"
---

<APIPage method="PUT" path="/v1/hosts/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "changeHostState": {
    "stateEvent": "enable"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"changeHostState":{"stateEvent":"enable"}}' \
http://localhost:8080/zstack/v1/hosts/70e37940fe263e858a151850a312143f/actions
```
