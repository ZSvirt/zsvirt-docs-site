---
title: "刷新主机Raid信息"
---

<APIPage method="PUT" path="/v1/storage-devices/local-raid/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "refreshLocalRaid": {
    "hostUuid": "36e5bbc506d632a5ac8e474e6d3b0caf"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中`systemTags`、`userTags`字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"refreshLocalRaid":{"hostUuid":"36e5bbc506d632a5ac8e474e6d3b0caf"}}' \
http://localhost:8080/zstack/v1/storage-devices/local-raid/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|hostUuid|String|body\(包含在`refreshLocalRaid`结构中\)|主机UUID| |3.6|
|systemTags \(可选\)|List|body| | |3.6|
|userTags \(可选\)|List|body| | |3.6|
