<APIPage method="GET" path="/v1/storage-devices/local-raid/physical-drives" altPaths={["/v1/storage-devices/local-raid/physical-drives/{uuid}"]}>

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/storage-devices/local-raid/physical-drives
```

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/storage-devices/local-raid/physical-drives/75dae76e484537bbaea154d9348f4e15
```

可查询字段

运行CLI命令行工具，输入`QueryLocalRaidPhysicalDrive`并按Tab键查看所有可查询字段以及可跨表查询的资源名。

|名字|类型|描述|起始版本|

|名字|类型|描述|起始版本|
