<APIPage method="PUT" path="/v1/hosts/power-off/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "powerOffHost": {
    "adminPassword": "password",
    "hostUuids": [
      "ff0192fa70113da886101145c084bd00"
    ],
    "waitTaskCompleted": false
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中`systemTags`、`userTags`字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"powerOffHost":{"adminPassword":"password","hostUuids":["ff0192fa70113da886101145c084bd00"],"waitTaskCompleted":false}}' \
http://localhost:8080/zstack/v1/hosts/power-off/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|adminPassword|String|body\(包含在`powerOffHost`结构中\)| | |0.6|
|hostUuids|List|body\(包含在`powerOffHost`结构中\)| | |0.6|
|waitTaskCompleted \(可选\)|boolean|body\(包含在`powerOffHost`结构中\)| | |0.6|
|maxWaitTime \(可选\)|Long|body\(包含在`powerOffHost`结构中\)| | |0.6|
|systemTags \(可选\)|List|body|系统标签| |0.6|
|userTags \(可选\)|List|body|用户标签| |0.6|
