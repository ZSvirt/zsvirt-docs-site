---
title: "账户组解绑角色"
---

<APIPage method="DELETE" path="/v1/account-groups/{groupUuid}/roles">

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth b86c9016b4f24953a9edefb53ca0678c" \
-X DELETE http://localhost:8080/zstack/v1/account-groups/28c89d7eaf23373baad7e0f8889b2c3d/roles
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|groupUuid|String|url|账户组 UUID| |4.10.0|
|roleUuids|List|body|角色 UUID 列表| |4.10.0|
|systemTags \(可选\)|List|body|系统标签| |4.10.0|
|userTags \(可选\)|List|body|用户标签| |4.10.0|

## API返回
该API成功时返回一个空的JSON结构`{}`，出错时返回的JSON结构包含一个error字段，例如：

```
{
  "error": {
    "code": "SYS.1001",
    "description": "A message or a operation timeout",
    "details": "Create VM on KVM timeout after 300s"
  }
}
```
