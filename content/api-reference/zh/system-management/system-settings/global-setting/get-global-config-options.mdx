---
title: "获取系统参数选项"
---

<APIPage method="GET" path="/v1/global-configurations/{category}/{name}">

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth b86c9016b4f24953a9edefb53ca0678c" \
-X GET http://localhost:8080/zstack/v1/global-configurations/kvm/vm.cpuMode
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|category|String|url| | |4.4.0|
|name|String|url|资源名称| |4.4.0|
|systemTags \(可选\)|List|query|系统标签| |4.4.0|
|userTags \(可选\)|List|query|用户标签| |4.4.0|

## API返回
该API成功时返回一个空的JSON结构`{}`，出错时返回的JSON结构包含一个error字段，例如：

```
{
  "error": {
    "code": "SYS.1001",
    "description": "A message or a operation timeout",
    "details": "Create VM on KVM timeout after 300s"
  }
}
```
