title: "启动PXE服务"
---

<APIPage method="PUT" path="/v1/baremetal/pxeservers/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "startBaremetalPxeServer": {},
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中`systemTags`、`userTags`字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"startBaremetalPxeServer":{}}' \
http://localhost:8080/zstack/v1/baremetal/pxeservers/340b1f6b12ab305aa05c12ded00020e7/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|资源的UUID，唯一标示该资源| |2.6.0|
|systemTags \(可选\)|List|body|系统标签| |2.6.0|
|userTags \(可选\)|List|body|用户标签| |2.6.0|
