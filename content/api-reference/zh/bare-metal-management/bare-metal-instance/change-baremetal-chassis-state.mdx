title: "修改裸金属设备状态"
---

<APIPage method="PUT" path="/v1/baremetal/chassis/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "changeBaremetalChassisState": {
    "stateEvent": "enable"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中`systemTags`、`userTags`字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"changeBaremetalChassisState":{"stateEvent":"enable"}}' \
http://localhost:8080/zstack/v1/baremetal/chassis/1a600f11b61e3585bbd26d06166ff640/actions
```
