---
title: "下发获取裸金属硬件信息命令"
---

<APIPage method="PUT" path="/v1/baremetal/chassis/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "inspectBaremetalChassis": {},
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中`systemTags`、`userTags`字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"inspectBaremetalChassis":{}}' \
http://localhost:8080/zstack/v1/baremetal/chassis/514c293bdd6c3bc38f0dd5050f85642d/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|裸机设备UUID| |2.6.0|
|systemTags \(可选\)|List|body|系统标签| |2.6.0|
|userTags \(可选\)|List|body|用户标签| |2.6.0|


|名字|类型|描述|起始版本|
|---|---|---|----|
|success|boolean| |0.6|
|error|ErrorCode|错误码，若不为null，则表示操作失败, 操作成功时该字段为null。 详情参考[error](#p_lvx_yyy_3gc)|2.6.0|
|inventory|BaremetalChassisInventory|详情参考[inventory](#p_fpw_nbz_3gc)|2.6.0|

|details|String|错误的详细信息|0.6|
|elaboration|String|保留字段，默认为null|0.6|

|cause|ErrorCode|根错误，引发当前错误的源错误，若无原错误，该字段为null|0.6|
