title: "获取跨存储迁移可选主机列表"
---

<APIPage method="GET" path="/v1/primary-storage/hosts/{vmInstanceUuid}/migration-candidates">

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/primary-storage/hosts/73e5ee655c3d3ef7b9fc0f3a3b560270/migration-candidates?dstPrimaryStorageUuid=cc8db724e1b334568026ca38d5c27b0f
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|vmInstanceUuid|String|url|虚拟机UUID| |4.0.0|
|dstPrimaryStorageUuid|String|query|目的数据存储UUID| |4.0.0|
|limit \(可选\)|Integer|query|获取主机列表数量| |4.0.0|
|systemTags \(可选\)|List|query|系统标签| |4.0.0|
|userTags \(可选\)|List|query|用户标签| |4.0.0|
