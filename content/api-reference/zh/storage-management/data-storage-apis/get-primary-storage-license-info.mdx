---
title: "获取数据存储的License信息"
---

<APIPage method="GET" path="/v1/primary-storage/{uuid}/license">

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/primary-storage/9b624d6e4ca53a4aa10bfc341281d0ef/license
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|数据存储UUID| |3.6.0|
|systemTags \(可选\)|List|query| | |3.6.0|
|userTags \(可选\)|List|query| | |3.6.0|

  "name": "Ceph",
  "expireTime": ""
