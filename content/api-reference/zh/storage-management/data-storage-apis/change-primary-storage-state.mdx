title: "更改数据存储状态"
---

<APIPage method="PUT" path="/v1/primary-storage/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "changePrimaryStorageState": {
    "stateEvent": "Disabled"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"changePrimaryStorageState":{"stateEvent":"disable"}}' \
http://localhost:8080/zstack/v1/primary-storage/2e9c3a048ce03f5db297da323061a0de/actions
```

|inventory|PrimaryStorageInventory|详情参考[inventory](#p_llx_nl1_n1b)|0.6|

### error

|details|String|错误的详细信息|0.6|
|elaboration|String|保留字段，默认为null|0.6|
