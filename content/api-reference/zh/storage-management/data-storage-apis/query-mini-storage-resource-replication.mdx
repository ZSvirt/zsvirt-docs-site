Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/primary-storage/mini/replications
```

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/primary-storage/mini/replications/981f98a16e173fd2a7b2fed99c8b3262
```

可查询字段

运行CLI命令行工具，输入`QueryMiniStorageResourceReplication`并按Tab键查看所有可查询字段以及可跨表查询的资源名。
