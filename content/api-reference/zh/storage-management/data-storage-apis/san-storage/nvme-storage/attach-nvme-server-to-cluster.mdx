---
title: "NVMe服务器加载到集群"
---

<APIPage method="POST" path="/v1/clusters/{clusterUuid}/storage-devices/nvme/servers/{uuid}">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {},
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{}}' \
http://localhost:8080/zstack/v1/clusters/1f8daabbcca53e30bde1f6511f266b53/storage-devices/nvme/servers/28aca7875015311d814e12bb7d03dbab
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|资源的UUID，唯一标示该资源| |4.7.21|
|clusterUuid|String|url|集群UUID| |4.7.21|
|systemTags \(可选\)|List|body|系统标签| |4.7.21|
|userTags \(可选\)|List|body|用户标签| |4.7.21|
