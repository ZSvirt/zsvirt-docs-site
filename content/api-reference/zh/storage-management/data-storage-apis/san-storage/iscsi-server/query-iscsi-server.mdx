Curl示例

```

-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/storage-devices/iscsi/servers
```

可查询字段

运行CLI命令行工具，输入`QueryIscsiServer`并按Tab键查看所有可查询字段以及可跨表查询的资源名。
