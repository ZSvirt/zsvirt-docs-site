```

```

参数列表

|名字|类型|位置|描述|可选值|起始版本|

## API返回
返回示例

```
{
  "vmInstanceMetadata": []
}
```

|名字|类型|描述|起始版本|

|success|boolean|操作是否成功|5.0.0|
|vmInstanceMetadata|List|详情参考[vmInstanceMetadata](#p_adm_54f_2jc)|5.0.0|
|error|ErrorCode|详情参考[error](#p_qnb_1nf_2jc)|5.0.0|

|名字|类型|描述|起始版本|
