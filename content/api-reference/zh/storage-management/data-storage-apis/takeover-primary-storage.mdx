title: "接管数据存储"
---

<APIPage method="PUT" path="/v1/primary-storage/{uuid}/takeover">

接管数据存储。将其他平台的共享块数据存储接管到当前平台。 dryRun=true时仅执行一致性预检：若一致（无需接管）则返回错误，若不一致（可接管）则返回成功。 接管操作不可逆（agent侧会执行VG rename、PV UUID reset、sanlock lockspace reset）。 接管完成后自动触发reconnect，通过返回的inventory.status获取重连状态。

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "takeoverPrimaryStorage": {
    "dryRun": false
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中`systemTags`、`userTags`字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"takeoverPrimaryStorage":{"dryRun":false}}' \
http://localhost:8080/zstack/v1/primary-storage/ff0359abb8443d2f8077cc368afa7c00/takeover
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|存储的UUID| |5.0.0|
|dryRun \(可选\)|boolean|body\(包含在`takeoverPrimaryStorage`结构中\)|预检模式：成功表示可以执行接管，失败表示无需或无法接管| |5.0.0|
|systemTags \(可选\)|List|body|系统标签| |5.0.0|
|userTags \(可选\)|List|body|用户标签| |5.0.0|
