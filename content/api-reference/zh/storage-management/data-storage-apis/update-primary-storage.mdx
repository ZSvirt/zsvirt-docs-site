---
title: "更新数据存储信息"
---

<APIPage method="PUT" path="/v1/primary-storage/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "updatePrimaryStorage": {
    "name": "New PS1"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"updatePrimaryStorage":{"name":"New PS1"}}' \
http://localhost:8080/zstack/v1/primary-storage/1ed3e2350ff736918ac97c2a4d7d2f6e/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|数据存储的UUID，唯一标示该资源| |0.6|
|name \(可选\)|String|body\(包含在**updatePrimaryStorage**结构中\)|数据存储的新名称| |0.6|
|description \(可选\)|String|body\(包含在**updatePrimaryStorage**结构中\)|数据存储的新详细描述| |0.6|
|url \(可选\)|String|body\(包含在**updatePrimaryStorage**结构中\)|数据存储的新地址| |0.6|
|systemTags \(可选\)|List|body|系统标签| |0.6|
|userTags \(可选\)|List|body|用户标签| |0.6|

```
      "31d01fe839da465ca540292132b50209"

```

|名字|类型|描述|起始版本|
|---|---|---|----|
|error|ErrorCode|错误码，若不为null，则表示操作失败, 操作成功时该字段为null。 详情参考[error](#p_h1q_bm1_n1b)|0.6|
|inventory|PrimaryStorageInventory|详情参考[inventory](#p_zyk_bm1_n1b)|0.6|

### error
|名字|类型|描述|起始版本|
|---|---|---|----|
|code|String|错误码号，错误的全局唯一标识，例如SYS.1000, HOST.1001|0.6|
|description|String|错误的概要描述|0.6|
|details|String|错误的详细信息|0.6|
|elaboration|String|保留字段，默认为null|0.6|
|opaque|LinkedHashMap|保留字段，默认为null|0.6|
|cause|ErrorCode|根错误，引发当前错误的源错误，若无原错误，该字段为null|0.6|
