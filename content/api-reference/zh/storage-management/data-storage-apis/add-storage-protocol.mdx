---
title: "添加存储协议"
---

<APIPage method="POST" path="/v1/primary-storage/protocols">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "uuid": "68c75f0058b93c61b30188e37b8fc5e9",
    "outputProtocol": "iSCSI"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中`systemTags`、`userTags`字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"uuid":"68c75f0058b93c61b30188e37b8fc5e9","outputProtocol":"iSCSI"}}' \
http://localhost:8080/zstack/v1/primary-storage/protocols
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|body\(包含在`params`结构中\)|资源的UUID，唯一标示该资源| |4.10.16|
|outputProtocol|String|body\(包含在`params`结构中\)|输出协议| |4.10.16|
|systemTags \(可选\)|List|body|系统标签| |4.10.16|
|userTags \(可选\)|List|body|用户标签| |4.10.16|

## API返回
该API成功时返回一个空的JSON结构`{}`，出错时返回的JSON结构包含一个error字段，例如：

```
{
  "error": {
    "code": "SYS.1001",
    "description": "A message or a operation timeout",
    "details": "Create VM on KVM timeout after 300s"
  }
}
```
