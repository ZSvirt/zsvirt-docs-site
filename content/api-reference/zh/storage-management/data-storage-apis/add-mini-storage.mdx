---
title: "添加Mini存储"
---

<APIPage method="POST" path="/v1/primary-storage/mini">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "diskIdentifier": "/dev/sdb",
    "name": "mini storage 1",
    "type": "MiniStorage",
    "zoneUuid": "c1e53af7bd7c3a87a9fc7e482b37a29f"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中`systemTags`、`userTags`字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"diskIdentifier":"/dev/sdb","name":"mini storage 1","type":"MiniStorage","zoneUuid":"c1e53af7bd7c3a87a9fc7e482b37a29f"}}' \
http://localhost:8080/zstack/v1/primary-storage/mini
```
