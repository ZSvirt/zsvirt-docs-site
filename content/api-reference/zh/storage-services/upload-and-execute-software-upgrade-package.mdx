title: "上传并更新软件包"
---

<APIPage method="POST" path="/v1/software-packages/backup-storage/{uuid}/upgrade">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "upgradeType": "Normal"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中`systemTags`、`userTags`字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"upgradeType":"Normal"}}' \
http://localhost:8080/zstack/v1/software-packages/backup-storage/ff04e1736ec6391f9a1f023b524d0a00/upgrade
```

## API返回
该API成功时返回一个空的JSON结构`{}`，出错时返回的JSON结构包含一个error字段，例如：

```
{
  "error": {
    "code": "SYS.1001",
    "description": "A message or a operation timeout",
    "details": "Create VM on KVM timeout after 300s"
  }
}
```
