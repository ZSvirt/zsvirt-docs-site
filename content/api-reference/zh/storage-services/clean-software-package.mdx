---
title: "清理软件包"
---

<APIPage method="DELETE" path="/v1/software-package/{uuid}">

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X DELETE http://localhost:8080/zstack/v1/software-package/ff04e1736ec6391f9a1f023b524d0a00?deleteMode=Permissive
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|软件包UUID| |4.10.20|
|deleteMode \(可选\)|String|query|删除模式\(Permissive / Enforcing，Permissive\)| |4.10.20|
|systemTags \(可选\)|List|query|系统标签| |4.10.20|
|userTags \(可选\)|List|query|用户标签| |4.10.20|

## API返回
该API成功时返回一个空的JSON结构`{}`，出错时返回的JSON结构包含一个error字段，例如：

```
{
  "error": {
    "code": "SYS.1001",
    "description": "A message or a operation timeout",
    "details": "Create VM on KVM timeout after 300s"
  }
}
```
