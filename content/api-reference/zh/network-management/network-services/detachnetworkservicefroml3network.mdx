---
title: "从分布式端口组卸载网络服务"
---

<APIPage method="DELETE" path="/v1/l3-networks/{l3NetworkUuid}/network-services" altPaths={["/v1/l3-networks/{l3NetworkUuid}/network-services/{service}"]}>

Headers

```
Authorization: OAuth the-session-uuid
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|l3NetworkUuid|String|url|分布式端口组UUID| |0.6|
|networkServices \(可选\)|Map|query|网络服务| |0.6|
|systemTags \(可选\)|List|query|系统标签| |0.6|
|userTags \(可选\)|List|query|用户标签| |0.6|
|service \(可选\)|String|query|服务类型| |4.10.16|

## API返回
该API成功时返回一个空的JSON结构`{}`，出错时返回的JSON结构包含一个error字段，例如：

```
{
  "error": {
    "code": "SYS.1001",
    "description": "A message or a operation timeout",
    "details": "Create VM on KVM timeout after 300s"
  }
}
```
