---
title: "挂载安全组到分布式端口组"
---

<APIPage method="POST" path="/v1/security-groups/{securityGroupUuid}/l3-networks/{l3NetworkUuid}">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {},
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{}}' http://localhost:8080/zstack/v1/security-groups/0551a95211783295879d083216cb493b/l3-networks/35aa9f6e9a2b3f849d1631ba89d0b27d
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|securityGroupUuid|String|url|安全组UUID| |0.6|
|l3NetworkUuid|String|url|分布式端口组UUID| |0.6|
|systemTags \(可选\)|List|body|系统标签| |0.6|
|userTags \(可选\)|List|body|用户标签| |0.6|
