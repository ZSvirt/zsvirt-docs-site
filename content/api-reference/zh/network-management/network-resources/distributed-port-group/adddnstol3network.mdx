---
title: "向分布式端口组添加DNS"
---

<APIPage method="POST" path="/v1/l3-networks/{l3NetworkUuid}/dns">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "dns": "8.8.8.8"
  },
  "systemTags": [],
  "userTags": []
}
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"dns":"8.8.8.8"}}' \
http://localhost:8080/zstack/v1/l3-networks/0b8da8c298ed3960925abbcc4f913da8/dns
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|l3NetworkUuid|String|url|分布式端口组UUID| |0.6|
|dns|String|url|DNS地址| |0.6|
|systemTags \(可选\)|List|body|系统标签| |0.6|
|userTags \(可选\)|List|body|用户标签| |0.6|
