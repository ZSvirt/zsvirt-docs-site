---
title: "修改DHCP服务器地址"
---

<APIPage method="PUT" path="/v1/l3-networks/{l3NetworkUuid}/dhcp-ip">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "changeL3NetworkDhcpIpAddress": {
    "dhcpServerIp": "192.168.1.100",
    "dhcpv6ServerIp": "2024:04:28:01::100"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中`systemTags`、`userTags`字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"changeL3NetworkDhcpIpAddress":{"dhcpServerIp":"192.168.1.100","dhcpv6ServerIp":"2024:04:28:01::100"}}' \
http://localhost:8080/zstack/v1/l3-networks/6b693b00316b30819bb30bfe0df10256/dhcp-ip
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|l3NetworkUuid|String|url|分布式端口组UUID| |4.10.16|
|dhcpServerIp \(可选\)|String|body\(包含在`changeL3NetworkDhcpIpAddress`结构中\)|DHCP v4 服务器地址| |4.10.16|
|dhcpv6ServerIp \(可选\)|String|body\(包含在`changeL3NetworkDhcpIpAddress`结构中\)|DHCP v6 服务器地址| |4.10.16|
|systemTags \(可选\)|List|body|系统标签| |4.10.16|
|userTags \(可选\)|List|body|用户标签| |4.10.16|

## API返回
返回示例

```
{
  "dhcpServerIp": "192.168.100.3",
  "dhcpv6ServerIp": "2024:04:28:01::100"
}
```
