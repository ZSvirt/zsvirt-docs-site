---
title: "通过网络CIDR添加IPv6地址范围"
---

<APIPage method="POST" path="/v1/l3-networks/{l3NetworkUuid}/ipv6-ranges/by-cidr">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "name": "Test-IPRange",
    "networkCidr": "2002:2001::/64",
    "addressMode": "SLAAC"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"name":"Test-IPRange","networkCidr":"2002:2001::/64","addressMode":"SLAAC"}}' http://localhost:8080/zstack/v1/l3-networks/92850b5a66633e2aa8c3a8ae6ebb541d/ipv6-ranges/by-cidr
```

<Callout type="info">
-   ZSvirt通过网络CIDR添加IPv6地址范围时支持指定DHCP server地址功能，**SystemTags**增加**affinityGroup**选项。
    -   选项格式为：`flatNetwork::DhcpServer::{%s}::ipUuid::{%s}`
    -   例如：`flatNetwork::DhcpServer::192.168.1.100::ipUuid::null`
</Callout>

```
{
  "inventory": {
    "l3NetworkUuid": "6735b2c2bc0c345892b7d66b1616d909",

```

|名字|类型|描述|起始版本|
|---|---|---|----|
|error|ErrorCode|错误码，若不为null，则表示操作失败, 操作成功时该字段为null。 详情参考[error](#p_wmy_svg_m1b)|3.1.0|
|inventory|IpRangeInventory|详情参考[inventory](#p_s5b_wvg_m1b)|3.1.0|

|details|String|错误的详细信息|3.1.0|
