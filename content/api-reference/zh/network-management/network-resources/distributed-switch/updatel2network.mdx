## AI请求
URLs

```
PUT zstack/v1/l2-networks/{uuid}/actions
```

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "updateL2Network": {
    "name": "Test-Net",
    "description": "Test"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"updateL2Network":{"name":"Test-Net","description":"Test"}}' \
http://localhost:8080/zstack/v1/l2-networks/8a44ece25f973842b841591a554f5fee/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|资源的UUID，唯一标示该资源| |0.6|
|name \(可选\)|String|body\(包含在**updateL2Network**结构中\)|普通分布式交换机名称| |0.6|
|description \(可选\)|String|body\(包含在**updateL2Network**结构中\)|普通分布式交换机的详细描述| |0.6|
|systemTags \(可选\)|List|body|系统标签| |0.6|
|userTags \(可选\)|List|body|用户标签| |0.6|

API返回

返回示例

```
{
  "inventory": {
    "vlan": 10,
    "name": "Test-Net",
    "description": "Test",
    "zoneUuid": "fa938a0c3dc437748ba603836bb59fda",
    "physicalInterface": "eth0",
    "type": "L2VlanNetwork"
  }
}
```

|名字|类型|描述|起始版本|
|---|---|---|----|
|success|boolean| |0.6|
|error|ErrorCode|错误码，若不为null，则表示操作失败, 操作成功时该字段为null。 详情参考[error](#p_et1_2qg_m1b)|0.6|
|inventory|L2NetworkInventory|详情参考[inventory](#p_g4g_2qg_m1b)|0.6|

### error
|名字|类型|描述|起始版本|
|---|---|---|----|
|code|String|错误码号，错误的全局唯一标识，例如SYS.1000, HOST.1001|0.6|
|description|String|错误的概要描述|0.6|
|details|String|错误的详细信息|0.6|
|elaboration|String|保留字段，默认为null|0.6|
|opaque|LinkedHashMap|保留字段，默认为null|0.6|
|cause|ErrorCode|根错误，引发当前错误的源错误，若无原错误，该字段为null|0.6|

### inventory
|名字|类型|描述|起始版本|
|---|---|---|----|
|uuid|String|资源的UUID，唯一标示该资源|0.6|
|name|String|资源名称|0.6|
|description|String|资源的详细描述|0.6|
|zoneUuid|String|数据中心UUID|0.6|
|physicalInterface|String|物理网卡|0.6|
|type|String|分布式交换机类型|0.6|
|createDate|Timestamp|创建时间|0.6|
|lastOpDate|Timestamp|最后一次修改时间|0.6|
|attachedClusterUuids|List|挂载集群的UUID列表|0.6|
