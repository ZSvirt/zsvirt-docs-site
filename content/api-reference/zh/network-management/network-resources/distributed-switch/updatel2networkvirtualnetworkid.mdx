title: "更新分布式交换机虚拟网络ID"
---

<APIPage method="PUT" path="/v1/l2-networks/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "updateL2NetworkVirtualNetworkId": {
    "virtualNetworkId": 1
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中`systemTags`、`userTags`字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"updateL2NetworkVirtualNetworkId":{"virtualNetworkId":1}}' \
http://localhost:8080/zstack/v1/l2-networks/aaed66240c433b289841fe7dc5cba765/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|资源的UUID，唯一标示该资源| |4.10.0|
|virtualNetworkId|Integer|body\(包含在`updateL2NetworkVirtualNetworkId`结构中\)|虚拟网络ID，vlanId或vni| |4.10.0|
|systemTags \(可选\)|List|body|系统标签| |4.10.0|
|userTags \(可选\)|List|body|用户标签| |4.10.0|
