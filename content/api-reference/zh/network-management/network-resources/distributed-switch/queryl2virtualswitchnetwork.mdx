可查询字段

运行CLI命令行工具，输入`QueryL2VirtualSwitchNetwork`并按Tab键查看所有可查询字段以及可跨表查询的资源名。

## API返回
返回示例

```
{
  "inventories": [
    {
      "name": "Test-dvs",
      "description": "Test",

      "physicalInterface": "eth0",
      "type": "virtualSwitch"
    }
  ]
}
```
