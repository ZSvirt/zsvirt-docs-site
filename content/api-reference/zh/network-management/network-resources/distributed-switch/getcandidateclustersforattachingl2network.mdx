---
title: "获取分布式交换机允许加载的集群"
---

<APIPage method="GET" path="/v1/l2-networks/{l2NetworkUuid}/cluster-candidates">

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/l2-networks/0b888b1f97993dbc9a22667219bcc690/cluster-candidates?limit=1000&start=0
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|l2NetworkUuid|String|url|分布式交换机UUID| |4.0.0|
|clusterTypes \(可选\)|List|query|集群类型列表| |4.0.0|
|limit \(可选\)|Integer|query|最多返回的记录数，类似MySQL的limit| |4.0.0|
|start \(可选\)|Integer|query|起始查询记录位置，类似MySQL的offset。跟`limit`配合使用可以实现分页| |4.0.0|
|systemTags \(可选\)|List|query|系统标签| |4.0.0|
|userTags \(可选\)|List|query|用户标签| |4.0.0|
