<APIPage method="PUT" path="/v1/volumes/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "undoSnapshotCreation": {
    "snapShotUuid": "7677380457d136629f44c93c99978acc"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中`systemTags`、`userTags`字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"undoSnapshotCreation":{"snapShotUuid":"7677380457d136629f44c93c99978acc"}}' \
http://localhost:8080/zstack/v1/volumes/7fc32ad187c939d8aca65977560c2714/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|资源的UUID，唯一标示该资源| |4.7.0|
|snapShotUuid|String|body\(包含在`undoSnapshotCreation`结构中\)| | |4.7.0|
|systemTags \(可选\)|List|body|系统标签| |4.7.0|
|userTags \(可选\)|List|body|用户标签| |4.7.0|
