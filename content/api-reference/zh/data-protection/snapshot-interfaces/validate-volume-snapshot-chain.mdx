---
title: "验证硬盘当前快照链"
---

<APIPage method="PUT" path="/v1/volumes/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "validateVolumeSnapshotChain": {},
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中`systemTags`、`userTags`字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"validateVolumeSnapshotChain":{}}' \
http://localhost:8080/zstack/v1/volumes/c741336c9efe334490ed027e7130af1e/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|资源的UUID，唯一标示该资源，验证这个云盘当前在使用的快照链| |4.3.0|
|systemTags \(可选\)|List|body|系统标签| |4.3.0|
|userTags \(可选\)|List|body|用户标签| |4.3.0|

## API返回
该API成功时返回一个空的JSON结构`{}`，出错时返回的JSON结构包含一个error字段，例如：

```
{
  "error": {
    "code": "SYS.1001",
    "description": "A message or a operation timeout",
    "details": "Create VM on KVM timeout after 300s"
  }
}
```
