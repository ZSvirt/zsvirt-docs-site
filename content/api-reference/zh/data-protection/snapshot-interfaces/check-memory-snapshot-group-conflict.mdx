---
title: "检查内存快照组冲突信息"
---

<APIPage method="GET" path="/v1/memory-snapshots/groups/{uuid}/conflict-detection">

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/memory-snapshots/groups/ff06c5015505317fae8e020694bad500/conflict-detection
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|内存快照组UUID| |4.10.16|
|systemTags \(可选\)|List|query|系统标签| |4.10.16|
|userTags \(可选\)|List|query|用户标签| |4.10.16|

## API返回
返回示例

```
{
  "vmNicConflict": [
    {
      "ip": "127.0.0.1",
      "mac": "00:16:3e:00:00:01",
      "vmNicName": "vmNicName",
      "vmInstanceName": "vmInstanceName",
      "vmInstanceUuid": "ff01ec80fd11327cba7519b66119d900"
    }
  ]
}
```

|名字|类型|描述|起始版本|
|---|---|---|----|
|success|boolean| |4.10.0|
|vmNicConflict|List|详情参考[vmNicConflict](#p_cm1_hkv_v2c)|4.10.0|
|error|ErrorCode|详情参考[error](#p_ebq_3kv_v2c)|4.10.0|

### vmNicConflict
|名字|类型|描述|起始版本|
|---|---|---|----|
|ip|String|冲突的ip|4.10.16|
|mac|String|冲突的mac|4.10.16|
|vmNicName|String|网卡名称|4.10.16|
|vmInstanceName|String|虚拟机名称|4.10.16|
|vmInstanceUuid|String|虚拟机UUID|4.10.16|

### error
|名字|类型|描述|起始版本|
|---|---|---|----|
|code|String|错误码号，错误的全局唯一标识，例如SYS.1000, HOST.1001|0.6|
|description|String|错误的概要描述|0.6|
|details|String|错误的详细信息|0.6|
|elaboration|String|保留字段，默认为null|0.6|
|opaque|LinkedHashMap|保留字段，默认为null|0.6|
|cause|ErrorCode|根错误，引发当前错误的源错误，若无原错误，该字段为null|0.6|
