<APIPage method="POST" path="/v1/sns/topics">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "name": "api topic",
    "locale": "zh_CN"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"name":"api topic","locale":"zh_CN"}}' \
http://localhost:8080/zstack/v1/sns/topics
```

## API返回
返回示例

```
{
  "inventory": {
    "uuid": "b3033f326b9d4f0fb01fa900d2dd6c2f",
    "name": "new name",
    "state": "Enabled",
    "locale": "zh_CN",
    "createDate": "Mar 26, 2024 2:46:30 AM",
    "lastOpDate": "Mar 26, 2024 2:46:30 AM"
  }
}
```

|名字|类型|描述|起始版本|
|---|---|---|----|
|success|boolean| |5.0.0|
|error|ErrorCode|错误码，若不为null，则表示操作失败, 操作成功时该字段为null。 详情参考[error](#p_b1q_chy_p1b)|2.3|
|inventory|SNSTopicInventory|详情参考[inventory](#p_ywy_chy_p1b)|2.3|

### error
|名字|类型|描述|起始版本|
|---|---|---|----|
|code|String|错误码号，错误的全局唯一标识，例如SYS.1000, HOST.1001|0.6|
|description|String|错误的概要描述|0.6|
|details|String|错误的详细信息|0.6|
|elaboration|String|保留字段，默认为null|0.6|
|opaque|LinkedHashMap|保留字段，默认为null|0.6|
|cause|ErrorCode|根错误，引发当前错误的源错误，若无原错误，该字段为null|0.6|

### inventory
|名字|类型|描述|起始版本|
|---|---|---|----|
|uuid|String|资源的UUID，唯一标示该资源|2.3|
|name|String|资源名称|2.3|
|description|String|资源的详细描述|2.3|
|state|String|状态|2.3|
|lastOpDate|Timestamp|最后一次修改时间|2.3|
|createDate|Timestamp|创建时间|2.3|
