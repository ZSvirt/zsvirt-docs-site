---
title: "添加飞书@用户"
---

<APIPage method="POST" path="/v1/sns/application-endpoints/feishu/at-persons">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "userId": "18099997777",
    "endpointUuid": "9214e9f129783370bea45388a1734073",
    "remark": "jack"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"userId":"18099997777","endpointUuid":"9214e9f129783370bea45388a1734073","remark":"jack"}}' \
http://localhost:8080/zstack/v1/sns/application-endpoints/feishu/at-persons
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|userId|String|body\(包含在**params**结构中\)|飞书用户ID| |4.2.0|
|endpointUuid|String|body\(包含在**params**结构中\)|飞书终端UUID| |4.2.0|
|resourceUuid \(可选\)|String|body\(包含在**params**结构中\)|资源UUID| |4.2.0|
|systemTags \(可选\)|List|body|系统标签| |4.2.0|
|userTags \(可选\)|List|body|用户标签| |4.2.0|
|tagUuid \(可选\)|List|body\(包含在**params**结构中\)|标签UUID列表| |4.2.0|
|remark \(可选\)|String|body\(包含在**params**结构中\)|备注| |4.2.0|
