<APIPage method="GET" path="/v1/sns/application-endpoints/feishu" altPaths={["/v1/sns/application-endpoints/feishu/{uuid}"]}>

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/sns/application-endpoints/feishu?q=url=http://feishu-url
```

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/sns/application-endpoints/feishu/79768ce4f641390e9c09337c77fe4f70
```

可查询字段

运行CLI命令行工具，输入`QuerySNSFeiShuEndpoint`并按Tab键查看所有可查询字段以及可跨表查询的资源名。

## API返回
该API成功时返回一个空的JSON结构**`{}`**，出错时返回的JSON结构包含一个error字段，例如：

```
{
  "error": {
    "code": "SYS.1001",
    "description": "A message or a operation timeout",
    "details": "Create VM on KVM timeout after 300s"
  }
}
```
