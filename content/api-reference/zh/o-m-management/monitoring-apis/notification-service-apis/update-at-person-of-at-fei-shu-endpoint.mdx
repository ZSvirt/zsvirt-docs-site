<APIPage method="PUT" path="/v1/sns/application-endpoints/feishu/at-persons/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "updateAtPersonOfAtFeiShuEndpoint": {
    "endpointUuid": "60274b11ffdc3ea080be205b964848d2",
    "userId": "zhang.san",
    "remark": "jack"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"updateAtPersonOfAtFeiShuEndpoint":{"endpointUuid":"60274b11ffdc3ea080be205b964848d2","userId":"zhang.san","remark":"jack"}}' \
http://localhost:8080/zstack/v1/sns/application-endpoints/feishu/at-persons/399ba943200638c2a63b65f002b6e180/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|资源的UUID，唯一标示该资源| |4.2.0|
|endpointUuid|String|body\(包含在**updateAtPersonOfAtFeiShuEndpoint**结构中\)|飞书endpoint uuid| |4.2.0|
|userId\(可选\)|String|body\(包含在**updateAtPersonOfAtFeiShuEndpoint**结构中\)|飞书用户id| |4.2.0|
|systemTags \(可选\)|List|body|系统标签| |4.2.0|
|userTags \(可选\)|List|body|用户标签| |4.2.0|
|remark|String|body\(包含在**updateAtPersonOfAtFeiShuEndpoint**结构中\)|备注| |4.2.0|
