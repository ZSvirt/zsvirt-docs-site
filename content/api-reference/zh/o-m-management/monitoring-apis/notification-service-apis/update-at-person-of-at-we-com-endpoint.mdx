<APIPage method="PUT" path="/v1/sns/application-endpoints/we-com/at-persons/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "updateAtPersonOfAtWeComEndpoint": {
    "endpointUuid": "4aec8a68c63439f197df9623ec89cda6",
    "userId": "zhang.san",
    "remark": "jack"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"updateAtPersonOfAtWeComEndpoint":{"endpointUuid":"4aec8a68c63439f197df9623ec89cda6","userId":"zhang.san","remark":"jack"}}' \
http://localhost:8080/zstack/v1/sns/application-endpoints/we-com/at-persons/87df59c09f0336c2817d318a468f717c/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|资源的UUID，唯一标示该资源| |4.2.0|
|endpointUuid|String|body\(包含在**updateAtPersonOfAtWeComEndpoint**结构中\)|企业微信终端UUID| |4.2.0|
|userId\(可选\)|String|body\(包含在**updateAtPersonOfAtWeComEndpoint**结构中\)|企业微信用户ID| |4.2.0|
|systemTags \(可选\)|List|body|系统标签| |4.2.0|
|userTags \(可选\)|List|body|用户标签| |4.2.0|
|remark \(可选\)|String|body\(包含在**updateAtPersonOfAtWeComEndpoint**结构中\)|备注| |4.2.0|
