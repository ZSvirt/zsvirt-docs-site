<APIPage method="PUT" path="/v1/sns/application-endpoints/ding-talk/at-persons/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "updateAtPersonOfAtDingTalkEndpoint": {
    "endpointUuid": "d7be4980da0a308380b761afd3f36687",
    "phoneNumber": "13062689903",
    "remark": "jack"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"updateAtPersonOfAtDingTalkEndpoint":{"endpointUuid":"d7be4980da0a308380b761afd3f36687","phoneNumber":"13062689903","remark":"jack"}}' \
http://localhost:8080/zstack/v1/sns/application-endpoints/ding-talk/at-persons/c42464333dce35db9fbc8816f22b1d31/actions
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|uuid|String|url|资源的UUID，唯一标示该资源| |4.2.0|
|endpointUuid|String|body\(包含在**updateAtPersonOfAtDingTalkEndpoint**结构中\)|钉钉终端UUID| |4.2.0|
|phoneNumber \(可选\)|String|body\(包含在**updateAtPersonOfAtDingTalkEndpoint**结构中\)|手机号码| |4.2.0|
|systemTags \(可选\)|List|body|系统标签| |4.2.0|
|userTags \(可选\)|List|body|用户标签| |4.2.0|
|remark|String|body\(包含在**updateAtPersonOfAtDingTalkEndpoint**结构中\)|备注| |4.2.0|
