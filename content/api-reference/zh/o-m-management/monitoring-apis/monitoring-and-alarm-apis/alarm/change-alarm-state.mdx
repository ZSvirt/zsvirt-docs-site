title: "更改报警器状态"
---

<APIPage method="PUT" path="/v1/zwatch/alarms/{uuid}/actions">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "changeAlarmState": {
    "stateEvent": "disable"
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中**systemTags**、**userTags**字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X PUT -d '{"changeAlarmState":{"stateEvent":"disable"}}' http://localhost:8080/zstack/v1/zwatch/alarms/226149ca389f387e95d0f671bd6b551f/actions
```

|名字|类型|描述|起始版本|
|---|---|---|----|
|error|ErrorCode|错误码，若不为null，则表示操作失败, 操作成功时该字段为null。 详情参考[error](#p_x5x_blk_p2b)|2.3|
|inventory|AlarmInventory|详情参考[inventory](#p_obs_dlk_p2b)|2.3|

### error
|名字|类型|描述|起始版本|
|---|---|---|----|
|code|String|错误码号，错误的全局唯一标识，例如SYS.1000, HOST.1001|2.3|
|description|String|错误的概要描述|2.3|
|details|String|错误的详细信息|2.3|
|elaboration|String|保留字段，默认为null|2.3|
|opaque|LinkedHashMap|保留字段，默认为null|2.3|
|cause|ErrorCode|根错误，引发当前错误的源错误，若无原错误，该字段为null|2.3|

### inventory
|名字|类型|描述|起始版本|
|---|---|---|----|
|uuid|String|资源的UUID，唯一标示该资源|2.3|
|name|String|资源名称|2.3|
|description|String|资源的详细描述|2.3|
|period|Integer|阈值持续时间|2.3|
|namespace|String|名字空间|2.3|
|metricName|String|监控项名称|2.3|
|threshold|Double|阈值|2.3|
|repeatInterval|Integer|报警重复时间|2.3|
|createDate|Timestamp|创建时间|2.3|
|lastOpDate|Timestamp|最后一次修改时间|2.3|
|comparisonOperator|ComparisonOperator|详情参考[comparisonOperator](#p_x2j_2lk_p2b)|2.3|
|status|AlarmStatus|详情参考[status](#p_gzz_flk_p2b)|2.3|
|labels|List|详情参考[labels](#p_fhy_glk_p2b)|2.3|
|actions|List|详情参考[actions](#p_w2z_hlk_p2b)|2.3|
