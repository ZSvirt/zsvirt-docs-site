<APIPage method="GET" path="/v1/management-nodes/zsha2/status">

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/management-nodes/zsha2/status
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|systemTags \(可选\)|List|query|系统标签| |4.10.20|
|userTags \(可选\)|List|query|用户标签| |4.10.20|

### inventory

### nodes
|名字|类型|描述|起始版本|
|---|---|---|----|

|keepalivedStatus|String|keepalived 服务状态, 一般为 'alive'|4.10.20|
|haMonitorStatus|String|HA monitor 服务状态, 一般为 'alive'|4.10.20|

### error
|名字|类型|描述|起始版本|
