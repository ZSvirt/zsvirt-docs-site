---
title: "获取管理节点角色"
---

<APIPage method="GET" path="/v1/zsv/nodes/roles">

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/zsv/nodes/roles
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|systemTags \(可选\)|List|query|系统标签| |4.10.7|
|userTags \(可选\)|List|query|用户标签| |4.10.7|

## API返回
返回示例

```
{
  "inventories": [
    {
      "uuid": "ff000842a4673ab39dad7a3990df5300",
      "resourceType": "ManagementNodeVO",
      "roles": [
        {
          "uuid": "ff000842a4673ab39dad7a3990df5300",
          "resourceType": "ManagementNodeVO",
          "role": "management"
        },
        {
          "uuid": "ff0192fa70113da886101145c084bd00",
          "resourceType": "HostVO",
          "role": "compute"
        }
      ]
    }
  ]
}
```

|名字|类型|描述|起始版本|
|---|---|---|----|
|success|boolean|请求是否成功|4.10.7|
|inventories|List|详情参考[inventories](#p_vkj_21r_dfc)|4.10.7|
|error|ErrorCode|错误码，若不为null，则表示操作失败, 操作成功时该字段为null。 详情参考[error](#p_vd4_21r_dfc)|4.10.7|

### inventories
|名字|类型|描述|起始版本|
|---|---|---|----|
|uuid|String|管理节点的 UUID，唯一标示该资源|4.10.7|
|compute|boolean|是否是计算节点|4.10.7|

### error
|名字|类型|描述|起始版本|
|---|---|---|----|
|code|String|错误码号，错误的全局唯一标识，例如SYS.1000, HOST.1001|0.6|
|description|String|错误的概要描述|0.6|
|details|String|错误的详细信息|0.6|
|elaboration|String|保留字段，默认为null|0.6|
|opaque|LinkedHashMap|保留字段，默认为null|0.6|
|cause|ErrorCode|根错误，引发当前错误的源错误，若无原错误，该字段为null|0.6|
