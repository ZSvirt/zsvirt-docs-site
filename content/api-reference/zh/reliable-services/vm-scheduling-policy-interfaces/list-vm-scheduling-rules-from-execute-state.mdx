---
title: "根据调度状态获取对应的虚拟机"
---

<APIPage method="POST" path="/v1/list/vmSchedulingRules/from/conflict/state">

Headers

```
Authorization: OAuth the-session-uuid
```

Body

```
{
  "params": {
    "executeStates": [
      "Enabled"
    ]
  },
  "systemTags": [],
  "userTags": []
}
```

<Callout type="info">
上述示例中`systemTags`、`userTags`字段可以省略。列出是为了表示body中可以包含这两个字段。
</Callout>

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X POST -d '{"params":{"executeStates":["Enabled"]}}' \
http://localhost:8080/zstack/v1/list/vmSchedulingRules/from/conflict/state
```

参数列表

|名字|类型|位置|描述|可选值|起始版本|
|---|---|---|---|---|----|
|executeStates|List|body\(包含在`params`结构中\)|调度状态\(Conflict,Normal,Invalid\)| |4.6.0|
|systemTags \(可选\)|List|body|系统标签| |4.6.0|
|userTags \(可选\)|List|body|用户标签| |4.6.0|

## API返回
该API成功时返回一个空的JSON结构`{}`，出错时返回的JSON结构包含一个error字段，例如：

```
{
  "error": {
    "code": "SYS.1001",
    "description": "A message or a operation timeout",
    "details": "Create VM on KVM timeout after 300s"
  }
}
```
