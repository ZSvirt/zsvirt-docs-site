<APIPage method="GET" path="/v1/query/vm/schedulingRule">

Headers

```
Authorization: OAuth the-session-uuid
```

Curl示例

```
curl -H "Content-Type: application/json;charset=UTF-8" \
-H "Authorization: OAuth YOUR_SESSION_UUID" \
-X GET http://localhost:8080/zstack/v1/query/vm/schedulingRule?q=uuid=2964e2f366e73491b858ca2da4052624
```

可查询字段

运行CLI命令行工具，输入`QueryVmSchedulingRule`并按Tab键查看所有可查询字段以及可跨表查询的资源名。
