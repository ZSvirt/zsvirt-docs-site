## 协作路径

内容更新从模板开始，进入 PR 后由 CODEOWNERS 分配审核。普通博客由市场审核，技术文章和文档需要技术 Owner 审核，场景页需要产品、技术和市场共同确认。

## 建议流程

1. 从对应内容模板创建草稿。
2. 在 PR 中说明目标页面、受众、发布日期和验证方式。
3. 等待 CODEOWNERS 分配审核。
4. 技术文档由技术 Owner 确认准确性。
5. 发布后把复盘结论回写到内容 PR 或 Roadmap 讨论中。
