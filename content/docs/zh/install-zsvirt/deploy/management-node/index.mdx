title: "安装管理节点"
---

-   **[Bond 网卡部署](/docs/install-zsphere/deploy/management-node/bond-deployment)**
    为了满足网口带宽容量和高可靠需要，在实际生产环境中需实施网卡 Bond 配置操作。x86 服务器与 ARM 服务器安装操作系统流程一致，本章以 x86 服务器为例介绍系统安装的详细步骤。
-   **[单网卡部署](/docs/install-zsphere/deploy/management-node/single-nic-deployment)**
    x86 服务器与 ARM 服务器安装操作系统流程一致，本章以 x86 服务器为例介绍系统安装的详细步骤。
-   **[使用 TUI 安装](/docs/install-zsphere/deploy/management-node/tui-installation)**
    本章介绍通过 ISO 部署计算节点模式，并在 TUI 中将管理网络配置为 bond，最终在该计算节点上安装管理节点的完整流程。
