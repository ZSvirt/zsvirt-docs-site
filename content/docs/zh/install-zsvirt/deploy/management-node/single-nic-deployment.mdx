title: "单网卡部署"
---

x86 服务器与 ARM 服务器安装操作系统流程一致，本章以 x86 服务器为例介绍系统安装的详细步骤。

## 操作步骤

1.  选择引导项。

    进入 ISO 系统引导界面，选择默认选项开始安装操作系统。您可根据实际情况选择，建议使用图形界面安装。若服务器无 VGA 接口，仅支持串口连接，您可使用 VNC 方式或字符安装方式。

    -   图形界面方式
    -   VNC 方式
    -   字符安装方式
    如[Figure 1](#fig_sx2_rpz_cdc)所示：

    ![系统引导](/docs/install-zsphere/images/ZStack_ZSphere_Installation_Tutorial_0004_1_1.png)

2.  查看安装配置汇总。

    此页面展示系统安装配置，您可按需修改，ZSvirt 默认已配置以下内容：

    -   **Keyboard**：默认 English \(US\)
    -   **Language Support**：默认 English \(United States\)
    -   **Time &amp; Date**：默认亚洲东八区，建议管理员提前检测主机时间，配置为当前时间和时区
    如[Figure 2](#fig_mrz_1qz_cdc)所示：

    ![安装系统界面](/docs/install-zsphere/images/ZStack_ZSphere_Installation_Tutorial_0004_1_2.png)

3.  选择安装模式。

    1.  在 INSTALLATION SUMMARY 界面，点击 **Software Selection**。

    2.  在 SOFTWARE SELECTION 界面，选择安装模式。

        管理节点所在服务器选择**ZSvirt Management Node**模式，其余节点所在服务器选择**ZSvirt Compute Node**模式。

    3.  选择完安装模式后，点击 **Done**。

    如[Figure 3](#fig_s43_2rz_cdc)所示：

    ![选择安装模式](/docs/install-zsphere/images/ZStack_ZSphere_Installation_Tutorial_0004_1_3.png)

4.  配置硬盘分区。

    1.  在 INSTALLATION SUMMARY 界面，点击 **Installation Destination**，进入 INSTALLATION DESTINATION 界面。

    2.  对于 Device Selection，建议此处仅配置系统盘，其余磁盘可在系统安装后配置。

    3.  对于 Storage Configuration，建议选择 **Automatic** 自动配置硬盘分区。

        若您需手动配置，可根据 BIOS 引导模式参考以下内容：

        -   UEFI 模式：
            -   `/boot`：存放 Linux 启动所需的核心文件，建议分配 1 GB 空间
            -   `/boot/efi`：存放 UEFI 启动引导文件，建议分配 500 MB
            -   `swap`：交换区，建议分配 32 GB
            -   `/`：Linux 系统根目录，建议分配全部剩余空间
        -   Legacy 模式
            -   `/boot`：存放 Linux 启动所需的核心文件，建议分配 1 GB 空间
            -   `swap`：交换区，建议分配 32 GB
            -   `/`：Linux 系统根目录，建议分配全部剩余空间

        <Callout type="info">

        - 以上数值为 ZSvirt 建议分区容量（磁盘总容量大于 300 GB）。
        - Legacy 模式下，若系统盘容量大于 2 TB，需配置 BIOS boot 分区，以支持 GPT 分区。UEFI 模式没有此限制，且支持 GPT 分区。

        </Callout>
    4.  确认配置无误后，点击 **Done**。

    如[Figure 4](#fig_usl_bvz_cdc)所示：

    ![配置硬盘分区](/docs/install-zsphere/images/ZStack_ZSphere_Installation_Tutorial_0004_1_4.png)

5.  开始配置网卡。

    1.  在 INSTALLATION SUMMARY 界面，点击 **Network &amp; Host Name**，进入 NETWORK &amp; HOST NAME 界面。

    2.  在左侧网卡列表，选择网卡，例如 **Ethernet \(ens3\)**。

    3.  点击 **Configure**。

    如[Figure 5](#fig_oqv_zxb_ddc)所示：

    ![配置网卡](/docs/install-zsphere/images/ZStack_ZSphere_Installation_Tutorial_0004_2_1.png)

6.  配置网卡静态 IP 地址。

    1.  在 Editing ens3 弹窗中，点击 **IPv4 Settings**。

    2.  对于 **Method**，按需选择 IP 地址获取方式，例如选择 **Manual** 手动指定 IP 地址。

    3.  点击 **Add** 添加 IP 地址条目，按需配置 IP 地址、子网掩码、网关地址。

    如[Figure 6](#fig_q4w_fzb_ddc)所示：

    ![配置静态 IP 地址](/docs/install-zsphere/images/ZStack_ZSphere_Installation_Tutorial_0004_2_2.png)

7.  配置网卡自动激活。

    1.  在 Editing ens3 弹窗中，点击 **General**，然后勾选 **Connect automatically with priority**，用于设置网卡自动激活。

    2.  确认配置无误后，点击 **Save**。

    如[Figure 7](#fig_tlv_kzb_ddc)所示：

    ![配置网卡自动激活](/docs/install-zsphere/images/ZStack_ZSphere_Installation_Tutorial_0004_2_3.png)

8.  完成网卡配置。

    1.  返回 NETWORK &amp; HOST NAME 界面，确认网卡选择正确，并且网卡状态为 **ON**。

    2.  点击 **Done**，返回 INSTALLATION SUMMARY 界面。

    如[Figure 8](#fig_u5x_rzb_ddc)所示：

    ![检查网卡配置](/docs/install-zsphere/images/ZStack_ZSphere_Installation_Tutorial_0004_2_4.png)

9.  在 INSTALLATION SUMMARY 界面，点击 **Root Password**，设置操作系统 root 密码。

10. 在 INSTALLATION SUMMARY 界面，点击 **Begin Installation**，开始安装操作系统。
