---
title: "网络规划"
---

如[Figure 1](#fig_hbr_1yl_ghc)所示，一个典型的数据中心通常由若干台不同功能的服务器和两个独立的网络环境构成。

![网络规划拓扑图](/docs/install-zsphere/images/ZStack_ZSphere_Installation_Tutorial_0003_3_1.png)

-   管理网络采用双千兆网络，用于管理虚拟化平台相关的硬件资源。业务网络采用双万兆网络，用于虚拟机的业务流量。网络速率可根据实际业务需求进行配置。
-   若您使用 NFS 或分布式存储等网络存储，还应额外规划存储网络，用于承载存储流量。
-   建议所有服务器的网卡命名保持一致，并使用相同名称的网卡承载相同的网络流量，例如：管理网流量都使用`em1`网卡。
-   若您使用 VLAN 网络环境，需提前在交换机上配置对应的 VLAN 网络通讯。
-   ZSvirt 会主动为虚拟机分配 IP 地址，需提前预留一段和系统不冲突的 IP 网络段，同时避免该网络段与原有网络环境中的 DHCP 服务冲突。
