---
title: "为什么有的虚拟机关机时间比较久？"
---

## 原因
这种情况一般出现在Linux虚拟机上，这是因为缺少ACPID服务（用于处理电源相关事件的守护进程）。KVM虚拟机安装Linux系统默认是没有安装ACPID服务的，所以不会做处理，关机一分钟后被虚拟化平台杀掉虚拟机进程强行关闭。

## 解决方案
1.  在虚拟机系统内执行以下命令，安装和启动ACPID服务：

    ```
    [root@kvm_client_00 ~]# yum install acpid -y
    ```

2.  执行以下命令，重新启动ACPID服务，安装后默认加入到开机启动：

    ```
    [root@kvm_client_00 ~]# /etc/init.d/acpid restart 
    ```
