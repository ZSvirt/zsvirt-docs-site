---
title: "使用分布式端口组的Windows虚拟机的DNS地址经常自动丢失，如何解决？"
---

## 现象
使用分布式端口组的Windows虚拟机的DNS地址经常自动丢失。

## 原因
Windows虚拟机存在DNS缓存问题。

## 解决方案
1.  在虚拟机控制台里，同时按下WINDOWS键和R键，在弹出窗口输入CMD并按下回车，进入CMD命令提示符窗口。

2.  在命令提示符窗口中执行`ipconfig /flushdns`，刷新虚拟机DNS缓存。

3.  在命令提示符窗口中执行`netsh winsock reset`命令，重置虚拟机winsock目录。

4.  重启虚拟机使配置生效。
