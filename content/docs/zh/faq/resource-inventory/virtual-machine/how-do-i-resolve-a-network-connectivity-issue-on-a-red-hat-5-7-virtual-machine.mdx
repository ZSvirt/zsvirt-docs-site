---
title: "RedHat 5.7虚拟机网络不通，如何解决？"
---

## 原因
默认情况下，Linux网卡中断响应会通过中断平衡守护进程（irqbalance daemon）周期性平均分配给各个CPU核心，造成网卡中断响应延迟，影响进程处理时间。

## 解决方案
1.  可通过中断平衡守护进程方式，使网卡中断响应默认由CPU0核心处理。可参考以下步骤关闭该守护进程：
2.  确认系统网卡配置文件正确。

3.  在虚拟机系统内执行以下命令，关闭中断平衡守护进程：

    ```
    [root@localhost ~]# chkconfig  irqbalance  off
    ```

4.  执行以下命令，重启虚拟机：

    ```
    [root@localhost ~]# reboot
    ```
