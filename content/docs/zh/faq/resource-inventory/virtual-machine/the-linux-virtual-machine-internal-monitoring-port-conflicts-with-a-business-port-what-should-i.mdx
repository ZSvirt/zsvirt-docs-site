---
title: "Linux虚拟机内部监控与业务端口冲突，怎么办？"
---

<HistoricalNamingNote locale="zh" />

## 原因
虚拟机内部监控使用端口与业务端口重复。

## 解决方案
1.  登录该虚拟机，执行以下命令，在`conf.yaml`配置文件中修改**collectdExporter.port**端口：

    ```
    [root@localhost ~]# vim /usr/local/zstack/zwatch-vm-agent/conf.yaml
    ```

2.  执行以下命令，重启**zwatch-vm-agent**服务：

    ```
    [root@localhost ~]# service zwatch-vm-agent restart
    ```
