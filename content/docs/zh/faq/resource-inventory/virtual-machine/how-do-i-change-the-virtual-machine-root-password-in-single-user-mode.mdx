---
title: "如何在单用户模式下修改虚拟机root密码？"
---

## 原因
若管理员忘记虚拟机root密码，且未安装QGA无法在线修改虚拟机root密码，此时需要进入单用户模式下手动修改虚拟机root密码。

## 解决方案
1.  进入虚拟机控制台，在grub启动项界面将光标定位到第一行，按**e**进入编辑模式。

2.  将光标定位到`.UTF-8`后，追加`init=/bin/sh`，需确保添加在`.UTF-8`后同一行，并注意空格。

3.  按下**Ctrl+x**引导启动。

4.  引导成功后，执行`mount -o remount,rw /`命令挂载根目录。

5.  使用`passwd`命令重设密码。

6.  执行`exec /sbin/init`或`exec /sbin/reboot`命令退出单用户模式。

7.  重启虚拟机，使用新密码登录虚拟机操作系统。
