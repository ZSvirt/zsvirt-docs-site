---
title: "Windows2016虚拟机可以ping通互联网地址，但不能通过浏览器访问这个互联网地址，怎么解决？"
---

## 现象
Windows2016虚拟机可以ping通互联网地址，但不能通过浏览器访问这个互联网地址。

## 原因
镜像为Windows2008后的版本的虚拟机中的TCP临时端口数调整为16384个，当业务访问量大，TCP连接建立过多，临时TCP端口不足，出现无法分配端口的情况，在这种情况下虚拟机无法与互联网建立TCP访问连接。

## 解决方案
1.  查看虚拟机事件日志，检查是否存在TCP端口分配失败警告。

    如[Figure 1](#fig_wwh_qy3_5xb)所示：

    ![事件日志](/docs/faq/images/ZStack_FAQ_Summary_0001_103_1.png)

2.  同时按下Windows和R键，输入CMD并按回车，在弹出的CMD命令行提示符窗口执行如下命令，按需调整Windows2016虚拟机可用临时TCP端口数，浏览器即可正常访问互联网。

    ```
    netsh int ipv4 set dynamicport tcp start=30000 num=35535
    ```

    <Callout type="info">
    在此场景下，开始端口号为30000，可用临时端口数为35535。
    </Callout>
