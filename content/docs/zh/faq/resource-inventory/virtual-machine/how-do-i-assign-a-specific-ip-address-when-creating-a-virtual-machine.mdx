---
title: "如何在新建虚拟机时指定IP？"
---

## 解决方案
-   以新建虚拟机为例，在新建虚拟机界面中，在硬件信息配置中的网卡中，勾选**通过VMTools指定IPv4/IPv6**选项，即可自定义配置虚拟机IP地址。

    <Callout type="info">
    -   若自定义配置，将按配置内容为虚拟机分配IP地址。此时应避免地址冲突，否则无法配置成功。
    -   若批量新建虚拟机时自定义配置IP地址，默认以指定IP为起始地址连续为多台虚拟机分配IP地址，当连续范围内某个指定IP已被占用时，对应虚拟机将创建失败。
    </Callout>
