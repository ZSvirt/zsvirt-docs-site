## 功能说明
-   虚拟化平台的时钟源统一由管理节点管控，所有硬件节点（含主机）均会同步此配置。在创建虚拟机时，会读取此时钟源作为系统时间，具体配置位置如下：`/usr/local/zstack/apache-tomcat/webapps/zstack/WEB-INF/classes/zstack.properties`中的**chrony.serverIp.0**。

-   Linux虚拟机内部系统时间会在创建、启动、重启等操作时读取主机时间作为时钟。

-   Windows虚拟机在创建时会自动读取主机的时间作为时钟。

-   若Windows虚拟机内部系统时间比主机时间滞后，Windows虚拟机将每隔一小时读取主机的时间作为时钟，在启动、重启等操作时也会进行同步。

-   当Windows虚拟机内部系统时间比主机时间提前时，启动、重启等操作无法读取主机的时间。

-   对时间比较敏感的业务系统，请确保时间源的准确性。对时间极度敏感的业务，例如实时计费业务，建议在虚拟机内部配置时间源，进行定时时间同步。
