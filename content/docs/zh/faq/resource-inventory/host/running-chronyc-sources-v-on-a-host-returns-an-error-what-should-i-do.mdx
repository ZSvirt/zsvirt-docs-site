---
title: "主机执行chronyc sources -v命令出现报错，怎么办？"
---

<HistoricalNamingNote locale="zh" />

## 现象
主机执行`chronyc sources -v`命令，出现`libedit.so.0: cannot open shared object file: No such file or directory`报错。

## 原因
主机缺少libedit依赖包。

## 解决方案
-   登录主机，执行以下命令手动安装libedit包：

    ```
    [root@localhost ~]# yum --disablerepo=* --enablerepo=zstack-local install -y libedit
    ```
