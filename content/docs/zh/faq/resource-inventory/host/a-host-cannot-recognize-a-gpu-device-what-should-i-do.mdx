---
title: "主机无法识别GPU设备，怎么办？"
---

## 现象
主机无法识别GPU设备，IOMMU就绪状态显示不可用。

## 原因
开启IOMMU后未重启主机。

## 解决方案
1.  迁移该主机上的所有虚拟机至其他主机。

2.  点击**资源清单** &gt; **主机与虚拟机**，进入主机界面。选中主机点击**操作** &gt; **进入维护模式**。

3.  登录该主机，执行以下命令重启主机：

    ```
    # 确认该主机上没有虚拟机运行
    [root@localhost ~]# virsh list
    [root@localhost ~]# sync;sync;reboot
    ```
