---
title: "USB设备无法识别，如何解决？"
---

## 原因
可能是由于开启了华为KVM虚拟键鼠连接。

## 解决方案
1.  SSH登录至问题主机。

2.  执行`lsusb`命令检查USB设备，检查是否存在华为KVM类型的USB设备。

3.  执行以下命令，查看USB设备详情，检查是否存在error信息：

    ```
    [root@localhost ~]# lsusb -v -d  $ID号  //步骤2查到的对应ID号
    ```

4.  确认后登录华为IBMC管理界面，取消勾选**虚拟键盘、鼠标持续连接**选项。

    如[Figure 1](#fig_mrn_sv5_p5b)所示：

    ![取消勾选虚拟键盘鼠标持续连接](/docs/faq/images/ZStack_FAQ_Summary_0012_26_1.png)

5.  重连主机。
