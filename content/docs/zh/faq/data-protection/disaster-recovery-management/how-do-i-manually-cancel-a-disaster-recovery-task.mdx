---
title: "如何手动取消灾备任务？"
---

## 解决方案
-   可通过**重启虚拟机**快速取消灾备任务。

-   若因业务限制不能重启虚拟机，可参考以下步骤：

    1.  备份过程中，可登录虚拟机所在的主机，执行以下命令查看灾备任务：

        ```
        [root@localhost ~]#  virsh qemu-monitor-command UUID --pretty '{ "execute": "query-block-jobs" }'
        ```

    2.  执行以下命令取消灾备任务：

        ```
        [root@localhost ~]#  virsh qemu-monitor-command UUID '{"execute": "block-job-cancel", "arguments": {"device": "zs-516"}}'
        ```

        <Callout type="info">
        参数**"device": "zs-516"**由步骤一中的命令查询得到。若存在两块盘，需执行两次命令，并将**device**修改为对应标号。
        </Callout>
