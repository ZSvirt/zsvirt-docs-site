---
title: "使用UltraISO刻录U盘安装操作系统，无法进入系统安装页面，如何解决？"
---

## 解决方案
1.  使用UltraISO刻录U盘安装操作系统，无法进入系统安装页面时，可尝试使用Rufus刻录ISO，并重新安装。

2.  在Rufus中打开ISO镜像。

    接入U盘，打开Rufus，引导类型选择列表选择**镜像文件（请选择）**，点击**选择**按钮，打开已下载好的ISO镜像文件。

3.  写入镜像。

    选择好ISO镜像后，其他Rufus选项按照默认设置，点击**开始**。

4.  点击**开始**后，会提示U盘数据被格式化，点击**确定**，Rufus会把ISO镜像刻录至U盘。

    <Callout type="info">
    -   若U盘中存有重要数据，请确保格式化前已做好备份。
    </Callout>

5.  此时U盘可用来作为启动盘，支持Legacy模式和UEFI模式引导。
