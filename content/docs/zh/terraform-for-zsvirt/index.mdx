---
title: "Terraform 管理 ZSvirt"
description: "使用官方 Terraform Provider 以基础设施即代码方式管理 ZSvirt。"
---

ZSvirt Terraform Provider 允许你通过 [Terraform](https://www.terraform.io/) 在 ZSvirt 平台上定义和管理云基础设施，可用于自动化创建虚拟机、网络、存储及相关平台资源。

<Callout type="info">
**ZSvirt** 由 **ZStack ZSphere** 商业化项目开源并独立发展而来，部分代码、配置和文档仍保留 **ZStack**/**ZSphere** 的历史命名（如环境变量、配置项、依赖、路径、命令等）。这些命名仅用于兼容，不影响 **ZSvirt** 正常使用。
</Callout>

## 环境要求

- [Terraform](https://www.terraform.io/downloads.html) >= 1.10.4
- [Go](https://golang.org/doc/install) >= 1.25（仅本地编译 Provider 插件时需要）

## 版本兼容

| Terraform 版本 | Provider 最低版本 | Provider 最高版本 |
| -------------- | ----------------- | ----------------- |
| >= 1.10.4      | 1.0.0             | latest            |
