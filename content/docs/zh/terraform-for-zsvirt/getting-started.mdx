## Provider 配置

```hcl
terraform {
  required_providers {
    zsphere = {
      source  = "terraform-zstack-modules/zsphere"
      version = "~> 1.0"
    }
  }
}

provider "zsphere" {
  host              = "your-zstack-host"
  access_key_id     = "your-access-key-id"
  access_key_secret = "your-access-key-secret"
}
```

## 环境变量

也可以通过环境变量配置 Provider：

```bash
export ZSPHERE_HOST="your-zstack-host"
export ZSPHERE_ACCESS_KEY_ID="your-access-key-id"
export ZSPHERE_ACCESS_KEY_SECRET="your-access-key-secret"
```

完整的 Provider 参数、认证方式及 `port` 等可选项，请参阅 [Provider 配置](/docs/terraform-for-zsphere/provider-configuration)。
