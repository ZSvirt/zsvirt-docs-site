---
title: "概述"
---

角色是一组权限的集合，为用户和用户组授予权限可获得调用相关 API 进行资源操作的能力。ZSvirt 采用了基于角色的访问控制 (RBAC) 的授权模型，将资源权限根据用户的工作职能（角色）定义权限。通过角色，您可以对用户权限进行精细控制。

-   **[权限层次结构关系](/docs/user-guide/system/iam/roles/permission-hierarchy)**  

-   **[系统预置角色](/docs/user-guide/system/iam/roles/built-in-roles)**  

-   **[新建自定义角色](/docs/user-guide/system/iam/roles/create-custom-role)**  
    为满足多样化的访问控制需求，可以新建自定义角色。

-   **[克隆角色](/docs/user-guide/system/iam/roles/clone-role)**  
    为满足多样化的访问控制需求，除新建自定义角色外，可以克隆现有角色。

-   **[修改角色权限](/docs/user-guide/system/iam/roles/modify-permissions)**  
    修改自定义角色的界面权限和 API 权限。

-   **[删除角色](/docs/user-guide/system/iam/roles/delete-role)**
