<HistoricalNamingNote locale="zh" />

一键清除当前的定制化设置，重新恢复为默认主题外观。

## 操作步骤

1.  在导航栏中，选择**系统管理** > **主题外观**。

2.  在主题外观页面，点击**恢复默认设置**。

    <Callout type="info">
    恢复默认设置后，存储在`/var/lib/zstack/static`路径下的定制化Logo图片以及发行信息将被删除。
    </Callout>
