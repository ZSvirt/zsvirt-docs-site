---
title: "管理通用存储服务器"
---

在ZSvirt主菜单，点击**存储服务** > **存储节点** > **通用存储节点**，进入服务器界面。

服务器支持以下操作：

## 添加服务器

添加一台或多台服务器。

<Callout type="info">
若当前集群中存在**未连接**状态的监控服务器，则无法添加新服务器。
</Callout>

## 删除服务器

删除服务器将停止服务器服务并删除所有相关数据，且数据将无法恢复，请谨慎操作。

<Callout type="info">
删除服务器需满足以下条件：
</Callout>

-   服务器已连接。
-   服务器所在集群处于健康状态。
-   服务器内没有正在使用的数据盘。
-   服务器没有被添加为对象网关。
-   服务器没有被添加为块网关。
