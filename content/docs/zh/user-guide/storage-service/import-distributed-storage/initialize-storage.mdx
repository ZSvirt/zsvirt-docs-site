---
title: "初始化分布式存储"
---

在服务器已完成存储软件包安装和网络配置，但尚未进行分布式存储初始化前，您可选择此方式直接初始化并接管分布式存储。

## 操作步骤

1.  在导航栏中，选择**存储服务** > **存储概览**。

2.  在存储概览页面，点击**开始初始化**。

3.  系统将自动扫描存储服务，扫描成功并满足初始化条件时，点击**初始化**。

4.  在初始化分布式存储弹窗中，参考以下示例完成初始化配置：

    管理节点配置

    -   **存储管理节点 IP**：选择分布式存储的管理节点 IP
    -   **集群**：显示所在集群位置
    网络配置

    -   **管理网络**：输入管理网络 CIDR 用于管理和配置存储集群
    -   **存储集群内部网络**：输入存储集群内部网络 CIDR 用于存储集群各节点之间数据盘监控及副本同步
    -   **存储集群对外网络**：输入存储集群对外网络 CIDR 用于存储集群对外提供服务
    -   **时间同步服务器地址**：根据系统检测的存储服务类型展示此参数。输入时间同步服务器地址用于保障存储集群各节点间的时间同步
    -   **存储网关网络**：根据系统检测的存储服务类型展示此参数。输入存储网关网络，用户业务可通过该网络访问存储资源

5.  确认配置无误后，点击**下一步**。

6.  参考以下示例完成存储配置：

    节点配置

    -   添加 3 个节点，并配置存储 IP (Public) 和存储 IP (Cluster)
    存储配置

    -   **管理监控角色**：至少选择 3 个节点配置为分布式存储的管理角色和监控角色

7.  确认配置无误后，点击**确定**。
