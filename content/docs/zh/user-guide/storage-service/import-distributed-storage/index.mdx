---
title: "概述"
---

在服务器已完成存储软件包安装和网络配置，但尚未进行分布式存储初始化前，您可选择此方式直接初始化并接管分布式存储。 在服务器已完成存储软件包安装、网络配置与系统初始化，或分布式存储已经在运行和使用时，您可选择此方式接管分布式存储。 取消接管分布式存储后，不会影响任何存储的数据，但您无法继续在平台管理分布式存储系统。
