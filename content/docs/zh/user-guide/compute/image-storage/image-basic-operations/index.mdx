-   **[添加镜像](/docs/user-guide/compute/image-storage/image-basic-operations/add-image)**  
    您可以添加多种格式的系统镜像或硬盘镜像至镜像存储中，首次新建虚拟机时，系统会下载该镜像到数据存储上作为镜像缓存。通过 URL 或本地上传方式，可将 QCOW2、ISO、RAW、VMDK 格式的镜像文件添加至镜像存储。
