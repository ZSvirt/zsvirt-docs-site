---
title: "冷迁移"
---

冷迁移为迁移关机状态下的虚拟机。

-   虚拟机所在数据存储为本地存储。
-   若虚拟机已加载 ISO 或外接设备，需提前卸载。

    <Callout type="info">
    本地存储虚拟机支持带本地数据盘冷迁移。
    </Callout>

-   若所选虚拟机已绑定调度策略，请根据业务需求进行更改，避免策略冲突。

1.  在导航栏中，选择**资源清单** > **主机与虚拟机**。

2.  选择目标虚拟机，然后点击**关机**。

3.  关机后，点击**更多操作** > **迁移管理** > **更改主机**。

4.  在更改主机弹窗中，选择目标主机。

5.  确认配置无误后，点击**确定**。

迁移后，您可将卸载的数据盘、ISO、与外接设备重新加载至该虚拟机。
