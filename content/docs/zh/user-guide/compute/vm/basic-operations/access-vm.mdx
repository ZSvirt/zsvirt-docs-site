---
title: "访问虚拟机"
---

支持一键打开虚拟机控制台，快速进入虚拟机内进行各种操作，例如安装操作系统、配置操作系统、执行命令、运行程序等。ZSvirt 提供以下选择：

-   通过控制台访问虚拟机
-   通过 SSH 访问虚拟机

-   **[（可选）管理虚拟机访问和引导选项](/docs/user-guide/compute/vm/basic-operations/access-options)**  

-   **[通过控制台访问虚拟机](/docs/user-guide/compute/vm/basic-operations/console-access)**  
    通过控制台快速访问虚拟机，执行各种操作，例如安装操作系统、配置操作系统、执行命令、运行程序等。

-   **[通过 SSH 访问虚拟机](/docs/user-guide/compute/vm/basic-operations/ssh-access)**  
    使用 SSH 连接协议访问虚拟机。
