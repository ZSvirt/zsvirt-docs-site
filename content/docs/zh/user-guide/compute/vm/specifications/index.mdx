---
title: "概述"
---

支持为 Windows 或 Linux 虚拟机的操作系统创建和管理自定义规范。虚拟机规范是包含虚拟机操作系统配置的文件。

使用虚拟机自定义规范，可以在通过模板批量部署虚拟机时，避免可能出现的冲突，如虚拟机主机名重复或 SID 重复而产生的冲突。

-   **[新建 Windows 虚拟机规范](/docs/user-guide/compute/vm/specifications/create-windows)**  
    在自定义规范中保存 Windows 虚拟机操作系统的系统设置，如虚拟机网络参与方式、主机名配置等。

-   **[新建 Linux 虚拟机规范](/docs/user-guide/compute/vm/specifications/create-linux)**  
    在自定义规范中保存 Linux 虚拟机操作系统的系统设置，如主机名配置。

-   **[管理虚拟机规范](/docs/user-guide/compute/vm/specifications/manage)**
