---
title: "虚拟机克隆为模板"
---

复制一个虚拟机副本作为模板。源虚拟机在克隆为模板后仍可继续使用。

-   虚拟机电源需处于运行中、暂停、关机、或故障状态。
-   虚拟机未挂载共享硬盘或 RDM 硬盘。若已挂载，需手动卸载后再克隆为模板。

1.  在导航栏中，选择**资源清单** > **主机与虚拟机**。

2.  选择目标虚拟机，然后点击**更多操作** > **克隆** > **克隆为模板**。

3.  在克隆为模板弹窗，参考以下示例完成配置：

    -   **名称**：输入模板名称

        <Callout type="info">
        不能和已有虚拟机或模板的名称重复。
        </Callout>

    -   **数据存储**：模板存放位置。默认与源虚拟机数据存储一致
    -   **标签**：绑定标签，用于识别不同模板。有关更多信息，请参阅 [标签管理](/docs/user-guide/operations/tags)
    <Callout type="info">
    若虚拟机加载有 GPU 设备、USB 设备、PCIe 设备（SR-IOV 类型网卡自动绑定的 PCIe 设备除外），克隆的模板将不会包括这些外接设备。如需保留，可将虚拟机转换为模板。
    </Callout>

4.  确认配置无误后，点击**确定**。

将虚拟机克隆为模板后，您可以基于此模板快速部署同属性虚拟机。

可对模板进行修改，而不影响源虚拟机的正常使用。
