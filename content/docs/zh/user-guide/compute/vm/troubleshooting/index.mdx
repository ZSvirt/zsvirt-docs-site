---
title: "虚拟机故障处理篇"
---

虚拟机故障是指在运行过程中，由于负载过重或其他原因，Windows 虚拟机出现蓝屏或 Linux 虚拟机出现卡死的状态。您可通过虚拟机故障处理策略设置虚拟机出现故障后的自动处理策略。

-   仅支持 CPU 架构为 x86\_64 的虚拟机设置故障处理策略。
-   设置前需为虚拟机安装 VMTools，并确保 VMTools 处于正常运行状态。有关 VMTools 的更多信息，请参阅 [虚拟机VMTools篇](/docs/user-guide/compute/vm/vmtools)。
-   故障处理策略设置后立即生效，无需重启虚拟机。

1.  在导航栏中，选择**资源清单** > **主机与虚拟机**。

2.  选择目标虚拟机，然后点击**更多操作** > **高级设置** > **修改VMTools**。

3.  在修改 VMTools 设置弹窗中，按需修改虚拟机故障处理策略。

    -   不处理（默认）：故障后保持当前状态，不处理。
    -   重启：故障后自动重启虚拟机。默认 30 分钟内重启达 5 次后，将不再重启，保持故障状态。
    -   关机：故障后自动将虚拟机关机。
    <Callout type="info">
    对于 Linux 虚拟机，开启后在下次启动时关闭 `kdump` 模块 。
    </Callout>

4.  点击**确定**。
