---
title: "备份新建虚拟机"
---

如果虚拟机发生故障，您可以基于备份数据直接创建新虚拟机。这种数据恢复方式是非破坏性的，不会覆盖现有虚拟机，而是基于备份数据创建一台新的虚拟机。

## 前提条件

-   确保虚拟机至少有一个成功生成的备份数据节点。
-   确保平台有充足的计算、存储、网络资源可支撑新虚拟机。
-   若使用异地备份数据新建虚拟机，需先将异地备份数据同步至本地再进行新建。

## 操作步骤

1.  在导航栏中，选择**数据保护** > **已保护资源**。

2.  在已保护资源页面，选择**虚拟机**选项卡。

3.  选择要还原的虚拟机的备份数据，然后点击**新建虚拟机**。

4.  在备份新建虚拟机弹窗中，参考以下示例完成配置：

### 备份信息

    -   **备份数据**：显示所选备份数据

### 基本信息

    -   **名称**：虚拟机名称
    -   **数量**：默认为 1，不支持修改
    -   **分组**：虚拟机所在分组，若不设置，则使用默认分组
    -   **运行位置**：虚拟机所在主机或集群位置
    -   **操作系统**：显示备份数据中记录的虚拟机操作系统
    -   **高可用**：虚拟机异常关机后自动重启机制，有关更多信息，请参阅 虚拟机高可用篇
    -   **电源状态**：虚拟机新建完成后是否自动开机

### 硬件信息

    -   **CPU**：支持调整总核数
    -   **内存**：支持调整内存大小
    -   **硬盘**：显示备份数据中记录的硬盘配置，不支持修改
    -   **网卡**：支持调整端口组、MAC 地址、IP 地址、DNS 分配方式、安全组

        通过点击**添加网卡**为虚拟机添加新网卡。新网卡可自定义网卡地址与特性。

5.  确认配置无误后，点击**确定**。

虚拟机部分配置依赖 VMTools 实现。虚拟机新建完成后，建议安装 VMTools 以使部分配置生效。有关 VMTools 的更多信息，请参阅 虚拟机VMTools篇。
