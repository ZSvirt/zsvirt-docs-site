---
title: "复用主机"
---

复用现有主机资源，利用主机空闲容量存储本地备份数据。

## 前提条件

-   平台中已有主机资源，且要求为已连接、已启用的主机。
-   已提前规划好备份网络。

## 操作步骤

1.  在导航栏中，选择**数据保护** > **备份存储**。

2.  在备份存储页面，点击**添加备份存储**。

3.  在请选择备份存储添加方式弹窗中，选择**复用主机**，然后点击**下一步**。

4.  在添加本地备份存储弹窗中，参考以下示例完成配置：

### 基本信息

    -   **名称**：本地备份存储名称
    -   **简介**：本地备份存储简介
    -   **数据中心**：显示备份存储所在数据中心
    -   **添加方式**：显示**复用主机**

### 配置信息

    -   **主机**：选择已有主机，将所选主机作为本地备份存储
    -   **备份存储路径**：填写本地备份存储上的挂载路径

        <Callout type="info">
        不能使用 `/`、`/dev/`、`/proc/`、`/sys/`、`/usr/bin`、`/bin` 等系统目录，否则可能导致主机异常。
        </Callout>

    -   **备份网络**：备份单独使用的网络，填写备份网络 CIDR
    -   **备份数据**：选择是否扫描已有备份数据

5.  确认配置无误后，点击**确定**。
