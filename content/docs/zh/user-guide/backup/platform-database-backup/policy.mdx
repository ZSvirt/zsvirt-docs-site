## 备份策略

### 备份周期

备份周期决定备份执行的频率。ZSvirt 为平台数据库备份提供按周备份、按天备份和按小时备份三种选项。

### 执行时间

若备份周期选择按周或按天备份时，您可以设置更细粒度的备份执行时间，支持选择到分钟级。

-   按周备份：执行时间设置为**周日 周二 00:00**时，表示该备份将在每周日和每周二的 0 点 0 分 0 秒开始执行。
-   按天备份：执行时间设置为**00:30**时，表示该备份将在每天的 0 点 30 分 0 秒开始执行。

### 开始时间

备份计划从开始时间开始，按照已设置的备份周期及执行时间进行备份。

## 保留策略

每次成功执行备份都会生成一份备份数据，用于将平台数据库恢复到之前的时间点。要控制备份数据数量，必须指定备份数据保留策略。基于备份场景，ZSvirt 可分别为本地备份数据和异地备份数据设置保留策略。

-   本地保留策略：
    -   按数量保留：最小允许保留最近 1 份本地备份数据。
    -   按时间保留：最小允许保留最近 1 天的本地备份数据。
-   异地保留策略：
    -   永久保留：异地备份数据将不会被自动清理。
    -   按数量保留：最小允许保留最近 1 份异地备份数据。
    -   按时间保留：最小允许保留最近 1 天的异地备份数据。

<Callout type="info">
保留策略之外的备份数据仅删除记录，不影响数据安全性。
</Callout>
