---
title: "新建备份计划"
---

## 前提条件

-   确保平台备份授权额度充足。
-   ZSvirt 仅支持 1 个平台数据库备份计划。确保无已有平台数据库备份计划。

## 操作步骤

1.  在导航栏中，选择**数据保护** > **备份计划**。

2.  在备份计划页面，点击**新建备份计划**。

3.  在新建备份计划弹窗中，完成基础配置和备份配置。

4.  对于**基础配置**，参考以下示例完成配置：

    **基本信息**

    -   **名称**：备份计划名称
    -   **简介**：备份计划简介
    -   **数据中心**：选择数据中心

    **备份存储**

    -   **本地备份存储**：添加本地备份存储服务器，最多允许指定 2 个备份存储，支持主备无缝切换
    -   **同步到异地备份存储**：默认关闭，可选择是否将本地备份数据同步至异地备份存储

        <Callout type="info">
        若开启，需提前在平台添加异地备份存储。有关更多信息，请参阅 [添加异地备份存储](/docs/user-guide/backup/backup-storage/remote)。
        </Callout>

        -   **异地备份存储**：开启同步到异地备份存储后，显示异地备份存储名称和可用容量

    **备份对象**

    -   **备份对象类型**：选择平台数据库

        <Callout type="info">
        若已有平台数据库备份计划，则不展示平台数据库选项。
        </Callout>

5.  确认基础配置无误后，点击**下一步**。

6.  对于**备份配置**，参考以下示例完成配置：

    **备份策略**

    -   **备份周期**：按需选择备份周期，包括按周备份、按天备份、按小时备份
    -   **执行时间**：备份周期选择按周或按天备份后，需设定执行时间
    -   **开始时间**：设置备份计划开始时间
    有关备份策略的更多信息，请参阅 [备份策略](/docs/user-guide/backup/platform-database-backup/policy)。

    **保留策略**

    -   **本地保留策略**：按数量或按时间设置本地备份保留策略
    -   **异地保留策略**：开启**同步到异地备份存储**后，需设置此参数。设置永久保留、按数量或按时间设置异地备份保留策略
    有关保留策略的更多信息，请参阅 [备份策略](/docs/user-guide/backup/platform-database-backup/policy)。

7.  确认配置无误后，点击**确定**。

执行备份后，您可以使用备份数据恢复平台数据库。有关更多信息，请参阅 数据恢复。
