---
title: "查看平台数据库备份数据"
---

<HistoricalNamingNote locale="zh" />

ZSvirt 提供统一入口方便用户查看已保护资源的备份数据，避免遗漏备份重要业务。

## 操作步骤

1.  在导航栏中，选择**数据保护** > **已保护资源**。

2.  进入已保护资源页面，选择**平台数据库**选项卡。

3.  查看平台数据库备份数据。

    平台数据库备份数据页面以数据存放位置划分为两个子页面：

    -   管理节点备份：备份文件存放在管理节点，默认存放路径为 `/var/lib/zstack/mysql-backup/`。
    -   本地备份：备份文件存放在本地备份存储中。
    -   异地备份：备份文件存放在异地备份存储中。
    按需选择对应位置后，您可以查看该平台数据库备份的名称、管理节点 IP、版本、容量、备份存储路径（或是否同步到异地/本地）以及创建时间。
