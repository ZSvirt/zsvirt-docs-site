---
title: "查看虚拟机备份数据"
---

备份计划执行期间会生成一系列备份数据，这些备份数据保存在指定的备份存储中。ZSvirt 提供统一入口方便用户查看已保护资源的备份数据，避免遗漏备份重要业务。

## 操作步骤

1.  在导航栏中，选择**数据保护** > **已保护资源**。

2.  进入已保护资源页面，选择**虚拟机**选项卡。

3.  查看虚拟机备份数据。

    虚拟机备份数据页面以单台虚拟机为单位，通过树形文件夹形式展示每台已保护虚拟机的备份数据。每台虚拟机文件夹下，关于该虚拟机的所有备份数据基于最新创建日期自上而下排列。

    -   选择虚拟机后，您可以查看该虚拟机的电源状态、备份数据总容量、关联的备份计划、UUID、以及该虚拟机所有的备份数据。
    -   选择虚拟机的某个备份数据后，您可以查看该备份数据的基本信息和备份信息，包括所属虚拟机、备份容量、备份类型、所属备份存储、是否同步到异地备份存储、所有者、UUID、创建时间、以及详细备份信息。
