title: "概述"
---

备份计划执行期间，您可以查看备份计划的执行情况，实时掌握备份动态。有关更多信息，请参阅 [查看备份计划执行情况](/docs/user-guide/backup/vm-backup/view-plans-and-data/view-plan-execution)。

备份计划执行期间，会生成一系列备份数据，您可以查看已保护资源的备份数据。有关更多信息，请参阅 [查看虚拟机备份数据](/docs/user-guide/backup/vm-backup/view-plans-and-data/view-vm-backup-data)。

-   **[查看备份计划执行情况](/docs/user-guide/backup/vm-backup/view-plans-and-data/view-plan-execution)**  

-   **[查看虚拟机备份数据](/docs/user-guide/backup/vm-backup/view-plans-and-data/view-vm-backup-data)**  
    备份计划执行期间会生成一系列备份数据，这些备份数据保存在指定的备份存储中。ZSvirt 提供统一入口方便用户查看已保护资源的备份数据，避免遗漏备份重要业务。
