---
title: "新建备份计划"
---

## 前提条件

-   确保平台备份授权额度充足。
-   确保要执行备份的虚拟机处于运行中或暂停状态，且未绑定其他备份计划。
-   若虚拟机所在数据存储为 ZHPS 分布式存储，则不支持绑定备份计划。

## 操作步骤

1.  在导航栏中，选择**数据保护** > **备份计划**。

2.  在备份计划页面，点击**新建备份计划**。

3.  在新建备份计划弹窗中，完成基础配置和备份配置。

4.  对于**基础配置**，参考以下示例完成配置：

    **基本信息**

    -   **名称**：备份计划名称
    -   **简介**：备份计划简介
    -   **数据中心**：选择数据中心

    **备份存储**

    -   **本地备份存储**：添加本地备份存储服务器，最多允许指定 2 个备份存储，支持主备无缝切换
    -   **同步到异地备份存储**：默认关闭，可选择是否将本地备份数据同步至异地备份存储

        <Callout type="info">
        若开启，需提前在平台添加异地备份存储。有关更多信息，请参阅 [添加异地备份存储](/docs/user-guide/backup/backup-storage/remote)。
        </Callout>

        -   **异地备份存储**：开启同步到异地备份存储后，显示异地备份存储名称和可用容量

    **备份对象**

    -   **备份对象类型**：选择**虚拟机**
    -   **虚拟机**：添加需备份的虚拟机，按需设置备份优先级

       <Callout type="info">

        -   选择的虚拟机数量不得超出备份授权额度。
        -   若所选虚拟机已有备份数据，新建备份计划不会额外占用备份授权额度。
        -   默认对虚拟机进行整机备份，若虚拟机带共享硬盘或 RDM 盘，则不会备份该共享硬盘和 RDM 盘。

       </Callout>

5.  确认基础配置无误后，点击**下一步**。

6.  对于**备份配置**，参考以下示例完成配置：

    **备份策略**

    -   **备份模式**：按需选择默认增量备份或自定义增量备份
    -   **增量备份策略**：自定义增量备份策略，包括备份周期和执行时间
    -   **全量备份策略**：备份模式选择自定义增量备份时，需自定义全量备份备份策略，包括备份周期和执行时间
    -   **备份链最大长度**：显示当前备份策略下的备份链长度，最大长度不超过 64
    -   **开始时间**：设置备份计划开始时间
    -   **硬盘读取速度**：设置硬盘读取速度上限，不填写则默认无限制。单位：MB/s、GB/s，取值范围：1MB/s~100GB/s。

        <Callout type="info">
        QoS 设置建议与物理环境网络带宽相匹配，并且需考虑并发备份所占带宽。
        </Callout>

    有关备份策略的更多信息，请参阅 [备份策略](/docs/user-guide/backup/vm-backup/policy)。

    **保留策略**

    -   **本地保留策略**：按数量或按时间设置本地备份保留策略
    -   **异地保留策略**：开启**同步到异地备份存储**后，需设置此参数。设置永久保留、按数量或按时间设置异地备份保留策略
    有关保留策略的更多信息，请参阅 [备份策略](/docs/user-guide/backup/vm-backup/policy)。

7.  确认配置无误后，点击**确定**。

执行备份后，您可以使用备份数据恢复虚拟机。有关更多信息，请参阅 数据恢复。
