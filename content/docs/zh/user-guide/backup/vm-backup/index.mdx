---
title: "概述"
---

ZSvirt 的备份服务是基于周期性的计划备份。要执行备份，您需先配置备份计划。有关更多信息，请参阅 新建备份计划。 在执行备份计划期间，其备份模式、备份数据链长度、备份数据保留策略以及备份 QoS 都取决于所配置的备份策略。有关更多信息，请参阅 备份策略。
