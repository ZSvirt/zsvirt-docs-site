## 备份策略

### 备份模式

ZSvirt 提供两种备份模式：

-   默认增量备份

    您只需自定义设置增量备份策略，全量备份策略由系统默认设置。当增量备份执行 63 次后，系统将自动执行 1 次全量备份，备份链最大长度为 64。

-   自定义增量备份

    您需自定义设置增量备份策略和全量备份策略。通过自定义配置全量备份策略，缩短全量备份间隔。全量备份数量增加，备份链缩短，恢复时合并的备份数据减少。

### 备份周期

备份周期决定备份执行的频率。

-   对于增量备份策略，ZSvirt 提供包括按月备份、按周备份、按天备份、按小时备份和按分钟备份在内的多种选项。
-   对于全量备份策略，ZSvirt 支持按月备份和按周备份。

### 执行时间

您可以设置更细粒度的备份执行时间，支持选择到分钟级。其中增量备份策略的备份周期选择按月、按周或按天备份时，可设置增量备份执行时间；全量备份策略的备份周期选择按月或按周备份时，可设置全量备份执行时间。

-   按月备份：执行时间设置为**每 1 个月 1 日 00:00**时，表示该备份将在每月 1 日的 0 点 0 分 0 秒开始执行。
-   按周备份：执行时间设置为**周日 周二 00:00**时，表示该备份将在每周日和每周二的 0 点 0 分 0 秒开始执行。
-   按天备份：执行时间设置为**00:30**时，表示该备份将在每天的 0 点 30 分 0 秒开始执行。

### 开始时间

备份计划从开始时间开始，按照已设置的备份周期及执行时间进行备份。

## 保留策略

每次成功执行备份都会生成一份备份数据，用于将虚拟机数据恢复到之前的时间点。要控制备份数据数量，必须指定备份数据保留策略。基于备份场景，ZSvirt 可分别为本地备份数据和异地备份数据设置保留策略。

-   本地保留策略：
    -   按数量保留：最小允许保留最近 1 份本地增量备份数据和最近 1 份本地全量备份数据。
    -   按时间保留：最小允许保留最近 1 天的本地备份数据。
-   异地保留策略：
    -   永久保留：异地备份数据将不会被自动清理。
    -   按数量保留：最小允许保留最近 1 份异地增量备份数据和最近 1 份异地全量备份数据。
    -   按时间保留：最小允许保留最近 1 天的异地备份数据。

<Callout type="info">
保留策略之外的备份数据仅删除记录，不影响数据安全性。
</Callout>
