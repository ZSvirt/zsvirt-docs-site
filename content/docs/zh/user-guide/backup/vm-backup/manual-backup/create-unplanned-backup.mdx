---
title: "创建计划外备份"
---

除了通过将虚拟机添加进备份计划来执行备份这种方式外，您还可以为虚拟机创建一个计划外的备份。

## 前提条件

-   若虚拟机所在数据存储为 ZHPS 分布式存储，则不支持创建备份。
-   若虚拟机已加载共享盘或 RDM 盘，则创建备份不会备份共享盘或 RDM 盘。

## 操作步骤

1.  在导航栏中，选择**资源清单** > **主机与虚拟机**。

2.  在左侧导航树中，右键单击虚拟机，然后选择**备份** > **创建备份**。

3.  在创建备份弹窗中，输入备份名称、选择备份类型、指定本地备份存储、选择是否同步到异地备份存储。

4.  确认信息无误后，点击**确定**。

创建备份成功后，可前往已保护资源页面查看该虚拟机的备份数据。
