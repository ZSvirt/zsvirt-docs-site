---
title: "新建标签"
---

创建不同颜色、简约样式、精简定义的标签。

1.  在导航栏中，选择**运维管理** > **标签**。

2.  在标签页面，点击**新建标签**。

3.  在新建标签弹窗中，参考以下示例完成配置：

    -   **标签预览**：显示标签的预览效果
    -   **名称**：输入标签名称

       <Callout type="info">

        -   标签具有唯一性，相同角色只允许创建一个同名称同颜色的标签。
        -   标签名称长度需保持在 20 个字符内。

       </Callout>
    -   **简介**：可选项。输入标签的描述
    -   **颜色**：选择标签颜色

4.  确认配置无误后，点击**确定**。
