---
title: "覆盖恢复虚拟机"
---

如果虚拟机发生故障，您可以将虚拟机从备份数据还原到最新备份时间点的状态，或还原到之前的一个备份时间点的状态。

-   确保虚拟机至少有一个成功生成的备份数据节点。
-   使用覆盖恢复方式还原虚拟机时，需先将虚拟机关机。
-   若使用异地备份数据恢复虚拟机，需先将异地备份数据同步至本地后再进行恢复。

1.  在导航栏中，选择**数据保护** > **已保护资源**。

2.  在已保护资源页面，选择**虚拟机**选项卡。

3.  选择要还原的虚拟机的备份数据，然后点击**覆盖恢复**。

4.  在覆盖恢复虚拟机弹窗中，按需勾选是否恢复后自动开机。

5.  确认信息无误后，点击**确定**。

    <Callout type="warning">
    覆盖恢复虚拟机将清除虚拟机当前数据，并将虚拟机数据恢复到所选备份数据节点，请谨慎操作。
    </Callout>
