---
title: "VMTools 适配 OS 列表"
---

不同操作系统对 VMTools 的适配程度不同，下表为各操作系统与 VMTools 的适配情况。

<Callout type="info">
表格中，**是**表示支持通过 VMTools 为虚拟机安装此组件，并正常使用相关功能；**否**仅表示不支持通过 VMTools 为虚拟机安装此组件，或安装后可能无法使用依赖该组件的功能。并非表示不支持此组件，您仍可通过其他方式安装此组件。
</Callout>
