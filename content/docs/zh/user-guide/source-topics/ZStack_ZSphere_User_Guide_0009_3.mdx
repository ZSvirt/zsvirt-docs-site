若您作为运维管理员，希望查看某一个数据中心下核心物理和虚拟资源使用情况、告警统计、登录等信息，可导航至**菜单** > **主页**页面，在左上角选择希望查看的数据中心，例如Datacenter-1。

在您查看数据前，可提前了解以下信息：

-   每次进入或刷新首页均能获取最新数据并实时展示。此外，图表类模块默认30秒自动刷新一次数据。
-   状态统计类图表采用统一的色彩规范，绿色表示正常状态、红色表示异常状态、灰色表示其他状态，方便用户快速识别资源健康状态。
-   百分比进度条包括蓝（小于60%）、黄（大于等于60%并且小于80%）、红（大于等于80%）三色，直观展示当前资源的使用状态。

## 虚拟机

Top10：虚拟机CPU使用率

-   虚拟机名称列表，支持跳转至相应虚拟机

## 主机

统计对象：数据中心里主机数量

 统计信息：

-   总数量
-   已连接的主机数量
-   未连接的主机数量
-   其他就绪状态的主机数量

## CPU使用率

统计对象：数据中心里所有可用主机，即已启用且处于已连接状态的主机

 统计信息：

-   所有可用主机的逻辑CPU核总量
-   所有可用主机CPU平均使用率

## 内存使用率

统计对象：数据中心里所有可用主机，即已启用且处于已连接状态的主机

 统计信息：

-   所有可用主机平均内存使用率
-   所有可用主机已用内存总量
-   所有可用主机内存总量

## CPU分配比

统计对象：数据中心里所有可用主机CPU

 统计信息：

-   已分配给虚拟机使用的vCPU核总数
-   所有可用主机的物理CPU核总数，即可用于超配的核数
-   所有可用主机的CPU分配比，即：已分配给虚拟机的vCPU核总数/所有可用主机的物理CPU核总数

## 内存分配比

统计对象：数据中心里所有可用主机内存

 统计信息：

-   已分配给虚拟机使用的虚拟内存总量
-   所有可用主机的物理内存总量，即可用于超配的内存
-   所有可用主机的内存分配比，即：已分配给虚拟机的虚拟内存总量/所有可用主机的物理内存总量

## 告警统计

通过以下两个维度展示近七日未读的告警统计信息：

-   根据告警紧急程度分别展示紧急、严重、和提示的告警数量
-   展示已发生告警的事件信息，包括事件名称、发生时间、告警次数，告警等级（通过颜色标识），您可点击对应事件查看告警详情信息

## 最新访问

显示6条最近访问的菜单记录。点击右上角删除按钮，支持清空记录。

## 用户信息

显示当前的登录用户以及当前的平台时间。
