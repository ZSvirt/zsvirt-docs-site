---
title: "使用 KMS 证书和私钥方式使 KMS 信任"
---

某些 KMS 厂商要求将 KMS 服务器证书和私钥上传到 ZSvirt。

1.  导航至密钥提供程序页面。

2.  找到要建立信任的标准密钥提供程序，点击**操作** > **建立信任** > **使KMS信任**。

3.  在使KMS信任弹窗中，选择**KMS证书和私钥**作为信任方式。

4.  点击**下一步**。

5.  将从 KMS 中收到的证书和私钥文件上传，或将证书和私钥内容粘贴至文本框中。

6.  点击**确定**。

建立双向信任，请参阅 [ZSvirt 信任 KMS](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0009_53_1_2_2)。
