---
title: "升级迁移服务"
---

-   确保没有正在进行中的迁移任务，否则将无法升级迁移服务。
-   确保镜像存储有足够的存储空间，再上传迁移服务升级包。

1.  在导航栏中，选择**运维管理** > **迁移服务** > **迁移概览**。

2.  在迁移概览页面，点击**升级**。

3.  在升级迁移服务弹窗中，参考以下示例完成配置：

    -   **迁移服务版本**：展示当前部署的服务版本
    -   **上传方式**：选择上传安装包的方式，包括 URL 和本地上传
    -   **URL/安装包**：输入 URL 或上传安装包文件
    -   **存储路径**：指定一个目录路径，用于存放上传的升级包及其解压后的文件

       <Callout type="info">

        -   请确保该目录具备充足的可用空间，否则将导致安装失败。
        -   不能使用 `/`、`/dev`、`/proc`、`/sys`、`/usr/bin`、`/bin`、`/opt` 等系统目录，否则可能导致服务器异常。

       </Callout>

4.  点击**确定**。

若升级失败，可重新升级。支持使用现有升级包或重新上传升级包。
