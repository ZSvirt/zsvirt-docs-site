---
title: "模板转换虚拟机"
---

将模板直接转为虚拟机。要编辑模板配置或者不再需要将虚拟机保留为用于部署虚拟机的模板时，可以将模板转换为虚拟机。

-   若模板的硬盘文件已被删除，则无法转换为虚拟机。
-   若模板网卡所在的分布式端口组已被删除，则无法转换为虚拟机。

1.  在导航栏中，选择**资源清单** > **镜像与模板**。

2.  在模板文件中，选择目标模板，然后点击**操作** > **转换为虚拟机**。

3.  在转换为虚拟机弹窗中，参考以下示例完成配置：

    -   **名称**：输入虚拟机名称
    -   **电源状态**：是否转换后自动开机虚拟机
    -   **运行位置**：默认自动分配，选择虚拟机所在主机或集群
        -   本地存储场景下，不支持指定虚拟机运行位置，默认为本地盘所在主机。
        -   非本地存储场景下，支持指定虚拟机运行位置。

4.  确认配置无误后，点击**确定**。

将模板转换为虚拟机后，您可对虚拟机配置进行按需调整，再将虚拟机转换回模板。
