---
title: "添加内置密钥提供程序"
---

ZSvirt 提供内置密钥提供程序，允许您无需第三方 KSM，也可启用加密相关的功能。

1.  在导航栏中，选择**资源清单** > **主机与虚拟机**。

2.  选择根节点。

3.  在根节点详情页，点击**密钥提供程序**。

4.  在密钥提供程序子页面，点击**添加密钥提供程序**。

5.  在添加密钥提供程序弹窗中，参考以下示例完成配置：

    -   **名称**：输入密钥提供程序名称

        <Callout type="info">
        每个密钥提供程序的名称将作为标识符，请确保名称全局唯一。
        </Callout>

    -   **简介**：为密钥提供程序输入简要说明
    -   **类型**：选择**内置密钥提供程序**

6.  点击**确定**。

    添加成功后，密钥提供程序状态显示为"未备份"。

添加内置密钥提供程序后，需先完成备份后再使用。有关更多信息，请参阅 [备份内置密钥提供程序](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0009_53_2_2)。
