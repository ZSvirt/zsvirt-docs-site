---
title: "创建测试虚拟机"
---

确保迁移任务状态不为"割接中"，否则将无法执行创建测试虚拟机操作。

1.  在导航栏中，选择**运维管理** > **迁移任务** > **所有任务**。

2.  在所有任务页面，选择目标迁移任务，然后点击**操作** > **测试** > **创建测试虚拟机**。

3.  在创建测试虚拟机弹窗中，参考以下示例完成配置：

    -   **CPU**：设置虚拟机的 CPU 数量
    -   **内存**：设置虚拟机的内存大小
    -   **网络**：选择虚拟机要使用的分布式端口组
    -   **CIDR**：系统根据所选网络自动获取 CIDR
    -   **IPv4地址**：根据所选网络配置决定 IP 地址分配方式
        -   若所选分布式端口组已启用 DHCP，则默认自动分配 IPv4 地址。您也可手动指定 IP 地址，指定的 IP 地址需在 CIDR 内。
        -   若所选分布式端口组未启用 DHCP，则必须手动指定 IP 地址，指定的 IP 地址需在 CIDR 内。
        -   若所选分布式端口组未启用 IPAM，则不展示 CIDR 参数。您需手动指定 IP 地址。
    -   **系统转换策略**：指定虚拟机启动前的系统转换策略
        -   **执行系统转换**：执行完整的系统转换，包括：驱动替换或注入、目标虚拟机网卡名称与 IP 地址配置、后置脚本执行。
        -   **执行系统转换但不加载目标驱动程序**：不执行驱动替换，仅配置目标虚拟机网卡名称与 IP 地址，并执行后置脚本。
        -   **跳过系统转换**：不执行驱动替换，不配置网卡名称与 IP 地址，不执行后置脚本。您需要登录目标虚拟机系统手动完成上述配置。
    -   **数据恢复点**：使用某个时间的快照或副本，进行虚拟机恢复测试

4.  确认配置无误后，点击**确定**。
