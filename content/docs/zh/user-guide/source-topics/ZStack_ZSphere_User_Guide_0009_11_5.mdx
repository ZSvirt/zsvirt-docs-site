---
title: "镜像模板封装篇"
---

您可以将虚拟机进行定制并保存为镜像模板文件，通过该镜像您可以大批量部署相同配置的虚拟机。平台支持基于虚拟机创建系统镜像和硬盘镜像。系统镜像针对硬盘1创建镜像，硬盘镜像可选择所有硬盘，包括硬盘1。

您可以参考以下步骤封装一个镜像模板：

1.  添加镜像至镜像存储
2.  使用镜像新建虚拟机
3.  自定义虚拟机配置
4.  使用虚拟机制作镜像模板

1.  添加镜像至镜像存储。

    关于如何添加镜像，详情可参考[添加镜像](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0009_11_6)。

2.  使用镜像新建虚拟机。

    您可以通过多种方式使用镜像新建虚拟机：

    -   在步骤1中新添加的镜像处，右键点击**新建虚拟机**。
    -   在**镜像存储** > **镜像**子页面，选择步骤1添加的镜像，然后点击**操作** > **新建虚拟机**。
    -   在新建虚拟机时，光驱选择步骤1中添加的镜像。
    关于新建虚拟机时如何填写其它配置信息，详情可参考[新建虚拟机-标准风](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0009_14_4)。

3.  自定义虚拟机配置。

    您可以对步骤2中创建的虚拟机进行自定义配置，包括计算、存储、网络相关配置。

    例如：若您希望基于模板创建的虚拟机可自动获取IP地址，您可以执行以下命令修改网卡相关配置：

    ```
    #设置开机自动激活网卡
    [root@localhost ~]# sed -i '/ONBOOT=/cONBOOT=yes' /etc/sysconfig/network-scripts/ifcfg-ens3
    #删除网卡配置文件中的UUID
    [root@localhost ~]# sed -i '/^UUID'/d /etc/sysconfig/network-scripts/ifcfg-ens3
    #删除网卡配置文件中的物理地址
    [root@localhost ~]# sed -i '/^HWADDR'/d /etc/sysconfig/network-scripts/ifcfg-ens3
    ```

4.  使用虚拟机制作镜像模板。

    在您完成虚拟机自定义配置后，您可以参考以下建议使用镜像模板：

    -   若您希望在平台内直接使用该镜像模板部署虚拟机，可导航至步骤3中配置的虚拟机处，点击**更多操作** > **快照和镜像** > **创建镜像**。镜像创建成功后，您可以在同一集群下的镜像存储中找到该镜像，后续您便可使用该镜像部署相同配置的虚拟机。
    -   若您希望跨平台部署相同配置的虚拟机，您可以选择导出镜像或将虚拟机导出为OVA模板，实现跨平台业务迁移。详情可参考[镜像跨平台使用篇](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0009_11_4)。
