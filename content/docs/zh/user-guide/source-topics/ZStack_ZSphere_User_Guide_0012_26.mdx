---
title: "迁移服务"
---

迁移服务支持将其他虚拟化平台中的虚拟机系统及数据完整迁移至当前平台。支持的源平台包括 VMware vSphere 和其他基于 KVM 的云平台。通过分步向导指引，完成端到端的迁移流程。

-   **[安装部署迁移服务](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0012_26_1)**  

-   **[管理迁移服务](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0012_26_4)**  

-   **[迁移资源管理](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0012_26_8)**  

-   **[迁移任务管理](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0012_26_13)**
