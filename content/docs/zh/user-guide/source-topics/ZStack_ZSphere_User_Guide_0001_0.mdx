---
title: "产品开发背景"
---

随着信息技术的发展，业务信息化已成必然趋势，业务对于性能、安全、以及稳定性的要求日益严苛。同时，在国产化大浪潮下，业务对于信创虚拟化产品的需求也变得日益紧迫。

**高性能要求**：高性能业务作为用户降本增效的重要抓手，虚拟化虽解决了资源利用率和运维效率低下的问题，但日益增加的高性能业务对底层承载的平台提出了更高的性能需求，例如：

-   最大化减少计算资源性能损耗
-   高效提升业务上线效率
-   无损利用各类网络资源
-   灵活接入高性能存储

**高安全要求**：随着网络基础设施日益完善，愈来愈多的数据线上化，如何保障业务安全稳定运行成为核心诉求。因此，平台自身需具备全覆盖、多维度的安全能力，例如：

-   可确保底层操作系统安全运行，不受病毒侵扰
-   支持商业密码安全应用于各类行业和领域
-   支持自定义规则按需过滤业务流量

**高稳定性要求**：平台作为IT系统的核心软件系统，是丰富业务能力的坚强后盾，数据中心平稳运行的最后底线，也是企业降本增效的基本前提。为此，运维人员极其关注平台的稳定性，例如：

-   断电自恢复
-   数据不丢失
-   日常不宕机

**自研可信要求**：近几年来，信创产品替代成为国内IT产业的一大趋势，研制一款自主可控安全可信的信创产品是该趋势的应有之义。信创是实现供应链安全的引擎，虚拟化产品作为信息系统架构的刚需品，在信创替代中占有重要地位。作为核心底座，高自研的平台应能具备至少以下能力：

-   支持天然兼容建立国产化生态
-   支持提供外部调用接口
-   支持自助下载搭建与试用
