---
title: "登录 ZSvirt"
---

平台默认使用 HTTPS 协议，并开启重定向至 HTTPS 地址的 443 端口，您只需在浏览器中输入管理节点 IP 地址即可访问 UI 管理界面。

-   为了获取更好的产品体验，建议使用 Chrome 67 及以上版本的浏览器，且将显示器最小分辨率调整为 1280 × 900 px。
-   若页面无法正常加载，请确认管理节点和 UI 服务均正常运行。

1.  在浏览器中，采用以下格式输入管理节点 IP 地址：`https://management_node_ip`。

    双管理节点环境可通过 VIP 访问 UI 管理界面。

2.  输入账户名和密码。

    首次登录时，默认账户名：**admin**，默认初始密码：**password**。

3.  点击**登录**。

-   为提升平台安全性并防止非授权人恶意登录，平台提供登录策略设置，有关更多信息，请参阅 [安全设置](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0013_19)。
-   平台支持使用 HTTPS/HTTP 协议访问 UI 管理界面，有关更多信息，请参阅 [证书管理](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0013_9)。
-   平台支持以账户身份登录和统一身份认证登录，有关更多信息，请参阅 [身份与访问管理](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0016)。
