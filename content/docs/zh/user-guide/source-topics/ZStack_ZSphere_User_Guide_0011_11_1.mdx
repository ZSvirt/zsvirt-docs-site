---
title: "新建 Kernel 适配器"
---

1.  在导航栏中，选择**资源清单** > **主机与虚拟机**。

2.  在资源树中，选择目标主机。

3.  在目标主机的详情页，点击**Kernel适配器**标签页。

4.  在Kernel适配器标签页，点击**新建Kernel适配器**。

5.  在新建Kernel适配器弹窗中，参考以下示例完成配置：

    -   **名称**：输入 Kernel 适配器名称
    -   **简介**：为 Kernel 适配器输入简要说明
    -   **网络服务**：默认展示**存储**，表明该 Kernel 适配器专门处理存储网络流量
    -   **分布式端口组**：选择一个分布式端口组
    -   **IPv4地址**：为 Kernel 适配器分配一个 IPv4 地址
    -   **子网掩码**：设置子网掩码

6.  确认配置信息无误后，点击**确定**。
