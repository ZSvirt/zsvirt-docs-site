---
title: "查看备份计划执行情况"
---

## 快速查看最近备份结果

**操作步骤**：

1.  在导航栏中，选择**数据保护** > **备份计划**。
2.  您可以通过列表中的**最近备份任务结果**项快速查看最近一次备份结果。

## 查看已保护资源的备份执行情况

若您启动了一个大型的备份计划，涉及到多台虚拟机。您可以查看每台虚拟机的备份结果，了解哪些虚拟机备份成功、备份失败或待备份。

**操作步骤**：

1.  在导航栏中，选择**数据保护** > **备份计划**。
2.  在备份计划页面，点击备份计划名称，进入详情页。
3.  在备份计划详情页，点击**备份资源**。
4.  在备份资源子页面，您可以查看该备份计划中所有已保护资源的备份执行情况。

## 查看备份计划的备份任务详情

您可以详细查看每个备份任务的详细信息，如备份对象、备份方式、备份资源数量、备份总容量、备份任务结果、备份耗时、开始和完成时间、以及备份明细。

**操作步骤**：

1.  在导航栏中，选择**数据保护** > **备份计划**。
2.  在备份计划页面，点击虚拟机备份计划的名称，进入详情页。
3.  在备份计划详情页，点击**备份任务**。
4.  在备份任务子页面，选择您项查看的备份任务，然后点击**查看备份详情**。
5.  在备份任务详情弹窗中，您可以查看备份任务的详细信息。
