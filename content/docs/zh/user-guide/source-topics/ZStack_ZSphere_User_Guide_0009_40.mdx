title: "虚拟机性能篇"
---

若业务要求虚拟机具备一些特性，例如具备较强的计算资源争抢能力，您可通过ZSvirt提供的相关虚拟机配置实现，以提升虚拟机性能。

您可在新建虚拟机时进行设置，也可对已有虚拟机修改对应配置进行设置。本节假定您已新建了若干台虚拟机。
