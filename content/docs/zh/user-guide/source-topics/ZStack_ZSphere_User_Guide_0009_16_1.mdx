---
title: "快照使用建议"
---

本章节主要针对生产环境使用快照功能给出建议说明。

1.  在生产环境中，建议单块硬盘的快照数量尽量控制在 5 以内，快照过多会影响虚拟机/硬盘的 I/O 性能、数据安全以及数据存储容量。
2.  在生产环境中，不建议进行高频的定时快照备份。长时间高频定时快照会从I/O、容量、业务稳定性等多方面影响生产环境：
    -   长时间高频定时快照，会导致快照过多，影响虚拟机业务。例如：对于分布式存储场景，主要影响虚拟机写性能；对于本地存储或集中式存储场景，主要影响虚拟机读性能。
    -   长时间高频定时快照，会导致全量快照相对较多，影响数据存储的整体I/O输出。
    -   长时间高频定时快照，会导致快照过多，占用额外的数据存储容量。

3.  在生产环境中，为确保数据完整性，不建议对高 I/O 的虚拟机新建快照。当虚拟机内部进行高 I/O 操作时，对虚拟机新建快照，内存中存在部分数据没有落入硬盘，这部分数据将无法保存到快照中。
4.  在生产环境中，为确保快照组恢复成功，不建议将普通快照组与包含虚拟机内存的快照组混用。
5.  快照对系统容量的占用说明：
    -   本地存储或集中式存储场景下，新建增量快照仅占用略微存储空间，新建全量快照会占用一倍存储空间。
    -   分布式存储场景下，新建快照本身不占用额外的存储空间，但新建快照后，对原有硬盘进行写操作可能触发快照的写时拷贝（Copy-On-Write），从而导致每个快照消耗与原有硬盘相同的存储空间大小。

6.  系统在特定场景触发一次性自动快照，包括重置虚拟机以及虚拟机克隆。新建镜像时会自动新建临时快照，当镜像新建完毕，会自动删除该快照。
7.  执行快照回滚操作前，强烈建议对硬盘新建一份快照，以保护当前硬盘数据状态。
8.  新建快照对当前业务的影响说明：

    一般情况下无影响，但在新建全量快照时，存储网络会有额外的网络 I/O 产生，特别是本地存储或集中式存储场景，硬盘 I/O 带宽占用比较明显，但硬盘 IOPS 基本不受影响。

9.  删除快照对当前业务的影响说明：

    一般情况下，删除快照会同时删除其子分支上的快照，并把数据合并（merge）到硬盘中，该过程会有额外的硬盘 I/O 带宽产生，业务 I/O 可能略微变慢。
