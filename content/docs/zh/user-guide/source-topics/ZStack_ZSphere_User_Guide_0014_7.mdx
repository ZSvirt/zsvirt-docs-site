---
title: "数据恢复"
---

ZSvirt 为针对多种灾难恢复场景提供了多种数据恢复方式：

-   您可以将虚拟机整机从备份数据恢复到指定位置。有关更多信息，请参阅 [覆盖恢复虚拟机](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0014_7_1)。
-   您可以基于备份数据直接创建新虚拟机。有关更多信息，请参阅 [备份新建虚拟机](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0014_7_2)。
-   您可以将平台从备份数据恢复到指定位置。有关更多信息，请参阅 [覆盖恢复平台数据库](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0014_7_3)。

-   **[覆盖恢复虚拟机](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0014_7_1)**  
    如果虚拟机发生故障，您可以将虚拟机从备份数据还原到最新备份时间点的状态，或还原到之前的一个备份时间点的状态。

-   **[备份新建虚拟机](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0014_7_2)**  
    如果虚拟机发生故障，您可以基于备份数据直接创建新虚拟机。这种数据恢复方式是非破坏性的，不会覆盖现有虚拟机，而是基于备份数据创建一台新的虚拟机。

-   **[覆盖恢复平台数据库](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0014_7_3)**  
    将平台从备份数据还原到指定备份时间点的状态。
