---
title: "同步迁移任务"
---

确保迁移任务状态为"停止同步"、"同步失败"、"可割接"状态，否则将无法执行同步操作。

1.  在导航栏中，选择**运维管理** > **迁移任务** > **所有任务**。

2.  在所有任务页面，选择要同步的迁移任务，然后点击**操作** > **同步**。

3.  在同步迁移任务弹窗中，选择同步模式。

    支持以下两种同步模式：

    -   增量同步：仅同步自上次同步后发生变更的数据。
    -   全量同步：同步虚拟机的全部数据。对于已完成初始同步的迁移任务，系统在执行全量同步前会默认进行对比扫描，此过程耗时较长。

4.  点击**确定**。
