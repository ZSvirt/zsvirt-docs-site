---
title: "新建 Windows 虚拟机规范"
---

在自定义规范中保存 Windows 虚拟机操作系统的系统设置，如虚拟机网络参与方式、主机名配置等。

以下操作系统版本的虚拟机支持自定义规范：

-   Windows Server 2012
-   Windows Server 2016
-   Windows Server 2019
-   Windows Server 2022
-   Windows Server 2025
-   Windows 10 Pro

1.  在导航栏中，选择**资源清单** > **主机与虚拟机**。

2.  选择根节点。

3.  在根节点详情页，点击**虚拟机规范**。

4.  在虚拟机规范标签页，点击**新建虚拟机规范**。

5.  在新建虚拟机规范弹窗中，参考以下示例完成配置：

    -   **名称**：输入虚拟机自定义规范的名称
    -   **简介**：为虚拟机规范输入简要说明
    -   **目标虚拟机操作系统**：选择**Windows**
    -   **工作组或域**：选择虚拟机参与网络的方式，包括工作组或 Windows 域服务器
        -   若选择工作组，需配置工作组名称、是否生成新的 SID。

            <Callout type="info">
            工作组名称长度不超过 15 个字符，支持使用字母、数字、下划线（\_）、英文句点（.）和连字符（-），且不能由纯数字组成。
            </Callout>

        -   若选择 Windows 域服务器，需配置域名、域用户名、域密码、组织单位、是否生成新的 SID。

           <Callout type="info">

            -   域名长度不超过 26 个字符，仅支持使用字母、数字、下划线（\_）、英文句点（.）和连字符（-）。
            -   域用户名长度不超过 15 个字符，支持使用字母、数字、下划线（\_）、英文句点（.）和连字符（-），且不能由纯数字组成。
            -   组织单位填写示例：OU=MyOU,DC=MyDom,DC=MyCompany,DC=com

           </Callout>
    -   **主机名配置方式**：选择如何配置虚拟机的主机名，包括使用虚拟机名称或手动指定

       <Callout type="info">

        -   当使用虚拟机名称作为主机名时，若 Windows 虚拟机名称长度超过 15 个字符，将被截断。
        -   手动指定的 Windows 主机名需符合以下规则：
            -   长度：2～15 个字符。
            -   允许字符：大小写字母、数字、连字符。
            -   不能连续使用连字符。不能使用连字符开头或结尾。不能仅使用数字。
        -   批量新建虚拟机时，主机名将自动增加后缀“-1/-2/-3”以此类推，用于确保主机名唯一。

       </Callout>
    -   **管理员密码**：设置管理员密码

        <Callout type="info">
        长度需为 8～16 字符，且至少包含以下两种字符组合：小写字母、大写字母、数字或特殊字符。
        </Callout>

    -   **确认密码**：输入密码二次确认

6.  确认配置无误后，点击**确定**。
