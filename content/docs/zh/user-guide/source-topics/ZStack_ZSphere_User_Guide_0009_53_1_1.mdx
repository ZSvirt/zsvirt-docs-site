---
title: "添加标准密钥提供程序"
---

支持添加外部密钥服务器（KMS）来辅助支持系统的各种加密能力，以此增强系统整体安全能力水平。KMS 必须支持密钥管理互操作协议（KMIP）1.1及以上标准。

确保平台已安装高级版许可证，并且许可证出于有效状态。

1.  在导航栏中，选择**资源清单** > **主机与虚拟机**。

2.  选择根节点。

3.  在根节点详情页，点击**密钥提供程序**。

4.  在密钥提供程序子页面，点击**添加密钥提供程序**。

5.  在添加密钥提供程序弹窗中，参考以下示例完成配置：

    -   **名称**：输入密钥提供程序名称

        <Callout type="info">
        每个密钥提供程序的名称将作为标识符，请确保名称全局唯一。
        </Callout>

    -   **简介**：为密钥提供程序输入简要说明
    -   **类型**：选择**标准密钥提供程序**
    -   **IP地址/域名**：输入 KMS 的 IP 地址或域名
    -   **端口**：输入 KMS 的连接端口，默认为 5696
    -   **密码保护**：一些 KMS 允许用户通过指定用户名和密码来隔离不同用户或组使用的加密密钥。开启后，输入对应的用户名和密码

6.  确认配置信息无误后，点击**确定**。

7.  点击**信任**。

    添加成功后，密钥提供程序状态显示为"已连接｜未被 KMS 信任"。

-   添加标准密钥提供程序后，需建立双向信任才可正常工作。有关更多信息，请参阅 [建立信任](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0009_53_1_2)。
-   场景实践：[使用 Thales 密钥提供程序](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0009_53_1_4)、[使用 HashiCorp 密钥提供程序](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0009_53_1_5)
