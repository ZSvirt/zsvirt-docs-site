---
title: "新建虚拟机-标准风"
---

若您希望严格按照业务需求新建一台/批的虚拟机，使虚拟机具备贴合业务的特性，可参照本节进行操作：

1.  新建虚拟机前（可选）
2.  新建虚拟机
3.  新建虚拟机后

## 新建虚拟机前 (可选)

ZSvirt提供系统参数功能，可全局控制平台设置的默认行为。新建虚拟机前，您可在系统参数中自定义虚拟机相关的参数，以控制虚拟机的默认特性。详细可参考[系统参数](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0013_10)。

## 新建虚拟机

平台提供多个虚拟机新建入口，您通过以下任一入口新建虚拟机：

-   在平台页面左侧导航栏中，右击目标集群、主机、或镜像，点击**新建虚拟机**。
-   在平台页面左侧导航栏中，选择目标集群、主机、或镜像。然后在平台页面右侧，点击**操作** > **新建虚拟机**，或在**虚拟机**子页面，点击**新建虚拟机**。

虚拟机由硬件和软件组成，新建虚拟机时，可自定义虚拟机硬件和软件设置。ZSvirt支持以下三大类信息设置：**基本信息设置**、**硬件信息设置**、**高级设置**。

**基本信息设置**：包括名称、数量、运行位置、存储位置、操作系统、高可用配置、以及默认开机配置

-   **名称**：虚拟机名称
-   **数量**：本次新建虚拟机的数量
-   **分组**：虚拟机所在分组，若不设置，则使用默认分组
-   **运行位置**：虚拟机所在主机或集群位置
-   **存储位置**：虚拟机硬盘所在数据存储位置，支持本地存储、NFS存储、SAN存储以及分布式存储，若不设置，则使用自动分配
-   **操作系统**：虚拟机操作系统，支持主流操作系统，包括Linux、Windows系统
-   **高可用**：虚拟机关机后自动重启机制，默认关闭。详情可参考[虚拟机高可用篇](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0009_18)
-   **默认开机**：虚拟机新建完成后是否自动开机，默认自动开机

**硬件信息设置**：包括CPU、内存、硬盘、网卡、光驱等硬件配置

-   **CPU**：自定义虚拟机CPU核数与特性
    -   **总核数**：虚拟机CPU核数
    -   **每个插槽内核数**：虚拟机CPU核在插槽内分配数量
    -   **CPU模式**：虚拟机CPU型号是否设置与主机CPU型号一致，用以继承主机部分或全部的CPU特性，以满足不同场景下业务需求，默认不设置（无），详情可参考[虚拟机CPU特性配置](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0009_42)
    -   **CPU资源优先级**：对于重要虚拟机，当主机负载率过高，出现CPU资源竞争时，可将优先级设置为“高”，较“正常”虚拟机具备更高的CPU抢夺能力，详情可参考[虚拟机资源争抢配置](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0009_41)
    -   **绑定CPU NUMA**：将虚拟机CPU(vCPU)与主机CPU (pCPU) 关联，为虚拟机分配特定的pCPU，提高虚拟机性能，详情可参考[虚拟机资源争抢配置](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0009_41)
    -   **CPU热插拔**：虚拟机是否支持在线修改CPU，默认支持。CPU热插拔与内存热插拔需同时开启或关闭

        <Callout type="info">
        仅部分操作系统支持热插拔，可点击**查看**获取热插拔支持系统列表。
        </Callout>

    -   **CPU虚拟化标记**：虚拟机是否打开虚拟化（hypervisor）标记。若关闭，将跳过应用程序对虚拟机的虚拟化环境检测，默认打开
-   **内存**：自定义虚拟机内存容量与特性
    -   **内存**：虚拟机内存容量
    -   **内存资源优先级**：对于重要虚拟机，当主机负载率过高，出现内存资源竞争时，可将优先级设置为“高”，较“正常”虚拟机具备更高的内存抢夺能力
    -   **内存热插拔**：虚拟机是否支持在线修改内存，默认支持。CPU热插拔与内存热插拔需同时开启或关闭

        <Callout type="info">
        仅部分操作系统支持热插拔，可点击**查看**获取热插拔支持系统列表。
        </Callout>

-   **硬盘1**：自定义虚拟机系统硬盘容量与特性，可新建硬盘或选择已有的系统镜像
    -   **容量**：新建硬盘时，系统硬盘的容量
    -   **系统镜像**：使用系统镜像时，需选择一个封装虚拟机系统的镜像，支持支持raw与qcow2格式
    -   **总线类型**：支持ide与Virtio两种总线类型。其中，Linux系统下硬盘1默认总线类型为Virtio，Windows系统下硬盘1默认总线类型为ide
    -   **分配方式**：仅当数据存储选择SAN存储时，需选择硬盘存储空间的分配方式，支持精简置备与厚置备两种分配方式，默认精简制备
        -   精简置备：按实际使用情况分配存储空间，可实现更高的存储利用率
        -   厚置备：创建硬盘时预先分配需要的存储空间，可提供充足的存储容量，保证存储性能。
    -   **缓存模式**：虚拟机写数据时是否使用主机页面缓存，以及若使用数据是否写入存储设备后再返回成功，默认为none，即不使用
    -   **aio加速**：虚拟机内核是否开启异步IO（AIO）加速，默认关闭
    -   **QoS限速**：硬盘是否设置读写带宽以及IOPS限制，默认不限制，详细可参考[虚拟机QoS配置](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0009_49)
-   **硬盘\{$n\}**：除硬盘1以外的硬盘，即数据盘，例如硬盘2。点击**硬件项**右侧的**添加硬件**按钮，在下拉选项中选择硬盘即可添加，一个虚拟机默认最多支持添加24个硬盘（包括硬盘1）
    -   数据盘支持新建硬盘、系统镜像或现有硬盘三种方式添加
    -   选择新建硬盘或已有系统镜像添加时，仅**总线类型**与**设置为共享类型**配置项与硬盘1存在差异，其他所有特性配置项与硬盘1相同
    -   数据盘支持Virtio与VirtioSCSI两种总线类型，默认为Virtio类型
    -   若使用分布式存储，支持将数据盘设置为共享硬盘，默认不设置
    -   若使用SAN存储，且总线类型设置为VirtioSCSI，同时硬盘分配方式为厚制备时，支持将数据盘设置为共享硬盘，默认不设置
-   **网卡1**：自定义虚拟机网卡相关地址与特性，支持无网卡新建虚拟机
    -   **启用状态**：网卡是否在虚拟机开机时自动启用
    -   **端口组**：虚拟机网卡所连接的分布式交换机端口所在的端口组
    -   **网卡型号**：不同网卡型号支持速度不同，支持e1000、rtl8139、和virtio三种，其中virtio类型网卡速度最快，可达10Gb/s
    -   **网卡多列队数目**：虚拟机网卡使用多个列队收发网络数据包，用以提升网络PPS与带宽性能
    -   **安全组**：虚拟机网卡绑定安全组，控制东西向流量。所绑定的安全组左侧对应的数值越小，生效的优先级越高

        <Callout type="warning">
        请妥善配置，避免各个安全组之间的规则冲突。
        </Callout>

    -   **QoS限速**：虚拟机网卡是否设置数据包收发带宽限制，默认不限制，详细可参考[虚拟机QoS配置](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0009_49)
-   **网卡\{$n\}**：虚拟机加载的第n块网卡，例如网卡2。点击**硬件项**右侧的**添加硬件**按钮，在下拉选项中选择网卡即可添加，网卡n的配置项与网卡1相同
-   **光驱1**：为虚拟机加载ISO镜像文件，用以支持从ISO光驱启动虚拟机
-   **光驱\{$n\}**：虚拟机加载的第n个光驱，例如光驱2。点击**硬件项**右侧的**添加硬件**按钮，在下拉选项中选择光驱即可添加。一个虚拟机默认最多支持添加3个光驱
-   **GPU设备\{$n\}**：虚拟机加载的第n个GPU设备，例如GPU设备1。点击**硬件项**右侧的**添加硬件**按钮，在下拉选项中选择GPU设备即可添加，支持添加物理GPU设备和vGPU设备
-   **USB设备\{$n\}**：虚拟机加载的第n个USB设备，例如USB设备1。点击**硬件项**右侧的**添加硬件**按钮，在下拉选项中选择USB设备即可添加，支持最多添加1个USB设备，可选择直连与转发两种方式
-   **其他硬件**：虚拟机加载显卡和声卡时的类型配置
    -   **显卡类型**：虚拟机启动时默认使用的显卡类型，支持vga、virtio、qxl、与cirrus，可提供基础/高清/高性能的视频功能体验，x86架构虚拟机默认为vga，ARM架构虚拟机仅支持选择virtio
    -   **显卡总显存**：使用vga与cirrus类型显卡时，显存容量固定为16MB；使用qxl类型显卡时，可自定义显存容量
    -   **声卡类型**：虚拟机启动时默认使用的声卡类型，支持HDA(ICH6)、HDA(ICH9)、与AC97，默认HDA(ICH6)

**高级设置**：包括常规设置、远程访问设置、登陆认证设置、VMTools设置、引导项设置、以及其他选项设置

-   **常规设置**：虚拟机常规设置
    -   **标签**：支持绑定一个或多个标签，用以识别不同虚拟机。详细可参考[标签管理](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0012_7)
    -   **主机名**：虚拟机的主机名
    -   **虚拟机调度组**：加入虚拟机调度组，按照调度组所关联的调度策略分配主机。一个虚拟机仅可以加入一个虚拟机调度组，详细可参考[虚拟机调度策略篇](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0009_17)
    -   **BIOS时钟同步**：Windows虚拟机BIOS时钟是否与主机BIOS时钟同步，默认不启用，详细可参考[虚拟机时间同步篇](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0009_48)
    -   **User Data**：用户自定义数据，通过上传自定义的参数或脚本，对虚拟机做一些定制化配置或完成特定任务，详细可参考[虚拟机自定义用户数据篇](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0009_50)
-   **远程访问**：虚拟机远程访问设置，详细可参考[访问虚拟机](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0009_14_8)
    -   **控制台模式**：虚拟机控制台模式，包括VNC、SPICE、VNC+SPICE，默认为VNC
    -   **控制台密码**：虚拟机的控制台密码，支持手动输入或随机生成。仅支持英文字母、数字和以下特殊字符：**-\`=\[\];',./~!@\#$%^&\*()\_+|\{\}:"&lt;&gt;?**
    -   **USB重定向**：将VDI客户端的USB设备重定向给虚拟机使用，默认不启用
-   **登陆认证**：登陆虚拟系统时的认证方法，支持以下认证方法：
    -   **暂不设置**：暂不设置登录密码或密钥
    -   **密码**：Linux虚拟机root用户或Windows虚拟机Administrator用户登陆系统时的密码，支持手动输入或随机生成。仅支持英文字母、数字和以下特殊字符：**-\`=\[\];',./~!@\#$%^&\*()\_+|\{\}:"&lt;&gt;?**

        <Callout type="info">
        设置密码前需确保虚拟机镜像已安装 Cloud-Init。
        </Callout>

    -   **SSH密钥**：新建Linux虚拟机时，可选择注入SSH公钥，免密登录虚拟机
-   **VMTools**：虚拟机故障处理策略和时间同步策略：
    -   **故障策略**：处理虚拟机故障时的策略，支持不处理、重启和关机策略
    -   **时间同步**：虚拟机的基准时间是否自动与主机系统时间进行同步，默认自动同步
-   **引导选项**：虚拟机BIOS启动顺序与模式等设置：
    -   **启动顺序**：虚拟机引导加载操作系统的优先顺序，支持硬盘、光盘和网络加载，默认情况下，BIOS从硬盘加载系统，若找不到启动设备，则无法加载。
    -   **BIOS模式**：BIOS引导模式，支持Legacy和UEFI两种。x86集群下默认为Legacy，ARM集群下默认为UEFI
    -   **BIOS停留时间**：BIOS界面自动停留时间
-   **其他选项**：虚拟机迁移、虚拟化、网络安全等相关的选项：
    -   **隐藏KVM虚拟化标记**：标记虚拟机CPU虚拟化是否打开。打开后，则在新启动的虚拟机定义 XML 中对'&lt;kvm&gt;'插入'&lt;hidden state="on"&gt;'，默认关闭
    -   **VMware IO端口模拟**：是否允许KVM虚拟机模拟VMware虚拟化环境中的IO端口，使KVM虚拟机可以使用VMware IO端口标准，实现与VMware虚拟化环境兼容，默认关闭

        该选项的主要用途：

        -   迁移和兼容性：允许将虚拟机从VMware环境迁移到KVM环境，或者在混合环境中同时运行VMware和KVM虚拟机，而不会涉及大规模的配置更改。
        -   测试和开发：开发人员和测试人员可以使用KVM虚拟机来模拟VMware环境，以测试应用程序或配置在VMware环境下的行为，而无需实际VMware许可证。
    -   **网卡防欺诈模式**：是否开启防IP/MAC伪造和ARP欺骗功能，开启后，虚拟机只能使用平台分配的IP/MAC地址与外界通信，默认关闭
    -   **跨集群高可用策略**：虚拟机自动高可用迁移时是否支持跨集群，默认不允许跨集群高可用

        <Callout type="info">
        该策略仅针对共享存储（分布式存储、NFS 存储、SAN 存储）场景下、虚拟机自动迁移行为有影响，例如虚拟机高可用更换主机启动、主机进入维护模式触发迁移。其它如：手动热迁移虚拟机（更改主机）、指定主机启动虚拟机、基于动态资源调度 (DRS) 策略更改主机等均不受影响。
        </Callout>

    -   **Hyper-V**：是否开启虚拟机Hyper-V模拟功能，主要用于Windows系统的虚拟机嵌套虚拟化场景。默认关闭
    -   **EmulatorPin**：是否将虚拟机中除vCPU和IO线程外的其他线程与主机pCPU进行绑定，支持按照NUMA节点绑定。默认不绑定，即虚拟机相关线程根据系统调度运行在对应pCPU上
    -   **热迁移自动收敛模式**：KVM虚拟机热迁移是否启用自动收敛模式，默认不启用
        -   若虚拟机长时间处于高业务负载状态，且业务应用对性能敏感度适中，建议启用自动收敛模式，以提升迁移成功率。
    -   **PCI 设备热插拔**：是否允许从虚拟机热插拔PCI设备，默认允许

        <Callout type="info">
        若热插拔时出现硬件兼容性错误，或不支持该硬件设备，可关闭该选项。
        </Callout>

确认配置无误后，点击**确认**，即可新建一台/批虚拟机。

## 新建虚拟机后

虚拟机部分配置依赖VMTools实现。虚拟机新建完成后，建议安装VMTools以使该部分配置生效。安装步骤可参考[虚拟机VMTools篇](/docs/user-guide/source-topics/ZStack_ZSphere_User_Guide_0009_19)。
