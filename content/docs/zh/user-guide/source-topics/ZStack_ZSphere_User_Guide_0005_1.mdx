---
title: "手动初始化"
---

跟随初始化向导，手动创建环境所需基础资源，包括数据中心、集群、主机、数据存储、镜像存储、镜像、分布式端口组。

1.  在欢迎使用初始化向导弹窗中，选择**手动初始化**。

2.  点击**下一步**。

3.  在手动初始化页面，新建数据中心。

    1.  输入数据中心名称和简介。

    2.  点击**确定**。

4.  新建集群。

    1.  输入集群名称。

    2.  选择集群 CPU 架构，包括 x86\_64 和 aarch 64。

    3.  点击**确定**。

5.  添加主机。

    1.  输入主机名称。

    2.  输入主机 IP 地址、SSH 端口、SSH 用户名和密码。

        <Callout type="info">
        添加至集群的主机架构需和集群 CPU 架构一致，否则将添加失败。
        </Callout>

    3.  点击**确定**。

        添加过程可能持续几分钟。

6.  添加数据存储。

    1.  输入数据存储名称。

    2.  选择数据存储类型，包括本地存储、ZCE 分布式存储、ZHPS 分布式存储。

        -   本地存储：需配置挂载路径、主机硬盘。

           <Callout type="info">

            -   挂载路径不能使用`/`、`/dev`、`/proc`、`/sys`、`/usr/bin`、`/bin`等系统目录，否则可能导致主机异常。
            -   配置主机空闲硬盘会格式化所选硬盘，将彻底清除硬盘上的所有分区、文件系统及数据。

           </Callout>
        -   ZCE 分布式存储：需配置是否启用密钥认证、添加监控节点、指定镜像缓存池和存储池、指定存储网络。

            <Callout type="info">
            需确保分布式存储的密钥认证和平台配置一致，否则可能导致虚拟机创建失败。
            </Callout>

        -   ZHPS 分布式存储：需配置 IP 地址、端口、用户名和密码、添加存储池。
        -   ZBS 分布式存储：添加 MDS 节点、输入存储池的池名称。
    3.  点击**确定**。

7.  添加镜像存储。

    1.  输入镜像存储名称。

    2.  选择镜像存储类型，包括单机镜像仓库和分布式镜像仓库。

        -   单机镜像仓库：需输入镜像存储 IP、SSH 端口、用户名和密码。完成硬盘相关配置，包括添加方式、挂载路径、是否获取已有镜像、镜像同步网络、以及数据网络。

           <Callout type="info">

            -   若添加方式选择空闲硬盘，配置空闲硬盘会格式化所选硬盘，将彻底清除硬盘上的所有分区、文件系统及数据。
            -   挂载路径不能使用`/`、`/dev`、`/proc`、`/sys`、`/usr/bin`、`/bin`等系统目录，否则可能导致镜像存储异常。

           </Callout>
        -   分布式镜像仓库：需配置监控节点，包括监控节点管理 IP、SSH 端口、用户名和密码。按需填写镜像存储池 UUID，若留空不填，默认自动创建镜像存储池。
    3.  点击**确定**。

8.  添加镜像。

    1.  选择镜像路径，包括 URL 和本地上传。

    2.  输入镜像名称。

    3.  选择镜像类型，包括系统镜像和硬盘镜像。

    4.  选择镜像格式，包括 qcow2、iso、vmdk、raw 格式。

    5.  点击**确定**。

9.  新建分布式端口组。

    1.  输入分布式端口组名称。

    2.  选择分布式端口组所在的分布式交换机，包括默认交换机和新建交换机。

        -   默认交换机：集群添加首台主机后，平台将基于主机相关配置自动创建默认分布式交换机，用于管理主机的管理网络。支持复用此默认分布式交换机，实现管理网和业务网复用。
        -   新建交换机：基于网络规划新建分布式交换机，实现管理网与业务网分离，推荐生产环境选择此选项。若选择此选项，需配置聚合口配置方式、上行链路名称、聚合模式、哈希策略、以及主机网口。
    3.  选择 VLAN 类型，包括无和标准 VLAN。

        选择标准 VLAN 需配置 VLAN ID。

    4.  选择是否开启 DHCP 服务。

        开启后，需配置网络段方式（IP 范围或 CIDR）、网关、IP 分配策略、以及 DHCP 服务 IP。

    5.  输入 DNS。

    6.  点击**确定**。

10. 弹出手动初始化已完成弹窗，点击**确定**。

    已完成创建环境所需基础资源，可以开始使用。
