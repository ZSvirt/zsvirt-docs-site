---
title: "新建迁移任务"
---

确保迁移服务许可证的授权额度充足。

1.  在导航栏中，选择**运维管理** > **迁移任务** > **所有任务**。

2.  在所有任务页面，点击**新建迁移任务**。

3.  在新建迁移任务弹窗中，参考以下示例完成源平台配置：

    -   **源平台**：选择源平台
    -   **源虚拟机**：添加要迁移的源虚拟机

        <Callout type="info">
        选择的源虚拟机不能超过授权类型对应的容量上限。超出部分需要额外购买容量授权。
        </Callout>

        -   测试授权：硬盘容量上限为 1 TB。
        -   正式授权：硬盘容量上限为 5 TB。
    -   **迁移授权类型**：选择授权类型

4.  点击**下一步**。

5.  配置目标平台。

    1.  参考以下示例完成虚拟机配置：

        -   **数据中心**：选择虚拟机迁移后所在的数据中心
        -   **集群**：选择虚拟机迁移后所在的集群
        -   **主机**：选择虚拟机迁移后所在的主机
        -   **存储位置**：选择虚拟机迁移后使用的数据存储
        -   **总线类型**：选择虚拟机硬盘设备的总线类型
        -   **CPU模式**：选择虚拟机迁移后的 CPU 模式
        -   **目标网络端口组**：选择虚拟机要使用的分布式端口组
            -   **CIDR**：选择 CIDR
            -   **网卡配置**：选择是否克隆源虚拟机的网络配置及 MAC 地址

                -   克隆网络配置：克隆后，虚拟机的目标 IP 地址默认与源虚拟机保持一致。子网掩码与网关需由手动填写
                -   克隆 MAC 地址：虚拟机的目标 MAC 地址与源虚拟机保持一致。

               <Callout type="warning">

                -   选择克隆网络配置后，平台将根据网络属性为虚拟机分配临时 IP 地址，以保障数据同步。您也可以在虚拟机配置确认页手动指定 IP 地址。
                -   选择克隆网络配置时，建议在正式割接前将源虚拟机关机，以避免 IP 地址冲突。

               </Callout>
            -   **目标IP地址**：指定虚拟机目标 IP 地址
        -   **临时网络端口组**：勾选**克隆网络配置**时，需配置临时网络端口组。临时网络端口组推荐使用 DHCP 端口组，默认同目标网络端口组，若目标网络端口组无 DHCP，则您需手动指定临时 IP 地址
        -   **安全组**：选择安全组
    2.  参考以下示例完成割接配置：

        -   **立即割接**：启用后，系统将在数据初始同步完成后，自动执行割接任务
        -   **创建回滚快照**：启用后，系统将在发起割接任务时为目标虚拟机创建回滚快照

            回滚快照的作用：

            -   启用时：删除迁移任务时若选择“仅删除割接程序”，系统将自动回滚目标虚拟机或硬盘至快照状态。
            -   关闭时：删除迁移任务时将无法使用“仅删除割接程序”选项。
        -   **源虚拟机自动关机**：启用后，系统将在执行割接任务前关闭源虚拟机
        -   **自动安装VMTools**：启用后，系统将在目标虚拟机操作系统转换完成后，自动安装VMTools

6.  点击**下一步**。

7.  检查配置信息，确认无误后点击**确定**。
