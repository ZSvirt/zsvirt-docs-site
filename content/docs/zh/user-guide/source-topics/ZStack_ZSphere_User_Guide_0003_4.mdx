---
title: "使用USB Key授权的许可证"
---

您可参考以下步骤了解USB Key许可证完整使用流程：

1.  安装许可证
2.  更新许可证
3.  查看许可证授权记录

## 安装许可证

若您首次安装USB Key许可证，可参考以下步骤：

1.  获取已预制授权的USB Key硬件。
2.  将USB Key插入管理节点。双管环境下，插入任一管理节点即可。
3.  在ZSvirt左上角导航菜单，点击**系统管理** > **许可证管理** > **许可证**，进入许可证界面。检查USB Key状态，确保状态为**正常**。
4.  点击**上传许可证**左侧的**同步**按钮。
5.  检查许可状态，确保状态为**有效**，即完成安装。

<Callout type="info">
使用USB Key授权的环境，每次进入许可证界面，会有大约2秒的信息读取时间，2秒后会出现USB Key相关信息。
</Callout>

## 更新许可证

若您需扩容或新增授权，可参考以下步骤更新授权：

1.  将USB Key插入管理节点。
2.  在ZSvirt左上角导航菜单，点击**系统管理** > **许可证管理** > **许可证**，进入许可证界面。检查USB Key状态，确保状态为**正常**。
3.  点击**复制**USB Key ID，使用该ID进行授权申请，获取授权文件。
4.  回到许可证界面，点击**上传许可证**，将授权文件上传。
5.  检查授权信息，确保信息全部正确，且许可状态为**有效**，即完成更新。

## 查看许可证授权记录

若您已完成安装或更新许可证，可在本页面点击授权记录页签查看详细授权历史记录，包括：许可上传时间、许可管理类型、授权方式、授权属性、授权额度、状态、许可签发时间、以及该许可到期时间。
