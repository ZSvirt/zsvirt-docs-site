---
title: "专用备份存储"
---

添加专用备份节点，利用节点空闲硬盘或本地目录存储备份数据。

1.  在导航栏中，选择**数据保护** > **备份存储**。

2.  在备份存储页面，点击**添加备份存储**。

3.  在请选择备份存储添加方式弹窗中，选择**专用备份存储**，然后点击**下一步**。

4.  在添加本地备份存储弹窗中，完成基础配置和硬盘配置。

5.  对于**基础配置**，参考以下示例完成配置：

    **基本信息**

    -   **名称**：本地备份存储名称
    -   **简介**：本地备份存储简介
    -   **数据中心**：显示备份存储所在数据中心
    -   **添加方式**：显示**专用备份存储**

    **配置信息**

    -   **备份存储IP**：填写专用备份存储的 IP 地址
    -   **SSH端口**：默认为 22
    -   **用户名**：默认为 root 用户
    -   **密码**：用户对应的密码

6.  确认基础配置无误后，点击**下一步**。

7.  对于**硬盘配置**，参考以下示例完成配置：

    -   **存储方式**：支持**空闲硬盘**和**本地目录**
    -   **空闲硬盘**：存储方式选择**空闲硬盘**时，需配置此参数

        <Callout type="info">
        配置空闲硬盘会格式化所选硬盘，将彻底清除硬盘上的所有分区、文件系统及数据。
        </Callout>

    -   **备份存储路径**：填写专用备份存储上的挂载路径

        <Callout type="info">
        不能使用 `/`、`/dev/`、`/proc/`、`/sys/`、`/usr/bin`、`/bin` 等系统目录，否则可能导致备份存储异常。
        </Callout>

    -   **备份网络**：备份单独使用的网络，填写备份网络 CIDR
    -   **备份数据**：存储方式选择**本地目录**时，需配置此参数。选择是否扫描已有备份数据

8.  确认配置无误后，点击**确定**。
