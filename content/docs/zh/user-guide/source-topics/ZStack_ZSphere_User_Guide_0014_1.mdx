---

备份管理模块提供了一组用于执行数据保护和灾难恢复的功能。

本模块文档主要介绍了备份管理的主要功能特性，以及数据保护和灾难恢复的相关步骤引导。

## 功能概述

**集中式管理界面**

ZSvirt 提供集中式 UI 界面，用于管理已保护资源、备份数据、备份计划和备份存储。

**基于计划的备份**

ZSvirt 的备份服务是基于周期性的计划备份，通过备份策略、备份数据保留策略、以及备份 QoS，您可以自定义创建符合您业务需求的备份计划，然后将其应用于需要备份保护的虚拟机资源或平台数据库。

**多种备份策略**

ZSvirt 针对不同备份对象，提供多种备份策略，轻松满足虚拟化备份需求。对于虚拟机，提供默认增量备份和自定义增量备份策略。对于平台数据库，用户可以自定义备份周期、执行时间和开始时间。

**灵活多场景备份**

ZSvirt 支持本地和异地数据保护，数据更可靠。本地备份存储支持主备无缝切换，有效保障业务连续性。同时，可将备份数据通过本地备份存储同步至异地备份存储。

**备份活动监控**

ZSvirt 提供备份相关活动的详细信息，您只需点击几下即可轻松掌握备份计划执行状态、备份数据容量占用信息。
