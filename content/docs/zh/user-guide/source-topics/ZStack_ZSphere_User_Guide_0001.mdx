---
title: "关于 ZSvirt"
---

ZSvirt基于高性能、高安全、高稳定、和高自研的核心理念，具备ZStack Cloud平台云平台引擎与4S特性，使用服务器虚拟化、网络虚拟化、存储虚拟化等前沿技术，兼具智能高级运维能力，是一款面向下一代的服务器虚拟化软件。用户可以利用ZSvirt快速构建虚拟化数据中心，也可结合云轴科技丰富的产品线搭建从IaaS到PaaS的一体化方案。
