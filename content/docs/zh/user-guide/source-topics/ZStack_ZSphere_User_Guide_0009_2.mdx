---
title: "数据中心基础操作篇"
---

您可从增删改查视角了解数据中心支持的基础操作。

-   新建数据中心
-   编辑数据中心
-   查看数据中心
-   删除数据中心

## 新建数据中心

导航至根节点，点击**新建数据中心**，参考以下示例新建数据中心：

-   **名称**：数据中心名称
-   **简介**：数据中心简介

点击**确定**后，即可新建完成。

## 编辑数据中心

若您需修改已有数据中心的名称或简介，可在对应数据中心页面，点击 **更多操作** / **编辑名称简介**，在出现的弹窗中修改对应信息即可。

## 查看数据中心

ZSvirt提供数据中心资源拓扑图，方便您快速掌握一个数据中心里所有资源的汇总信息。您可在目标数据中心**总览**页面查看该信息。

## 删除数据中心

若您需删除已有数据中心，可在目标数据中心页面，点击**更多操作** > **删除**，即可删除。

<Callout type="warning">
删除数据中心会删除集群、主机、网络、数据存储等资源，同时还会删除各资源下所有子级资源（如虚拟机），请谨慎操作。
</Callout>
