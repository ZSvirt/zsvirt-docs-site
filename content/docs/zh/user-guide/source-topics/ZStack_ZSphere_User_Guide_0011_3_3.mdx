---
title: "删除分布式交换机"
---

-   默认分布式交换机中仍有加入的主机时，不支持删除操作。
-   若分布式交换机下的分布式端口组被虚拟机内存快照引用，不支持删除操作。
-   若分布式交换机下的分布式端口组关联 Kernel 适配器，不支持删除操作。

1.  在导航栏中，选择**资源清单** > **网络资源**。

2.  在资源树中，选择目标分布式交换机。

3.  在目标分布式交换机的详情页，点击**操作** > **删除**。

    <Callout type="warning">
    删除分布式交换机会删除其下分布式端口组，并卸载相应虚拟机的网卡，请谨慎操作。
    </Callout>
