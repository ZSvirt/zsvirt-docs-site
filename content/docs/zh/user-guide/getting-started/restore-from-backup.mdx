---
title: "备份数据还原"
---

若本地数据中心发生灾难，可依赖平台数据库备份数据，重建数据中心并恢复业务。您可跟随初始化向导，从已有平台数据库备份数据恢复环境资源配置。

已有平台数据库备份数据。

## 操作步骤

1.  在欢迎使用初始化向导弹窗中，选择**备份数据还原**。

2.  点击**下一步**。

3.  在备份数据还原弹窗中，参考以下示例完成服务器配置：

    -   **备份存储 IP**：输入存有平台数据库备份数据的备份存储 IP 地址
    -   **URL**：备份存储的路径 URL
    -   **SSH 端口**：备份存储 SSH 端口，默认为 22
    -   **用户名**：备份存储用户名
    -   **密码**：用户名对应的密码

4.  点击**测试连接**，检测备份存储网络连通性。

5.  连接成功后，参考以下示例完成备份数据配置：

    -   **数据库备份数据**：选择平台数据库备份数据

        <Callout type="warning">
        请根据许可证授权情况，选择适当的数据进行还原，避免备份数据还原后，因许可证授权配额不足导致管理节点启动失败。可按需点击**更新许可证**对许可证进行更新。
        </Callout>

6.  确认配置无误后，点击**确定**。

7.  在还原平台数据库弹窗中，输入平台数据库 root 密码，然后点击**确定**。

    <Callout type="info">
    还原平台数据库需要重新启动管理节点，期间将无法使用管理界面。此过程通常需要几分钟，您的业务资源不会受到影响。
    </Callout>

8.  等待平台数据库还原成功后，点击**重新登录**。

恢复平台数据库后，平台所有资源都会变为创建备份时的状态。请在本地备份存储中点击**扫描备份数据**以获取当前真实备份数据信息。
