---
title: "手动初始化"
---

跟随初始化向导，手动创建环境所需基础资源，包括数据中心、集群、主机、数据存储、镜像存储、镜像、分布式端口组。

## 操作步骤

<Steps>

<Step>

<p className="procedure-step-title">进入手动初始化</p>

在**欢迎使用初始化向导**弹窗中选择**手动初始化**，然后点击**下一步**。

</Step>

<Step>

<p className="procedure-step-title">新建数据中心</p>

在手动初始化页面输入数据中心名称和简介，然后点击**确定**。

</Step>

<Step>

<p className="procedure-step-title">新建集群</p>

输入集群名称，选择集群 CPU 架构（`x86_64` 或 `aarch64`），然后点击**确定**。

</Step>

<Step>

<p className="procedure-step-title">添加主机</p>

1. 输入主机名称。
2. 输入主机 IP 地址、SSH 端口、SSH 用户名和密码。
3. 点击**确定**。添加过程可能持续几分钟。

<Callout type="info">
添加至集群的主机架构需和集群 CPU 架构一致，否则将添加失败。
</Callout>

</Step>

<Step>

<p className="procedure-step-title">添加数据存储</p>

输入数据存储名称，然后选择数据存储类型：

- **本地存储**：配置挂载路径和主机硬盘。

<Callout type="info">

- 挂载路径不能使用 `/`、`/dev`、`/proc`、`/sys`、`/usr/bin`、`/bin` 等系统目录，否则可能导致主机异常。
- 配置主机空闲硬盘会格式化所选硬盘，并彻底清除硬盘上的所有分区、文件系统及数据。
- 使用 ZCE 分布式存储时，需确保密钥认证与平台配置一致，否则可能导致虚拟机创建失败。

</Callout>

完成配置后点击**确定**。

</Step>

<Step>

<p className="procedure-step-title">添加镜像存储</p>

输入镜像存储名称，然后选择镜像存储类型：

- **单机镜像仓库**：输入镜像存储 IP、SSH 端口、用户名和密码，并配置添加方式、挂载路径、是否获取已有镜像、镜像同步网络和数据网络。
- **分布式镜像仓库**：配置监控节点管理 IP、SSH 端口、用户名和密码。可按需填写镜像存储池 UUID；留空时平台将自动创建镜像存储池。

<Callout type="info">

- 选择空闲硬盘作为添加方式会格式化所选硬盘，并彻底清除硬盘上的所有分区、文件系统及数据。
- 挂载路径不能使用 `/`、`/dev`、`/proc`、`/sys`、`/usr/bin`、`/bin` 等系统目录，否则可能导致镜像存储异常。

</Callout>

完成配置后点击**确定**。

</Step>

<Step>

<p className="procedure-step-title">添加镜像</p>

1. 选择镜像路径：URL 或本地上传。
2. 输入镜像名称。
3. 选择镜像类型：系统镜像或硬盘镜像。
4. 选择镜像格式：`qcow2`、`iso`、`vmdk` 或 `raw`。
5. 点击**确定**。

</Step>

<Step>

<p className="procedure-step-title">新建分布式端口组</p>

1. 输入分布式端口组名称。
2. 选择分布式交换机：
   - **默认交换机**：复用平台在集群添加首台主机后自动创建的管理网络交换机。
   - **新建交换机**：按网络规划分离管理网与业务网，适合生产环境。需配置聚合口配置方式、上行链路名称、聚合模式、哈希策略和主机网口。
3. 选择 VLAN 类型。使用标准 VLAN 时需配置 VLAN ID。
4. 选择是否开启 DHCP 服务。开启后需配置网络段方式（IP 范围或 CIDR）、网关、IP 分配策略和 DHCP 服务 IP。
5. 输入 DNS，然后点击**确定**。

</Step>

<Step>

<p className="procedure-step-title">完成初始化</p>

在**手动初始化已完成**弹窗中点击**确定**。环境所需基础资源已创建完成，可以开始使用平台。

</Step>

</Steps>
