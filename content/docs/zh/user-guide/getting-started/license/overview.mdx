-   两种授权方式

-   授权联系方式

## 授权方式

ZSvirt提供两种授权方式：USB Key授权和请求码授权。

-   USB Key通过在硬件中预制许可的方式实现授权，授权流程如下：
    1.  获取已预制授权的USB Key硬件
    2.  双管环境下，将USB Key插入任一管理节点，即可完成授权。单管部署时，插入至该管理节点即可。
-   请求码通过纯软文件上传的方式实现授权，授权流程如下：
    1.  获取已包含相关授权的License压缩包文件。
    2.  将该License文件上传至ZSvirt任一管理节点，即可完成授权。单管部署时，上传至该管理节点即可。

## 授权协议

ZSvirt提供基础版-试用、基础版-付费、高级版-付费三种授权协议。具体授权协议说明：

-   基础版-试用：可免费添加1台主机试用基础的计算虚拟化、存储虚拟化及网络虚拟化功能，试用期为30天。试用期间不提供官方售后技术支持服务，可用于部署测试环境。
-   基础版-付费：可按物理CPU或主机数量付费授权，提供基础的计算虚拟化、存储虚拟化及网络虚拟化功能。售后服务期内可获得官方售后技术支持服务，可用于部署生产环境。
-   高级版-付费：可按物理CPU或主机数量付费授权，提供完整的计算虚拟化、存储虚拟化及网络虚拟化功能。售后服务期内可获得官方售后技术支持服务，可用于部署生产环境。

<Callout type="info">
关于不同授权协议提供的功能差异详情，请咨询官方销售人员。
</Callout>

若使用信创服务器，则需申请信创版的许可证。信创版许可证包括基础版-试用、信创基础版-付费、信创高级版-付费三种授权协议。后两种协议所支持的功能与服务分别与基础版-付费、高级版-付费相同。
