## 关于本文档

本文档可帮助您快速了解 ZSvirt，包括产品架构、功能特性、系统配置和详细操作说明。

## 目标读者

本文档适用于以下读者：

- 技术支持工程师
- 部署运维工程师
- 产品咨询工程师
- 有兴趣研究 ZSvirt 的相关人员

## 文档地图

建议按以下路径阅读：

- **了解产品**：先阅读[产品功能](/docs/user-guide/getting-started/product-features)和[用户界面](/docs/user-guide/getting-started/interface)，快速建立对产品定位和控制台结构的认识。
- **完成入门**：继续阅读[登录 ZSvirt](/docs/user-guide/getting-started/login)和[初始化 ZSvirt](/docs/user-guide/getting-started/initialization)，了解登录与初始化向导。
- **开始使用**：进入[计算管理](/docs/user-guide/compute)和[虚拟机](/docs/user-guide/compute/vm)，掌握核心计算资源的日常操作。
