---
title: "事件"
---

事件：实时监控并记录平台所有活动，可用于操作追踪、等保合规、安全分析、问题排查、自动运维等场景。通过事件，可持续监控并保留对平台的所有操作，包括通过控制台、API 服务、开发者工具对平台的访问和使用等行为。

## 资源操作事件

如下图所示，资源操作事件提供在平台上进行资源操作时调用 API 的事件信息。

<img src="/docs/user-guide/images/ZStack_ZSphere_User_Guide_0012_23_1.png" alt="资源操作列表" />

-   点击 API 名称查看事件详情，包括基本信息、API 请求、API 返回等。
-   支持选择时间段，查看所选时间段内的事件。可选时间段包括：最近 3 天、最近 7 天、最近 30 天、自定义。
-   支持通过输入 API 名称/资源 UUID/资源名称/资源类型/操作员 IP 来搜索资源操作事件。
-   支持根据任务结果筛选事件。可选任务结果包括：成功、失败。
-   支持将事件以 CSV 格式导出。
-   支持调整每页显示的事件数量。可选值包括：10、20、50、100 项/页。支持翻页操作。
-   保留平台内所有事件记录，您可自行设置事件保留时间上限。有关更多信息，请参阅 [系统参数](/docs/user-guide/system/platform-settings/system-parameters)。
