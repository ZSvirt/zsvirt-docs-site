-   **[报警规则说明](/docs/user-guide/operations/alarms/alarm-rules/rule-reference)**  

-   **[新建资源报警器](/docs/user-guide/operations/alarms/alarm-rules/create-resource-alarm)**  
    资源报警器用于监控平台中的资源时序化数据，例如对虚拟机 CPU 使用率设置一个报警器，当某虚拟机 CPU 使用率超过 80% 并持续 5 分钟时，将触发系统报警。

-   **[新建事件报警器](/docs/user-guide/operations/alarms/alarm-rules/create-event-alarm)**  
    事件报警器用于监控平台中预定义的事件，例如主机未连接事件报警器，当主机失联时，将触发系统报警。
