title: "添加源平台"
---

## 操作步骤

1.  在导航栏中，选择**运维管理** > **迁移资源** > **源平台**。

2.  在源平台页面，点击**添加源平台**。

3.  在添加源平台弹窗中，参考以下示例完成配置：

    -   **名称**：设置源平台名称
    -   **数据网关配置方式**：选择配置方式，包括选择已有数据网关或输入新数据网关 IP 地址
    -   **数据网关**：选择数据网关
    -   **平台类型**：VMware
    -   **vCenter/ESXi地址**：输入 VMware 环境地址
    -   **用户名**：输入登录用户名
    -   **密码**：输入用户名对应的密码
    -   **连通性测试**：点击**检测**测试网络是否可达

4.  确认配置无误后，点击**确定**。
