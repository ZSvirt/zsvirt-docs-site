title: "添加数据网关"
---

## 操作步骤

1.  在导航栏中，选择**运维管理** > **迁移资源** > **数据网关**。

2.  在数据网关页面，点击**添加数据网关**。

3.  在添加数据网关弹窗中，参考以下示例完成配置：

    -   **名称**：设置数据网关名称
    -   **添加方式**：选择数据网关添加方式，支持新建虚拟机和已有 IP 两种方式

        若选择**新建虚拟机**方式：

        -   **数据中心**：选择虚拟机所在数据中心
        -   **运行位置**：选择运行位置
        -   **CPU**：默认 8 核，设置 CPU 数量
        -   **内存**：默认 8 GB，设置内存大小
        -   **存储位置**：指定数据存储
        -   **硬盘1**：默认 100 GB，设置系统盘大小
        -   **网络**：指定分布式端口组，需确保所选分布式端口组与源端平台、目标端平台网络互通，以保证数据传输
        -   **IPv4地址**：指定 IP 地址

            <Callout type="info">
            IP 地址分配方式取决于所选迁移网络的配置：
            </Callout>

            -   迁移网络启用 DHCP 时，系统自动分配 IP 地址。
            -   迁移网络未启用 DHCP 时，需手动指定 IP 地址。
            -   迁移网络启用 IP 地址管理后，手动指定 IP 地址时，需确保地址在所选网络段内。

        若选择**已有IP**方式：

        -   **IP地址**：输入 IP 地址
        -   **主机名称**：IP 地址连通后，将自动获取对应名称
        -   **连通性检测**：点击**检测**测试网络是否可达

4.  确认配置无误后，点击**确定**。
