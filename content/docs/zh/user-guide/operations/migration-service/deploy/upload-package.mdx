---
title: "第一步 上传迁移服务安装包"
---

上传安装包后，系统将自动解压并获取迁移服务所需文件。

## 前提条件

-   确保平台已安装迁移服务许可证且授权额度充足。
-   已提前准备好迁移服务的安装包。
-   平台已添加镜像存储资源，且镜像存储有足够的存储空间。

## 操作步骤

1.  在导航栏中，选择**运维管理** > **迁移服务**。

2.  在迁移服务页面，点击**去上传**。

3.  在上传迁移服务安装包弹窗中，参考以下示例完成配置：

    -   **上传方式**：选择上传安装包的方式，包括 URL 和本地上传
    -   **URL/安装包**：输入 URL 或上传安装包文件
    -   **存储路径**：指定一个目录路径，用于存放上传的安装包及其解压后的文件

       <Callout type="info">

        -   请确保该目录具备充足的可用空间，否则将导致安装失败。
        -   不能使用 `/`、`/dev`、`/proc`、`/sys`、`/usr/bin`、`/bin`、`/opt` 等系统目录，否则可能导致服务器异常。

       </Callout>

4.  确认配置无误后，点击**确定**。
