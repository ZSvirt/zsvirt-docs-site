---
title: "第二步 安装部署迁移服务"
---

根据业务需求选择合适的规格，部署迁移服务。部署完成后，即可通过迁移服务将虚拟机迁移至目标平台。

## 操作步骤

1.  在迁移服务页面，点击**去安装**。

2.  在安装部署迁移服务弹窗中，参考以下示例完成配置：

    -   **迁移服务版本**：展示安装部署的服务版本
    -   **数据中心**：迁移服务通过虚拟机数据网关部署，选择数据中心
    -   **运行位置**：选择运行位置
    -   **CPU**：默认 8 核，设置 CPU 数量
    -   **内存**：默认 8 GB，设置内存大小
    -   **存储位置**：指定数据存储
    -   **存储池**：当存储位置为分布式存储时，需指定存储池
    -   **硬盘1**：默认 100 GB，设置系统盘大小
    -   **迁移网络**：指定分布式端口组用作迁移网络。需确保所选分布式端口组与源端平台、目标端平台网络互通，以保证数据传输
    -   **IPv4地址**：指定 IP 地址

        <Callout type="info">
        IP 地址分配方式取决于所选迁移网络的配置：
        </Callout>

        -   迁移网络启用 DHCP 时，系统自动分配 IP 地址。
        -   迁移网络未启用 DHCP 时，需手动指定 IP 地址。
        -   迁移网络启用 IP 地址管理后，手动指定 IP 地址时，需确保地址在所选网络段内。

3.  确认配置无误后，点击**确定**。
