---
title: "概述"
---

Kernel 适配器使用网络标签来标识物理网络流量。在集群成功添加主机后，ZSvirt 将为每台主机创建一个默认 Kernel 适配器，用于获取和展示该主机的管理网。您可为主机新建用于存储网络服务的 Kernel 适配器。

-   **[新建 Kernel 适配器](/docs/user-guide/network/network-resources/kernel-adapter/create)**  

-   **[修改 Kernel 适配器配置](/docs/user-guide/network/network-resources/kernel-adapter/modify)**  

-   **[删除 Kernel 适配器](/docs/user-guide/network/network-resources/kernel-adapter/delete)**
