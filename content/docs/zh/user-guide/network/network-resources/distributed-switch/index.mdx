---
title: "概述"
---

通过分布式交换机，您可以在 ZSvirt 中设置和配置网络连接。

集群添加首台主机后，ZSvirt 将基于该主机的相关配置自动创建默认分布式交换机，默认分布式端口组、以及默认 Kernel 适配器，用于集中管理主机的管理网络。基于网络规划，您可以灵活复用默认分布式交换机或使用新建的分布式交换机。

-   **[新建分布式交换机](/docs/user-guide/network/network-resources/distributed-switch/create)**  

-   **[分布式交换机上行链路篇](/docs/user-guide/network/network-resources/distributed-switch/uplinks)**  

-   **[分布式交换机网络拓扑篇](/docs/user-guide/network/network-resources/distributed-switch/topology)**  

-   **[分布式交换机加载/卸载集群](/docs/user-guide/network/network-resources/distributed-switch/load-unload-cluster)**  

-   **[删除分布式交换机](/docs/user-guide/network/network-resources/distributed-switch/delete)**
