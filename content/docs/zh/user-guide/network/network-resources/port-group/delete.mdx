---
title: "删除分布式端口组"
---

## 前提条件

-   默认分布式端口组不支持删除操作。
-   若分布式端口组被虚拟机内存快照引用，不支持删除操作。
-   若分布式端口组关联 Kernel 适配器，不支持删除操作。

## 操作步骤

1.  在导航栏中，选择**资源清单** > **网络资源**。

2.  在资源树中，选择目标分布式端口组。

3.  在目标分布式端口组的详情页，点击**操作** > **删除**。

    <Callout type="warning">
    删除分布式端口组会卸载正在使用此端口组的虚拟机网卡，请谨慎操作。
    </Callout>

4.  确认知晓风险信息后，点击**确定**。
