---
title: "概述"
---

分布式端口组用于向虚拟机提供网络连接并供 Kernel 适配器流量使用。

集群添加首台主机后，ZSvirt 将基于该主机的相关配置自动创建默认分布式交换机，默认分布式端口组、以及默认 Kernel 适配器，用于集中管理主机的管理网络。基于网络规划，您可以灵活复用默认分布式交换机新建分布式端口组，或使用自定义分布式交换机新建分布式端口组。

-   **[新建分布式端口组](/docs/user-guide/network/network-resources/port-group/create)**  

-   **[修改分布式端口组配置](/docs/user-guide/network/network-resources/port-group/modify)**  

-   **[删除分布式端口组](/docs/user-guide/network/network-resources/port-group/delete)**
