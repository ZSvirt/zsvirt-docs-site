---
title: "新建裸金属集群"
---

裸金属集群用于管理裸金属主机。创建集群时可选择加载部署服务器，为集群中的裸金属主机提供 PXE 部署能力。

## 前提条件

- 裸金属集群需加载部署服务器才能为集群中的裸金属主机提供 PXE 服务。
- 一个裸金属集群仅支持加载一台部署服务器，一台部署服务器可同时加载至多个裸金属集群。
- 裸金属集群可加载分布式交换机，为集群中的裸金属主机提供网络服务。

## 操作步骤

<Steps>

<Step>

### 进入裸金属管理

在导航栏中，选择**资源清单** > **裸金属管理**。

选择目标数据中心，在详情页点击**裸金属管理**，进入**裸金属集群**子页面。

</Step>

<Step>

### 新建裸金属集群

点击**新建裸金属集群**，在弹窗中参考以下参数完成配置。

#### 基本信息

| 参数 | 说明 |
|------|------|
| **名称** | 裸金属集群名称 |
| **简介** | 可选项，可留空不填 |

#### 部署服务器

选择是否加载部署服务器。若加载，需指定**部署服务器来源**：

### 新建部署服务器

| 参数 | 说明 |
|------|------|
| **部署服务器名称** | 部署服务器名称 |
| **DHCP 监听网卡** | 部署服务器上连通部署网络的网卡设备编号 |
| **存储路径** | 部署服务器上的一个本地目录，用于保存 PXE 部署的镜像 |
| **部署服务器 IP** | 部署服务器的 IP 地址 |
| **SSH 端口** | 默认为 22 |
| **用户名** | 默认为 root 用户，也可输入普通用户 |
| **密码** | 对应用户的密码 |
| **DHCP 起始 IP** | 遍历 DHCP 服务的 IP 地址范围起始值 |
| **DHCP 结束 IP** | 遍历 DHCP 服务的 IP 地址范围结束值 |

<Callout type="info">

- DHCP 监听网卡需连接到裸金属设备的部署网络，且已配置 IP 地址。
- 此网卡所在网络不能存在其他 DHCP 服务，以免冲突。
- 若 DHCP 起始/结束 IP 留空不填，系统将根据此网卡 IP 侦测并过滤已用的 IP 地址作为 IP 范围。

</Callout>

### 使用已有部署服务器

选择要加载的已有部署服务器即可。

</Step>

<Step>

### 完成创建

确认配置无误后，点击**确定**。

</Step>

</Steps>
