## FAQ 范围

FAQ 会持续沉淀来自 GitHub Discussions、Issue 和迁移 PoC 的问题，优先覆盖安装校验、网络连通、存储挂载和镜像下载失败。

## 首批问题

### ISO 校验失败怎么办？

不要继续安装。重新下载 ISO 和 SHA256 文件，并记录镜像来源、文件名和下载时间。

### 网络不通先查什么？

先确认管理网、网关、DNS、端口组映射和主机防火墙，再检查 VM 内部网络配置。

### 存储挂载异常怎么处理？

先确认存储池状态、主机访问权限、网络连通和容量，再检查具体错误日志。
