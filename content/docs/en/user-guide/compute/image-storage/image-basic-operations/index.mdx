-   **[Add an Image](/en/docs/user-guide/compute/image-storage/image-basic-operations/add-image)**  
You can add various formats of system images or disk images to the image storage. When creating a virtual machine for the first time, the system will download the image to the data storage as an image cache. Using a URL or by uploading locally, you can add QCOW2, ISO, RAW, and VMDK image files to the image storage.
