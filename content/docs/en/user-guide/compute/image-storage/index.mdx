title: 'Image Storage'
---

Image storage acts as a repository for storing image templates containing operating systems, as well as disk images. Through image storage, you can share image files across multiple data centers.

This section introduces how to use image storage from the following chapters:

-   [Image Storage Basic Operations](/en/docs/user-guide/compute/image-storage/basic-operations)
-   [Image Basic Operations](/en/docs/user-guide/compute/image-storage/image-basic-operations)
-   [Image Cross-Platform Usage](/en/docs/user-guide/compute/image-storage/cross-platform)
