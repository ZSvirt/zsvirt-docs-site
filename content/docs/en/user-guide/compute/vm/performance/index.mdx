---
title: 'VM Performance'
---

If your business requires VMs to have certain characteristics, such as a stronger ability to compete for computing resources, you can achieve this by configuring the relevant VM settings provided by ZSvirt.

You can set these configurations when creating a new VM or modify the settings of existing VMs. This section assumes that you have already created several VMs.

The relevant VM configurations include:

-   [VM Resource Contention](/en/docs/user-guide/compute/vm/performance/resource-contention)
-   [VM CPU](/en/docs/user-guide/compute/vm/performance/cpu-features)
-   [VM QoS](/en/docs/user-guide/compute/vm/performance/qos)
