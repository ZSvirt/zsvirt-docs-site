---
title: 'Access a Virtual Machine'
---

You can access a virtual machine by launching the VM console with one click. In the VM console, you can perform various actions, such as installing the operating system, configuring the system, executing commands, and running applications. ZSvirt provides these access options:

-   Access a VM by using the console
-   Access a VM by using SSH

-   **[(Optional) Manage VM Access and Boot Options](/en/docs/user-guide/compute/vm/basic-operations/access-options)**  

-   **[Access a VM by using Console](/en/docs/user-guide/compute/vm/basic-operations/console-access)**  
You can quickly access a virtual machine through the console to perform various actions, such as install the operating system, configuring system, executing commands, and running applications.
-   **[Access a VM by using SSH](/en/docs/user-guide/compute/vm/basic-operations/ssh-access)**  
You can access a virtual machine by using the SSH connection protocol.
