title: 'Virtual Machine Basic Operations'
---

-   **[Create a New Virtual Machine](/en/docs/user-guide/compute/vm/basic-operations/create-vm)**  
A new virtual machine that you'll be able to customize CPU, memory, storage, and network.
-   **[Import a Virtual Machine](/en/docs/user-guide/compute/vm/basic-operations/import-vm)**  
Upload an OVF file to quickly import virtual machines, facilitating VM migration across different platforms.
-   **[Create a Virtual Machine from a Template](/en/docs/user-guide/compute/vm/templates/create-from-template)**  
Create identical virtual machines from a template. You'll be able to customize hardware, software, and other configurations.
-   **[Register a Virtual Machine](/en/docs/user-guide/compute/vm/basic-operations/register-vm)**  
You can register a virtual machine configuration file and data file to create a corresponding virtual machine record on the platform. After registration, the virtual machine is managed uniformly by the platform.
-   **[Clone a Virtual Machine](/en/docs/user-guide/compute/vm/basic-operations/clone-vm)**  
If you want to reuse the configuration of a virtual machine, you can clone the virtual machine. ZSvirt provides full VM cloning with two methods: full cloning and instant full cloning
