---
title: 'Change Host'
---

-   **[Hot Migration](/en/docs/user-guide/compute/vm/migration/change-host/hot-migration)**  
Hot migration migrates a running virtual machine. This action mainly copies the CPU register status and memory information.
-   **[Cold Migration](/en/docs/user-guide/compute/vm/migration/change-host/cold-migration)**  
Cold migration migrates a powered-off virtual machine.
