---
title: 'VM Migration Management'
---

ZSvirt provides both manual migration and HA automatic migration mechanisms. For more information about HA automatic migration, see [VM HA](/en/docs/user-guide/compute/vm/high-availability). This section introduces the following three scenarios for virtual machine manual migration:

-   [Change Host](/en/docs/user-guide/compute/vm/migration/change-host): Migrate a virtual machine to another host. This action only changes the host where the virtual machine runs.
-   [Change Data Storage](/en/docs/user-guide/compute/vm/migration/change-datastore): Migrate a virtual machine to another data storage. This action only changes data storage.
-   [Change Host and Data Storage](/en/docs/user-guide/compute/vm/migration/change-host-and-datastore): Migrate a virtual machine to another host and data storage.
