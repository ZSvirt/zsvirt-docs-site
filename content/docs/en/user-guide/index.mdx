This section summarizes the ZSvirt User Guide, covering getting started, resource management, O&M management, system management, backup, bare metal management, and more.

<Callout type="info">
**ZSvirt** was open-sourced from the **ZStack ZSphere** commercial project and has since developed independently. Some code, configuration, and documentation still retain historical **ZStack**/**ZSphere** names (such as environment variables, configuration items, dependencies, paths, and commands). These names are for compatibility only and do not affect the normal use of **ZSvirt**.
</Callout>
