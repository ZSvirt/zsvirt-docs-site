---
title: 'Host Hardware Monitoring'
---

ZSvirt supports monitoring the status of host hardware components such as CPU, memory, sensors, PCIe devices, and more.

The hardware components that can be monitored on the host include:

-   CPU
-   Memory
-   Physical Disks
-   Physical Network Cards
-   GPU Devices
-   Block Devices
-   USB Devices
-   Sensors (Voltage, Current, Fans, Temperature)
-   Power Supply
-   PCIe Devices
