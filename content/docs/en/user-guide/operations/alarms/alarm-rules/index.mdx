-   **[New Resource Alarm](/en/docs/user-guide/operations/alarms/alarm-rules/create-resource-alarm)**  
    Resource alarms are used to monitor time-series data of resources within the platform. For example, you can set an alarm for the CPU usage of a virtual machine. If the CPU usage exceeds 80% and persists for 5 minutes, it will trigger a system alarm.

-   **[New Event Alarm](/en/docs/user-guide/operations/alarms/alarm-rules/create-event-alarm)**  
    Event alarms are used to monitor predefined events in the platform. For example, you can set a host disconnected event alarm. When the host is disconnected, it will trigger a system alarm.
