---
title: 'Virtual Machine Backup'
---

In ZSvirt, the backup service is based on periodic scheduled backups. To perform a backup, you need to configure a backup plan. For more information, see [New Backup Plan](/en/docs/user-guide/backup/vm-backup/create-plan).

During executions of backup plans, the backup mode, backup chain length, backup data retention policy, and backup QoS all depend on the configured backup policy. For more information, see [Backup Policy](/en/docs/user-guide/backup/vm-backup/policy).

After you performed backups, you can use them to restore virtual machines. For more information, see [Data Recovery](/en/docs/user-guide/backup/restore).
