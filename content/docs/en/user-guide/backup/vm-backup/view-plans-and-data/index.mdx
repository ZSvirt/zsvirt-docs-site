---
title: 'View Backup Plan and Data'
---

During executions of backup plans, you can monitor the progress and get real-time updates on the backup activities. For more information, see [View Backup Plan Executions](/en/docs/user-guide/backup/vm-backup/view-plans-and-data/view-plan-execution).

During executions of backup plans, a series of backup data is generated, and you can view the backup data for protected resources. For more information, see [View VM Backup Data](/en/docs/user-guide/backup/vm-backup/view-plans-and-data/view-vm-backup-data).

-   **[View Backup Plan Executions](/en/docs/user-guide/backup/vm-backup/view-plans-and-data/view-plan-execution)**  

-   **[View VM Backup Data](/en/docs/user-guide/backup/vm-backup/view-plans-and-data/view-vm-backup-data)**  
During executions of backup plans, a series of backup data is generated and saved in the specified backup storage. ZSvirt provides a unified interface to help you view the backup data of protected resources, ensuring that no important business backups are overlooked.
