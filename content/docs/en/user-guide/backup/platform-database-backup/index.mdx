---
title: 'Platform Database Backup'
---

In ZSvirt, the backup service is based on periodic scheduled backups. To perform a backup, you need to configure a backup plan. For more information, see [New Backup Plan](/en/docs/user-guide/backup/platform-database-backup/create-plan).

During executions of backup plans, the backup cycle, execution time, start time, and backup data retention policy all depend on the configured backup policy. For more information, see [Backup Policy](/en/docs/user-guide/backup/platform-database-backup/policy).

After you performed backups, you can use them to restore the platform database. For more information, see [Data Recovery](/en/docs/user-guide/backup/restore).
