---
title: 'Quick Start Guide'
---

Follow this workflow to quickly create bare metal instances:

1.  (Optional) Add custom bare metal templates.

    Use templates to generate pre-configured files for unattended batch OS installation on bare metal instances. You can use either system templates or custom templates. For more information, see [Bare Metal Template](/en/docs/user-guide/bare-metal/templates).

2.  Create a new bare metal cluster.

    Provides dedicated cluster management for bare metal devices. For more information, see [Bare Metal Cluster](/en/docs/user-guide/bare-metal/clusters).

3.  Add bare metal chassis.

    You can add bare metal chassis by manual addition or template import. For more information, see [Bare Metal Chassis](/en/docs/user-guide/bare-metal/devices).

4.  Create bare metal instances.

    [For more information, see Bare Metal Instance](/en/docs/user-guide/bare-metal/hosts).
