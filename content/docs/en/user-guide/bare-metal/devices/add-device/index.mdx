---
title: 'Add a Bare Metal Chassis'
---

-   **[Manually Add a Bare Metal Chassis](/en/docs/user-guide/bare-metal/devices/add-device/manual)**  
Add single or multiple bare metal chassis by specifying an IPMI address or IPMI range.
-   **[Import a Bare Metal Chassis from a Template](/en/docs/user-guide/bare-metal/devices/add-device/import-template)**  
Use a CSV configuration file. Enter bare metal chassis information in the specified format and upload the file to import bare metal chassis.
