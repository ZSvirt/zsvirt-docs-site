---
title: 'System Predefined Roles'
---

ZSvirt provides predefined roles as shown in the following table.

<table className="doc-feature-table">
  <thead>
    <tr>
      <th>User Type</th>
      <th>Role Name</th>
      <th>Description</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td rowSpan="4">Admin User</td>
      <td>System Admin</td>
      <td>Manages daily system operations and maintenance.</td>
    </tr>
    <tr>
      <td>Security Admin</td>
      <td>Manages users, security policies, and security attributes.</td>
    </tr>
    <tr>
      <td>Auditor</td>
      <td>Manages system event information and auditing.</td>
    </tr>
    <tr>
      <td>Read-Only Role</td>
      <td>Has read-only access to system resources without write permissions</td>
    </tr>
    <tr>
      <td>Regular User</td>
      <td>VM User</td>
      <td>Supports regular users in creating virtual machines and basic VM management.</td>
    </tr>
  </tbody>
</table>
