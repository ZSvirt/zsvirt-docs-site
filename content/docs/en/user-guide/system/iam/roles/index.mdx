---
title: 'Role Management'
---

A role is a collection of permissions that, when granted to users and user groups, enables them to invoke related APIs for resource operations. ZSvirt adopts a Role-Based Access Control (RBAC) authorization model, defining resource permissions based on the user's job function (role). Through roles, you can achieve fine-grained control over user permissions.

-   **[System Predefined Roles](/en/docs/user-guide/system/iam/roles/built-in-roles)**  

-   **[Create Custom Role](/en/docs/user-guide/system/iam/roles/create-custom-role)**  
To meet diverse access control requirements, you can create custom roles.
-   **[Clone Role](/en/docs/user-guide/system/iam/roles/clone-role)**  
To meet diverse access control requirements, in addition to creating custom roles, you can clone existing roles.
-   **[Modify Role Permissions](/en/docs/user-guide/system/iam/roles/modify-permissions)**  
Edit the interface and API permissions of custom roles.
-   **[Delete Role](/en/docs/user-guide/system/iam/roles/delete-role)**
