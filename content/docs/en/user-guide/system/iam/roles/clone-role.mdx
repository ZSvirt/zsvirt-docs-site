---
title: 'Clone Role'
---

To meet diverse access control requirements, in addition to creating custom roles, you can clone existing roles.

Make sure ZSvirt is installed with a valid Advanced Edition license.

1.  In the navigation pane, choose **System Management** &gt; **Role**.

2.  On the Role page, select the target role and then click **Actions** &gt; **Clone Role**.

3.  In the Clone Role dialog, enter a name and description.

4.  Review the configuration and click **OK**.
