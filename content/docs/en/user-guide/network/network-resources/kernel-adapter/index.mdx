---
title: 'Kernel Adapter'
---

The Kernel adapter uses network labels to identify physical network traffic. After successfully adding a host to a cluster, ZSvirt creates a default Kernel adapter for each host, which is used to obtain and display the management network of that host. You can create Kernel adapters for hosts to manage storage network traffics.
