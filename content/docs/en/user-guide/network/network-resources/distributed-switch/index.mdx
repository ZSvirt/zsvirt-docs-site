---
title: 'Distributed Switch'
---

Through distributed switches, you can set up and configure network connections in the ZSvirt environment.

After the first host is added to the cluster, ZSvirt automatically creates a default distributed switch, a default distributed port group, and a default Kernel adapter based on the host's related configuration. These are used for centralized management of the host's management network. Based on your network planning, you can flexibly reuse the default distributed switch or use a newly created distributed switch.
