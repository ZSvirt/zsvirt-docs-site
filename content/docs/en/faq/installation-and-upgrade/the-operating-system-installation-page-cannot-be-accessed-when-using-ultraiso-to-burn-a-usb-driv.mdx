---
title: "The operating system installation page cannot be accessed when using UltraISO to burn a USB drive. How do I resolve this?"
---

## Solution
1.  If you cannot access the operating system installation page when using UltraISO to burn a USB drive, try using Rufus to burn the ISO and reinstall.

2.  Open the ISO image in Rufus.

    Insert the USB drive and open Rufus. In the Boot selection list, select **Disk or ISO image \(Please select\)**, click **Select**, and open the downloaded ISO image file.

3.  Write the image.

    After selecting the ISO image, keep all other Rufus settings at their defaults and click **Start**.

4.  After clicking **Start**, a prompt warns that the USB drive data will be formatted. Click **OK** to allow Rufus to burn the ISO image to the USB drive.

    <Callout type="info">
    -   If the USB drive contains important data, back it up before formatting.
    </Callout>

5.  The USB drive can now be used as a bootable drive, supporting both Legacy and UEFI boot modes.
