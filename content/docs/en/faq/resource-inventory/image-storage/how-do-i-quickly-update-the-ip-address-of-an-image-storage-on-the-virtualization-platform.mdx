---
title: "How do I quickly update the IP address of an Image Storage on the virtualization platform?"
---

## Cause
If the IP address of an Image Storage changes, you must update the IP address on the virtualization platform accordingly.

## Solution
1.  Update the IP address in the Image Storage operating system configuration.

2.  Click **Resource Inventory** &gt; **Images and Templates** and select the Image Storage.

3.  On the details page, click **Modify Configuration**, update the Image Storage IP address, and verify that the Image Storage status is normal.
