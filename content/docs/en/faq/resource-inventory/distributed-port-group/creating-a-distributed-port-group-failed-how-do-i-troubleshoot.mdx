---
title: "Creating a Distributed Port Group failed. How do I troubleshoot?"
---

## Solution
-   Check the operation log for the error message to identify the cause. If the failure persists, check the following:
-   Verify whether the new network segment overlaps with an existing network segment.

-   Multiple Distributed Port Groups can be created on the same Distributed Switch. The IP address ranges of Distributed Port Groups on the same Distributed Switch must not overlap.
