---
title: "Why does a Distributed Port Group not display a DHCP IP?"
---

## Feature description
-   If DHCP is disabled on the Distributed Port Group, no DHCP IP is displayed.

    <Callout type="info">
    If DHCP is enabled on the Distributed Port Group, a DHCP IP is automatically assigned when a virtual machine is created using this network.
    </Callout>

-   If no virtual machines have been created on the Distributed Port Group, no DHCP IP is displayed. An IP address is assigned at creation time.
