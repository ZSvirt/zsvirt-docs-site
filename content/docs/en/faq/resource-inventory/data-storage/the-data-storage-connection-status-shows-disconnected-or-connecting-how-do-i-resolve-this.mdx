---
title: "The Data Storage connection status shows Disconnected or Connecting. How do I resolve this?"
---

## Solution
-   Try the following approaches:
-   If the Management Node was restarted or the virtualization platform was upgraded, wait for the Data Storage to reconnect successfully.

-   If multiple hosts have abnormal connection states, this may cause Data Storage connection issues. Check and fix the host states.

-   If the Data Storage is Ceph type, verify that the available OSD capacity exceeds the write threshold.
