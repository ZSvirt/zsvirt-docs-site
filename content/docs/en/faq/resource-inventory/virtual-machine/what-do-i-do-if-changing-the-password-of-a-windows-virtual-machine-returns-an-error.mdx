---
title: "What do I do if changing the password of a Windows virtual machine returns an error?"
---

## Symptom
When changing the password of a Windows virtual machine, the following error appears:

```
return code: 1 stdout: stderr: error: internal error: unable to execute QEMU agent command 'guest-set-user-password':
The command guest-set-user-password has not been found
```

## Cause
An incorrect Windows Virtio driver may have been installed.

## Solution
-   The ZSvirt customized ISO already includes a compatible Windows Virtio driver. Extract the ISO, add the Windows Virtio driver as an ISO image to Image Storage, mount the ISO, and reinstall VMTools.
