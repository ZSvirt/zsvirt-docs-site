---
title: "How do I resolve an abnormal screen lock on a virtual machine?"
---

## Cause
A compatibility issue with the cirrus graphics adapter type used to start the virtual machine.

## Solution
1.  Go to **Resource Inventory** &gt; **Hosts and Virtual Machines** and locate the virtual machine. On the virtual machine details page, go to **Modify Configuration** &gt; **Other Hardware** &gt; **Graphics Adapter Type** and change it to **vga**.

2.  Click **Restart** to restart the virtual machine.
