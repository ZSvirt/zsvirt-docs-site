---
title: "How do I use a sound card in a Windows virtual machine?"
---

## Solution
1.  Click **Resource Inventory** &gt; **Hosts and Virtual Machines**, locate the target virtual machine, and open its details page. On the Advanced Configuration tab of the virtual machine details page, click **Remote Access** &gt; **Console Mode** &gt; **Modify** to switch the virtual machine console mode to **vnc+spice**. This action automatically loads a virtual sound card in the Windows device.

2.  Connect to the virtual machine using a remote desktop client to play audio normally.
