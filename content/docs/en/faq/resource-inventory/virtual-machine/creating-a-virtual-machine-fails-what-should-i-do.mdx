---
title: "Creating a virtual machine fails. What should I do?"
---

## Symptom
Creating a virtual machine on a specific host using Local Storage fails with a `Capacity usage has reached the 80% threshold` message.

## Cause
The Local Storage resources on the host are insufficient.

## Solution
-   Delete unnecessary resources on the host to free up capacity and then create the virtual machine, or create the virtual machine on a different host.
