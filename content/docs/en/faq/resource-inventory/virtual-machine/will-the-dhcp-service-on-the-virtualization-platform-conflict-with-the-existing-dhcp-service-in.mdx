---
title: "Will the DHCP service on the virtualization platform conflict with the existing DHCP service in the data center?"
---

## Feature description
-   The DHCP service on the virtualization platform does not conflict with the existing DHCP service in the data center.

    <Callout type="info">
    The network segment used by virtual machines on the virtualization platform must not overlap with any IP range already in use in the current environment. Overlapping ranges may cause IP address conflicts.
    </Callout>
