---
title: "How do I configure the platform login password strength? Does the password strength policy apply to sub-accounts?"
---

## Solution
-   In the ZSvirt main menu, go to **System Management** &gt; **Security Settings** &gt; **Platform Login Password Strength** to specify the password length and enforce the use of digits, uppercase and lowercase letters, and special characters.

-   This restriction applies to newly created sub-accounts and the admin account, but does not apply to existing sub-accounts.
