---
title: "Step 4: Install HA Suite"
---

This section introduces two methods for installing the high availability \(HA\) suite:

-   [Install Through CLI](/en/docs/install-zsphere/deploy/management-node-ha/cli-setup/step-4-ha-suite/cli-install)
-   [Install Through Configuration File](/en/docs/install-zsphere/deploy/management-node-ha/cli-setup/step-4-ha-suite/config-file-install)

<Callout type="info">
    When installing the HA suite with the same configuration, the CLI method takes precedence over the configuration file method.
</Callout>

-   **[Install Through CLI](/en/docs/install-zsphere/deploy/management-node-ha/cli-setup/step-4-ha-suite/cli-install)**
    In this scenario, you have installed both servers as the ZSvirt management nodes. To enable high availability for both nodes, you only need to install the **HA suite** on one of the nodes. If you install the HA suite on **MN 1**, MN 1 becomes the active management node and MN 2 becomes the standby management node.
-   **[Install Through Configuration File](/en/docs/install-zsphere/deploy/management-node-ha/cli-setup/step-4-ha-suite/config-file-install)**
    In this scenario, you have installed both servers as the ZSvirt management nodes. To enable high availability for both nodes, you only need to install the **HA suite** on one of the nodes. If you install the HA suite on **MN 1**, MN 1 becomes the active management node and MN 2 becomes the standby management node.
