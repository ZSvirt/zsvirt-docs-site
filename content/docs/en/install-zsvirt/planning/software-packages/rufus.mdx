---
title: "Burn ISO Image Using Rufus"
---

After you obtain the ISO package, you can use Rufus to burn the ISO image to a USB drive.

## Procedure

1.  Select an ISO image.

    1.  Connect your USB drive and open Rufus.

    2.  In the Boot Selection drop-down list, choose **Disk or ISO image**.

    3.  Click **SELECT** to open the ISO image file that you obtained.

    ![Select ISO Image](/docs/en/install-zsphere/images/ZStack_ZSphere_Installation_Tutorial_0003_2_1_1.png)

2.  Burn the image.

    1.  After selecting the ISO image, keep the other options at their default settings and click **START**.

    2.  Confirm the warning message.

        <Callout type="info">
            Burning the image will format the data on the USB drive. If you have important data on your USB drive, make sure to back it up before formatting.
        </Callout>

    3.  Click **OK**, and Rufus will burn the ISO image to the USB drive.

    ![Burn the Image](/docs/en/install-zsphere/images/ZStack_ZSphere_Installation_Tutorial_0003_2_1_2.png)


After the burning process completes, you can use the USB drive as a boot disk. ZSvirt supports booting in Legacy mode or UEFI mode.
