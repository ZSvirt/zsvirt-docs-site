## About This Guide
This guide describes how to install ZSvirt management node and how to set up management node HA.

![Installation Process](/docs/en/install-zsphere/images/ZStack_ZSphere_Installation_Tutorial_0002_1.png)

## Intended Audience
This guide is intended for experienced administrators who want to install ZSvirt.
